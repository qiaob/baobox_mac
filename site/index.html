原生，不是 Electron

Swift 5.9 + SwiftUI/AppKit，零第三方依赖。常驻内存控制在 50 MB 以内，不是每个工具再开一个浏览器内核。

模块化，随时增减

App 外壳不认识任何具体工具，每个模块自己声明菜单、快捷键与设置页。用不上的工具不会挡路，新工具接进来也不动框架。

数据只在本机

剪贴板历史、截图、窗口布局全部存在本地磁盘，不上传任何服务器。剪贴板落盘可开启 AES-GCM 加密，密钥进钥匙串。

已发布的工具

每一个都做到能替掉一个独立 App 的程度

不是把功能罗列在一起就叫工具集。下面每一项都是按「日常真的用得下去」的标准做的，右侧是出厂快捷键。

截图与录屏

一个快捷键自动识别意图：悬停高亮窗口，单击即截；按下拖拽切区域截图，八向手柄微调、方向键逐像素移动；⏎ 全屏。 截完原地标注，也能把图钉在屏幕最上层继续对照。录屏复用同一套选区交互，输出 MP4 或 GIF。

  • 矩形 / 箭头 / 画笔 / 荧光笔 / 马赛克 / 文字
  • 像素放大镜 · 实时坐标与色值
  • 贴图可缩放、调透明度
  • 历史存档，随时找回
  • 录制系统声音与麦克风
⌘⇧2

剪贴板

文本、图片、文件、链接全都记，浮层面板里即输即搜，⏎ 直接粘回你正在写的地方。 密码管理器标记过的内容默认不入库；历史落盘可以加密。选中条目时预览区会自动认出 JWT、JSON、时间戳、Base64， 就地给出格式化、解码、生成二维码这些动作。

  • 按类型过滤 · 收藏置顶
  • 纯文本粘贴 ⌘⌥V
  • 按 App 忽略名单
  • 过期自动清理
  • AES-GCM 落盘加密
⌘⇧V

窗口管理

半屏、四分屏、最大化、居中、跨显示器移动，共 13 条可自定义快捷键。 还能把当前所有窗口的位置存成一份布局，接上外接屏或换个工位时一键还原——每条记录带显示器标识与屏内相对位置， 分辨率变了也能对上。

  • 完整多显示器支持
  • 布局快照与恢复
  • 恢复窗口原始位置
出厂不绑定

键盘点击

按一下快捷键，屏幕上所有可点的东西都会浮出两个字母的标签，敲字母就等于点它——手不用离开键盘。 多显示器下标签范围可选当前屏或全部屏。

  • 基于辅助功能，识别真实控件
  • 优先走系统点击，不移动真实鼠标
⌃⇧空格

防休眠

编译、跑测试、下载大文件时别让屏幕黑掉。菜单里选 15 分钟 / 1 小时 / 2 小时 / 无限期， 到点自动释放，菜单实时显示剩余时间。可选连显示器一起防休眠。

纯菜单操作

Claude Code / Codex 助手

把本地 AI 编程 CLI 的状态收进菜单栏：最近会话一键在终端里续接，5 小时与周额度窗口、今日花费、 按天/项目/模型的用量报表，还能用可视化控件改配置文件、装事件通知与危险命令卫士。 纯本地文件解析——不调用任何 AI API、不需要登录。

  • 会话续接 · 用量与额度
  • 配置可视化，写文件前先备份
  • statusline 生成器 · MCP 面板

框出可滚动区域后自己滚页面，相邻画面按重叠自动对齐拼成一张长图。 取字则是用系统 Vision 本地识别选区里的文字，顺带解出画面里的二维码，识错了还能在结果窗里就地改完再复制。

hosts 管理

多套 hosts 方案，菜单里勾一下就生效，写完自动刷新 DNS 缓存。 只重写自己那一段，系统条目和你手写的内容原样保留，首次接管前还会备份原文件。

文本片段

常用文本存成片段，在剪贴板面板里搜出来直接粘。给它设个关键字，在任何输入框打「;关键字」就会就地展开。

网络抓包

菜单栏一键开关的本地 HTTP(S) 抓包器，Mac 与同网手机都能抓，两栏窗口看请求与响应。 关掉开关即零后台开销，默认不落盘。

权限与隐私

要什么权限，为什么要，说清楚

屏幕录制

截图、录屏、屏幕取字需要。首次使用时系统会弹窗，也可以随时在系统设置里收回。

辅助功能

剪贴板回填粘贴、窗口管理、键盘点击需要。没授权时功能降级为仅复制，不会静默失败。

麦克风（可选）

只有在录屏时打开「录制麦克风」才会请求。默认关闭。

不需要的

不需要联网账号，不需要后台上传，不收集使用数据。所有工具的数据都留在这台 Mac 上。
