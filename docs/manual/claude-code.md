# Claude Code 助手

简体中文 · [English](en/claude-code.md)

菜单栏 → **Claude Code**。为本地 Claude Code CLI 做的菜单栏仪表盘。

**数据全部来自 `~/.claude` 下的本地文件——不调用任何 AI API、不需要登录、不联网**
（唯一的例外是「检查最新版」会去 npm 查版本号，需要你主动点）。

没装 Claude Code 时（`~/.claude` 不存在）菜单里只显示一行置灰提示，不启动任何后台服务。

## 菜单

| 区块 | 内容 |
|---|---|
| 实时状态 | 当前会话在跑 / 在等你确认 |
| 额度 | `5 小时：已用 X ≈ $Y · Z 后重置`、`本周：已用 X ≈ $Y · Z 后重置` |
| 今日 | 今日估算花费 |
| 最近会话 | 最近 5 个，点击即在终端续接 |
| 快速续接… | 打开 Spotlight 式搜索面板 |
| 最近文件… | 打开最近文件面板 |
| 浏览会话历史… | 打开中心窗口 |
| 用量报表… | 中心窗口的用量页 |
| 今日改动… | 中心窗口的审计页 |
| 完成 / 等待通知 | 通知开关 |

> 所有费用都是**按公开定价估算**的，界面上处处标了「估算」。

## 快速续接面板

出厂快捷键 **⌃⇧空格**。Spotlight 式的浮层：输入即搜会话标题、项目名或路径。

| 按键 | 动作 |
|---|---|
| 输入 | 搜索 |
| ↑ / ↓ | 选择 |
| ⏎ | 在终端续接 |
| ⌘C | 复制续接命令 |
| Tab | **在「会话」与「文件」两种模式间切换** |
| esc | 关闭 |

### 最近文件模式

同一个面板切到「文件」模式（也有独立快捷键，出厂不绑定），搜索 Claude Code
**最近写过的文件**，⏎ 直接打开。

「设置 → Claude Code → 最近文件」里可以**按分类指定用哪个应用打开**（未设置的分类用系统
默认应用），以及是否包含 `~/.claude` 下的内部文件。

### 会话行的展示格式

「设置 → Claude Code → 会话行（快速续接面板）」可以选展示方案：**简洁 / 标准 / 详细**，
或**新建自定义方案**，自行勾选要显示的字段：项目、目录路径、最后活跃、模型、上下文大小、
文件大小。内置方案不可编辑，改动请新建自定义方案。

## 中心窗口

快捷键出厂不绑定；菜单 → 浏览会话历史…。三个标签页：

### 会话

可搜索的完整会话历史（按标题或项目搜）。每行：

- **双击** 续接
- 右键：续接、复制续接命令、**导出 Markdown**、删除

删除会二次确认——它会永久删掉那个会话的 JSONL 文件。

### 用量

- **5 小时窗口**与**周窗口**卡片：已用 token、估算花费、距重置倒计时，设了预算的话还有进度条
- 按**天** / 按**项目** / 按**模型**三张报表
- **调用统计**：Skill 与斜杠命令、MCP 服务器 › 工具、内置工具

### 审计

按日期列出 Claude Code 改过的文件：`N 个项目 · M 处改动`，可展开看具体文件，
右键**在访达中显示**。

## 通知与 hooks

「设置 → Claude Code → 通知」。

要收通知得先**安装 hooks**（设置页里一个按钮），Baobox 会把事件上报 hook 写进你的
Claude Code 配置；不想要了点「移除 hooks」，配置里不留残余。

| 设置 | 说明 |
|---|---|
| 完成 / 等待通知 | 任务完成、或 Claude 在等你确认时发系统通知 |
| 提醒方式 | 仅通知 / 提示音 / 语音朗读 |
| 提示音 | 可选系统音效 |
| 语音朗读 | 用系统语音念一句，文案可自定义，`{project}` 会替换成项目名，留空则念通知标题 |
| 试听 | 先听听效果再决定 |

### 额度预算提醒

- **每窗口预算（千 token）** 与 **周额度预算**
- 用量达 **80%** 时提醒一次
- 额度窗口重置时也可提醒（「新的 5 小时额度窗口已开始」）

周窗口支持两种口径：留空按**近 7 天滚动**估算；也可以**按固定重置时间对齐**（填重置星期与
小时，对照 Claude 的 `/usage` 填）。

## 危险命令卫士

「设置 → Claude Code → 配置 → 危险命令卫士」。

开启后安装一个 `PreToolUse(Bash)` hook：命中规则的命令会被**拦下来**，并把原因反馈给
Claude，让它换个做法。

内置规则：

- 递归删除根目录（`rm -rf /`）、递归删除主目录（`rm -rf ~`）
- 以管理员删除（`sudo rm`）
- 强制推送（`git push --force`）、硬重置（`git reset --hard`）、强制清理（`git clean -fd`）
- 删除数据表（`DROP TABLE`）
- 格式化文件系统（`mkfs`）
- 递归开放全部权限（`chmod -R 777`）

可以加**自定义规则**（ERE 正则，匹配整行命令 JSON），也可以一键恢复默认规则。

> 设置页里写明了：**黑名单只防手滑，不防刻意绕过**。

## 配置可视化

「设置 → Claude Code → 配置」把 `settings.json` 里常用的项做成了控件：

| 分组 | 内容 |
|---|---|
| 行为 | 默认权限模式（默认 / 自动接受编辑 / 计划模式 / 跳过所有确认）、默认模型、会话保留天数 |
| 权限规则 | allow / deny 规则列表，可增删；另有**预设**一键勾选：文件读取、Git 只读、Git 写入、包管理、构建与测试 |
| 隐私 | 关闭遥测、关闭错误上报、禁用非必要网络请求 |
| 提交署名 | 是否在提交中署名 `Co-Authored-By: Claude`（只影响以后的提交） |
| CLAUDE.md | 列出全局与各已知项目的 CLAUDE.md，可打开；缺失的可从内置模板创建 |

「跳过所有确认」会红字警告——Claude 可无提示执行任何操作。

**所有写入都是安全的**：只改自己那几个键，保留文件里的未知字段，写前备份同名
`.baobox.bak`。选「跟随默认」等于把那个键从文件里移除，而不是写一个默认值进去。

## Statusline 生成器

「设置 → Claude Code → Statusline」：勾选要显示的段，实时预览，满意了点「应用到 Claude Code」。

可选段包括：目录、Git 分支、模型、上下文占用 %、上下文 tokens、会话花费（估算）、
会话时长、Effort、时间等，分隔符可改。

如果检测到你已有一个非 Baobox 的 `statusLine` 配置，会**明确警告并二次确认**再覆盖。
装上之后可以随时「移除」。

## MCP 面板

「设置 → Claude Code → MCP」管理 `~/.claude.json` 顶层的**用户级** `mcpServers`：

- 列出现有服务器
- 添加：名称、类型（stdio 本地命令 / http 远程 URL）、命令、参数、环境变量
- 删除（二次确认）

## 维护

「设置 → Claude Code → 维护」：

- **磁盘占用**：会话记录 / Shell 快照 / 待办 / 其他 / 总计，以及会话文件数
- **清理旧会话**：清理早于 N 天的会话文件，二次确认，完成后告诉你删了几个、释放了多少
- **版本**：本机 `claude --version`，可**检查 npm 上的最新版**并**复制升级命令**
  （检查失败会提示「可能离线」）
