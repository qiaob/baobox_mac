# 截图与录屏

简体中文 · [English](en/screenshot.md)

菜单栏 → **截图**。这是 Baobox 里最大的一块，包含七件事：智能截图、标注、贴图、长截屏、
屏幕取字、录屏、屏幕标注画笔，外加一份截图历史。

需要**屏幕录制**权限。系统限制：在系统设置里勾选后必须重启 Baobox 才生效。

## 智能截图

出厂快捷键 **⌘⇧2**，或菜单 → 截图 → 开始截图。

按下后整屏变为选取状态，此时有三种走法：

| 操作 | 结果 |
|---|---|
| 移动鼠标 | 自动高亮鼠标下的**窗口**，边框标出范围 |
| 单击 | 截取当前高亮的那个窗口 |
| 按住拖拽 | 切换为**区域截图**，拉出任意矩形 |
| ⏎ | 截取整个屏幕 |
| esc | 取消 |

选区拉出来之后还能继续调整：

- 八个方向的手柄可以拖动改变大小
- 方向键**逐像素**移动选区，用于精确对齐
- 选区旁显示实时尺寸（如 `820 × 460`）
- 放大镜跟随光标，放大显示像素并给出坐标与该点色值

截图完成后按设置决定行为：复制到剪贴板、同时按模板保存到磁盘，或只保存。

### 保存设置

「设置 → 截图 → 保存」：

- **截图后自动保存到文件夹** —— 关掉就只进剪贴板
- **保存位置** —— 默认 `~/Pictures/Baobox`
- **文件名模板** —— DateFormatter 格式，自动追加 `.png`。默认 `截图 yyyy-MM-dd HH.mm.ss`
  （英文界面下默认模板不含单词前缀，因为 `Screenshot` 里的字母会被 DateFormatter 当成格式符解析成乱码）
- 同一秒连拍两张不会互相覆盖，后者自动追加序号

保存失败（目录不可写、落在 TCC 保护目录、磁盘满）会**弹窗告诉你**，不静默失败。

## 标注

截完图直接进入标注界面，工具条在选区旁边：

| 工具 | 说明 |
|---|---|
| 矩形 | 空心框 |
| 椭圆 | 空心圆 |
| 箭头 | 指示用 |
| 画笔 | 自由手绘 |
| 荧光笔 | 半透明粗线 |
| 马赛克 | 涂抹遮挡敏感区域 |
| 文字 | 点击输入 |
| 橡皮 | 点一下删掉整笔（不是擦局部） |

- 颜色与**粗细 / 字号**可调
- **撤销 ⌘Z** / **重做 ⇧⌘Z**
- **复制并完成 ⏎** / **保存 ⌥⏎** / **取消 esc**

工具条上还有三个跨功能入口：**贴图**、**取字（OCR）**、**长截屏（滚动拼接）**。

## 贴图

把截好的图钉在**所有窗口最上层**，用于一边看设计稿一边写代码这类场景。

- 标注工具条 → 贴图，或截图历史 → 钉到屏幕上
- 菜单 → 截图 → 贴图管理 → **从剪贴板贴图**（先复制一张图再用）
- 菜单 → 截图 → 贴图管理 → **关闭全部贴图**

贴图窗口右键菜单：

| 菜单项 | 说明 |
|---|---|
| 复制图片 | 回到剪贴板 |
| 另存为… | 存成文件 |
| 取字 | 对这张贴图跑 OCR |
| 透明度 | 调整不透明度 |
| 恢复原始大小 | 撤销缩放 |
| 关闭贴图 | 关掉这一张 |

贴图可以拖动、可以缩放；超过屏幕时会等比缩到可见区域的 80%。

## 长截屏（滚动拼接）

用于截一整页超出屏幕的内容。

1. 截图时框出**可滚动的区域**（比如浏览器正文区）
2. 在标注工具条点「长截屏（滚动拼接）」
3. 控制条出现后，**自己滚动页面**，Baobox 按相邻画面的重叠自动对齐拼接
4. 控制条实时显示「已拼接 N pt」
5. 点「完成」，或菜单 → 截图 → 结束长截屏

拼完弹出**长截屏预览**窗，四个动作：保存、复制、贴图、取字。

没拼到内容时会明确提示——通常是没框到真正可滚动的区域，或者控制条显示期间没有滚动。

## 屏幕取字（OCR）

把屏幕上的文字抠出来，识别由系统 **Vision 在本地完成，不上传任何内容**。

入口：

- 快捷键（出厂不绑定，可自设）
- 菜单 → 截图 → 屏幕取字
- 标注工具条 → 取字
- 贴图右键 → 取字
- 长截屏预览 → 取字

用法与截图一致：**单击窗口**取整窗，**拖拽**框选范围。

识别结果窗口里可以**直接编辑再复制**——识错一两个字不用重来。画面里的二维码 / 条码
也会一并解出来，显示为「二维码 / 条码：<内容>」。

「设置 → 截图 → 屏幕取字」：

- **识别语言** —— 仅英文 / 中文 + 英文 / 中文 + 英文 + 日文。**选得越少准确率通常越高**
- **识别后直接复制，不弹结果窗** —— 追求快的话打开

## 录屏

出厂快捷键 **⌃⇧R**，或菜单 → 截图 → 开始录屏。再按一次快捷键停止。

选区交互与截图完全一致：单击选窗口、拖拽框区域、⏎ 整个屏幕。

选好之后出现**确认工具条**，可以在这里临时开关系统声音与麦克风，再点「开始录制」。

录制中的悬浮 HUD：**暂停 / 继续**、**停止**、**取消录制（不保存）**。
菜单里也能暂停与停止。

「设置 → 截图 → 录屏」：

- **输出格式** —— MP4 或 GIF。GIF 无声音、最高 10 帧/秒、宽度缩至 720px，适合短片段
- **录制系统声音** —— 无需额外权限
- **录制麦克风** —— 首次开启会请求系统授权；声音写入**独立的第二条音轨**。
  未授权时提示一次并继续录（本次不含麦克风声音），不中断
- **混合为单条音轨** —— 系统声音与麦克风同录时，混为单轨可在所有播放器正常出声
  （有些播放器只播第一条音轨）

## 屏幕标注画笔

不截图，直接在**实时画面**上圈画，讲解和录屏时用。快捷键出厂不绑定，可自设；
菜单 → 截图 → 屏幕标注。

工具条：

| 按钮 | 说明 |
|---|---|
| 穿透模式 | **保留笔迹，同时能操作下面的 App** —— 边画边操作的关键 |
| 回到绘制 | 从穿透模式切回来 |
| 清空笔迹 | 擦掉所有 |
| 保存画面（含笔迹） | 把当前屏幕连同笔迹存下来 |
| 退出（esc） | 结束标注 |

「设置 → 截图 → 屏幕标注」：

- **画布范围** —— 所有屏幕 / 仅当前屏幕。选「仅当前屏幕」时画布只吃掉鼠标所在那块屏的点击，
  其余屏幕照常使用。改动在**下次开始标注**时生效
- **保存画布后弹出预览窗** —— 开启：保存即结束标注并打开预览窗（保存 / 取字 / 贴图 / 复制）。
  关闭：静默复制到剪贴板并按设置落盘，**标注不中断**

## 截图历史

菜单 → 截图 → 截图历史，列出最近的截图（默认保留 20 张，可调）。

每一张的子菜单：**复制**、**钉到屏幕上**、**另存为…**、**删除**。底部有「清空历史」。

历史与「保存到磁盘的文件」是**相互独立**的两件事：即便关掉自动保存，每次截图
（复制 / 保存 / 贴图）也都会进历史，便于找回。另存为时用的是**条目自身的时间戳**，
不是保存那一刻的时间。

「设置 → 截图 → 历史」可调保留张数。
