# 快捷键总览

简体中文 · [English](en/shortcuts.md)

对应 0.0.6。所有键位都可以在「设置 → 快捷键」里重录、清空或恢复默认；与系统或其他 App
冲突时录制界面会**即时提示**「快捷键被占用，请更换」。

## 出厂已绑定

| 快捷键 | 动作 | 工具 |
|---|---|---|
| ⌘⇧2 | 智能截图（单击截窗口 · 拖拽选区域 · ⏎ 全屏） | 截图 |
| ⌃⇧R | 开始 / 停止录屏 | 截图 |
| ⌘⇧V | 打开剪贴板历史面板 | 剪贴板 |
| ⌘⌥V | 纯文本粘贴上一条 | 剪贴板 |
| ⌘⇧空格 | 键盘点击（给元素打字母标签） | 键盘点击 |
| ⌃⇧空格 | Claude Code 快速续接面板 | Claude Code |
| ⌃⌥← / → / ↑ / ↓ | 左 / 右 / 上 / 下半屏 | 窗口管理 |
| ⌃⌥U / I / J / K | 左上 / 右上 / 左下 / 右下四分之一 | 窗口管理 |
| ⌃⌥⏎ | 最大化（填满可用区域，非全屏） | 窗口管理 |
| ⌃⌥C | 居中（不改变尺寸） | 窗口管理 |
| ⌃⌥⌘→ / ← | 移到下一个 / 上一个显示器 | 窗口管理 |
| ⌃⌥⌫ | 恢复原始位置 | 窗口管理 |

> ⚠️ 窗口管理的 **⌃⌥ 系列与 Rectangle / Magnet 完全同键**。两个都装的话请改掉其中一边。

## 出厂不绑定（需自行设置）

留空是因为这些组合容易和别的 App 撞车，或者本身不够高频：

| 动作 | 工具 |
|---|---|
| 屏幕取字（OCR） | 截图 |
| 屏幕标注画笔 | 截图 |
| 最近一条生成二维码 | 剪贴板 |
| 键盘滚动（j/k 滚页面） | 键盘点击 |
| 打开 Claude Code 中心 | Claude Code |
| 最近文件面板 | Claude Code |
| Codex 会话中心 | Codex 助手 |
| Codex 快速续接面板 | Codex 助手 |

## 无快捷键的工具

**防休眠**是纯菜单操作，不声明任何快捷键——避免为一个低频动作占用组合键。

## 界面内的按键（非全局）

这些只在对应界面打开时生效，不占用全局组合键。

### 截图 / 录屏选区

| 按键 | 动作 |
|---|---|
| 单击 | 截取 / 录制高亮的窗口 |
| 拖拽 | 自选区域 |
| ⏎ | 整个屏幕 |
| 方向键 | 逐像素移动选区 |
| esc | 取消 |

### 标注

| 按键 | 动作 |
|---|---|
| ⌘Z | 撤销 |
| ⇧⌘Z | 重做 |
| ⏎ | 复制并完成 |
| ⌥⏎ | 保存 |
| esc | 取消 |

### 剪贴板面板

| 按键 | 动作 |
|---|---|
| 直接输入 | 搜索 |
| ↑ / ↓ | 选择 |
| ⏎ | 粘贴到刚才的 App |
| ⌘⌫ | 删除该条 |
| esc | 关闭 |

### 键盘点击 / 滚动

| 按键 | 动作 |
|---|---|
| 两个字母 | 点击对应元素 |
| j / k 或 ↑ / ↓ | 滚动（滚动模式） |
| 空格 / ⇧空格 | 翻页（滚动模式） |
| esc | 退出 |

### 快速续接面板（Claude Code / Codex）

| 按键 | 动作 |
|---|---|
| 输入 | 搜索会话 |
| ↑ / ↓ | 选择 |
| ⏎ | 续接 |
| ⌘C | 复制续接命令 |
| Tab | 会话 / 文件模式切换（仅 Claude Code） |
| esc | 关闭 |

### 屏幕标注画笔

| 按键 | 动作 |
|---|---|
| esc | 退出标注 |

### 全局

| 按键 | 动作 |
|---|---|
| ⌘, | 打开设置 |
| ⌘Q | 退出 Baobox |
