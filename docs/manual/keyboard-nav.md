# 键盘点击

简体中文 · [English](en/keyboard-nav.md)

菜单栏 → **键盘点击**。出厂快捷键 **⌘⇧空格**。

按一下快捷键，屏幕上所有**可点击的元素**都会浮出一个两字母标签，敲那两个字母就等于点它。
手不用离开键盘。

需要**辅助功能**权限。未授权时菜单显示「需要辅助功能权限」。

## 怎么用

1. 按 **⌘⇧空格**
2. 屏幕上出现字母标签
3. 敲标签上的字母 → 该元素被点击
4. **esc** 取消

标签是按 AX（辅助功能）树扫描出来的——认的是**真实控件**（按钮、链接、菜单项、复选框…），
不是靠图像猜测，所以窗口挪动、分辨率变化都不影响准确性。

点击优先走系统的 `AXPress` 动作，**不移动你的真实鼠标**；只有元素不支持 AXPress 时才回退
到在元素中心合成一次点击。

## 连续点击

「设置 → 键盘点击 → 连续点击」（默认行为可自选）：

- **开启** —— 点完自动重新扫描并刷新标签，可以接着点下一个。**esc 或用鼠标点击**退出
- **关闭** —— 每按一次快捷键只点一次

需要连续点好几个地方时（比如逐个勾选一串复选框），开着省事很多。

## 标签显示范围

「设置 → 键盘点击 → 标签显示范围」：**仅当前屏** / **所有屏**。

多显示器下如果只想在鼠标所在那块屏上操作，选「仅当前屏」，标签更少也更好找。

## 键盘滚动

第二个动作：**滚动**（快捷键出厂不绑定，可自设；菜单 → 键盘点击 → 滚动）。

用于**页面本身不给焦点、鼠标又懒得动**的场景——典型的是 Chrome，它不暴露滚动条元素，
普通的键盘点击够不着。

进入滚动模式后：

| 按键 | 动作 |
|---|---|
| j / ↓ | 向下滚 |
| k / ↑ | 向上滚 |
| 空格 | 向下翻页 |
| ⇧空格 | 向上翻页 |
| esc | 退出 |

屏幕上会显示这一行提示，不用记。
