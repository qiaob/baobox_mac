# AI

简体中文 · [English](en/ai.md)

「设置 → AI」（侧边栏「通用 / 快捷键」下面）。Baobox 里用到 AI 模型的功能，都在这一页选用哪个模型：

- **本机模型**：在这台 Mac 上跑，免费，内容不出这台 Mac，但占内存和磁盘。
- **云端模型**：效果更好、不占本机内存，但要 API Key、按量付费，内容会发给服务商。

出厂全部用本机模型（翻译类用「自动」），云端只能自己手动选。

页面顶部分三栏：**功能 / 本机模型 / 云端模型**。

## 功能

用到模型的功能按工具分组，每个功能一行：功能名、模型下拉框、一句话说明。

| 工具 | 功能 | 用在 | 出厂 | 选云端时发出去的 |
|---|---|---|---|---|
| 会议 | 字幕翻译 | 字幕与同传、会议里打开字幕时的翻译 | 自动 | 识别出来的每一句话 |
| | AI 纠错 | 改正中文识别里的错字 | 本机 Qwen3-1.7B | 识别出来的中文句子连同上文 |
| | 会议纪要 | 会后的纪要、会议库里重新生成 | 本机 Qwen3-1.7B | 整场会议的转写和速记 |
| | 周报概述 | 本周周报里的概述 | 本机 Qwen3-1.7B | 一周各场会议的纪要摘要 |
| 划词助手 | 划词翻译 | 划词助手的「翻译」 | 自动 | 选中的文字 |
| | 划词助手 AI 动作 | 润色、改写、地道英文、解释、总结、自定义动作 | 本机 Qwen3-1.7B | 点了动作的那段选中文字 |
| 语音听写 | AI 润色 | 把听写整理成书面语 | 本机 Qwen3-1.7B | 听写出来的文字 |

工具自己的设置页里嵌着同一行（多一个「AI 设置…」跳回这里），改哪边都一样。

### 下拉框里有什么

- 翻译类功能先列「自动」和「系统翻译」。「自动」后面写着这台 Mac 实际用什么：macOS 15 起是「自动（系统翻译）」，
  系统不支持的语言或翻译失败时改用本机的离线翻译模型；更早的系统是「自动（本机 Hy-MT2-1.8B）」。
- 「本机」一组：所有本机模型，没下载的标「（未下载）」。翻译专用的 Hy-MT2 只出现在翻译类功能里。
- 每个云端服务商一组，列出你在「云端模型」里加的模型，没配好的标「（未配置）」。

### 第三列那句话

每行只说一件事：

- **选的这个现在用不了**（橙色）：「还没下载」带「去下载」；「缺 API Key」「地址不对」「没填模型名」带「去填写」；
  「需要 macOS 15」；下载中显示「下载中 42%」。
- **用的就是建议的模型**：「建议的模型」。
- **用的不是建议的**：「建议 Qwen3-8B：本机写得最好」，右边「改用」，点了就换过去。

建议跟着功能走，只在本机的 Qwen3 里挑：

| 功能 | 建议 | 为什么 |
|---|---|---|
| 字幕翻译、划词翻译 | 自动 | 系统自带，免费（没有系统翻译的 Mac 上就是本机 Hy-MT2，免费又快） |
| AI 纠错、AI 润色、划词助手 AI 动作 | Qwen3-1.7B | 最快：一句一秒左右，等不起 |
| 会议纪要、周报概述 | 这台 Mac 跑得动的最大的 Qwen3（16 GB 内存是 Qwen3-8B） | 本机写得最好；会后整理慢几秒没关系。内存小的 Mac 上就是 1.7B（内存只够它） |

鼠标停在建议上能看到完整的理由。

### 用量上限与隐私

功能栏最下面，默认收起；收起时标题右边也一直写着今天的用量，比如「今天 123 次 · 4.5k token」（到上限变橙色）：

- **每天最多请求**：默认 500 次（100–10000）。到了上限，云端请求改用本机模型，宠物问你要不要「再用 500 次」；
  这一栏里也有同样的按钮。这台 Mac 上的服务（如 Ollama）不花钱，不算进来。
- **每分钟最多请求**：默认 120 次（10–600）。
- **单次回复上限**：默认 4096 token（128–8192）。回复超过它会被截断，截断时改用本机模型。

都是所有云端模型合计，防止误刷费用；超过上限的请求改用本机模型（已下载的话）。下面还列着现在会把什么发给谁，
比如「字幕翻译：会把识别出来的每一句话发给「Anthropic Claude」。」；没有功能用云端时写
「现在没有功能用云端模型，什么都不会发出去。」

## 本机模型

只管模型本身：

- **这台 Mac**：芯片、内存；现在可用的内存和磁盘。
- **已装的模型**：每个一行，显示状态（未运行 / 启动中… / 运行中 · 占用 X GB），按钮「启动 / 停止」、「开机自启」开关、删除。
  下载中的也在这里，可以暂停、继续下载。
- **添加模型**：「安装模型」下拉框按这台 Mac 的内存分三组：**这台 Mac 跑得动 / 能跑，但很占内存 / 内存不够**。
  选中后显示它是什么样的模型、文件多大、运行时大约占多少内存，点「下载」。

可选的模型：

| 模型 | 说明 |
|---|---|
| Hy-MT2-1.8B | 腾讯混元，翻译专用，翻译类功能的默认本机模型 |
| Qwen3-0.6B / 1.7B / 4B / 8B / 14B / 32B | 通义千问，通用，中英文都好；1.7B 是通用功能的默认本机模型，0.6B 最小、效果一般 |
| Qwen3-30B-A3B | 通义千问，混合专家：体积大、速度快 |
| Gemma 3 4B / 12B / 27B | Google，英文和多语言好 |
| Llama 3.1 8B | Meta，英文好，中文一般 |
| GLM-4-9B | 智谱，中文好 |
| Phi-4-mini | 微软，小而聪明，英文好 |
| DeepSeek-R1 7B / 14B | 推理型：先思考再回答，慢 |

下拉框最后一项「自定义（粘贴 Hugging Face 链接）…」：粘贴 Hugging Face 上某个 `.gguf` 文件的链接（文件页或下载链接都行），
点「添加并下载」。效果和速度不保证。

几道保护：

- 选了「内存不够」的模型，点下载时先确认一次（「这台 Mac 跑不动它」）；磁盘不够时提示先腾空间。
- 启动前看一眼可用内存，不够时先问「内存可能不够」，确认了才启动。
- 每个文件下完都核对大小和校验值。

**什么时候在跑**：开了「开机自启」的模型，Baobox 一启动就拉起来并常驻，点「停止」才停；没开的，有功能用到时才加载，
空闲 10 分钟自动退出。要 Baobox 自己在登录时启动，去「设置 → 通用」打开。

## 云端模型

「服务商」：每个账号一行，收起时显示名字、哪家服务、Key 的状态（Key 已保存 / 缺 API Key / 本机，不用 Key）和模型数。
点开后：

- **名字**：下拉框里显示用的。
- **地址**：留空就用这家的默认地址；用国际站、代理或自建网关时再改。必须是 `https://`；只有这台 Mac 上的服务（如 Ollama）
  可以用 `http://`，否则 API Key 和内容会明文经过网络（填了会提示「不在这台 Mac 上的服务要用 https://」）。
- **API Key**：粘贴后点「保存」。存在钥匙串里，保存后不再显示，只写「已保存（输入新的可替换）」；可以删除。
  有官方申请页的服务下面有「获取 API Key」链接。
- **模型**：每个一行，「显示名称（可不填）」和「模型名（下拉选或直接输入）」，「测试」，删除。保存 Key 后下拉列表换成
  服务商返回的全部模型（Ollama 返回的就是本机装好的模型）；没保存 Key 时列常用模型。下面是「添加模型」「刷新列表」。
- 最下面「删除这个服务商…」：它的模型和 Key 一起删，用到这些模型的功能改回默认。

一个服务商可以挂多个模型（比如一个快的给字幕、一个强的给纪要），同一家也能加多个账号（比如公司和个人两个 Key）。

「添加服务商」菜单分三组：

1. Anthropic Claude；
2. 预填了地址和默认模型的：OpenAI、Google Gemini、DeepSeek、通义千问（阿里云百炼）、Kimi（月之暗面）、智谱 GLM、
   OpenRouter、硅基流动 SiliconFlow、Groq；
3. Ollama（本机）、自定义（OpenAI 兼容）。

Ollama 虽然排在这一栏，但跑在你自己的 Mac 上：不用 Key，内容不离开这台 Mac。先启动 Ollama 并拉取一个模型。
模型很大时会标出来，测试前先确认（加载时可能把内存占满）。

除了 API Key，这一栏的输入随打随存，不用点保存。

## 云端出错时

断网、超时、Key 无效、限流、服务端出错、超过本机的上限、回复被截断时，这一次改用同类的本机模型（已下载的话），
并提示「云端不可用，已改用本地」。一个服务商出了服务级的错，接下来 30 秒里用它的请求直接走本机，免得每句都先等一次超时。
本机模型也没下载时，功能会直接报错（比如字幕条提示翻译出错）。

## 数据与隐私

- 只有选了云端模型的功能才会发，也只发它需要的文字；其余都在本机处理。
- API Key 存在钥匙串里，不进偏好设置，也不写日志。
- 本机模型的文件在 `~/Library/Application Support/Baobox/Translation/models/`，从 Hugging Face 下载
  （Qwen3 和 Hy-MT2 连不上时换 ModelScope）。
- 账号、模型名、每个功能的选择存在 UserDefaults。

## 常见问题

- **下拉框里写着「（未下载）」**：点这一行的「去下载」，会跳到「本机模型」并选好那个模型。
- **用了大模型后电脑卡**：换成「这台 Mac 跑得动」那组里的模型；不用的模型点「停止」，或关掉「开机自启」。
- **「测试」失败**：按提示检查 API Key、地址和模型名。Ollama 提示「连不上本机服务（Ollama 启动了吗？）」时先启动它；
  大模型第一次加载要等一会儿。
- **提示回复被截断**：在「用量上限与隐私」里调高单次回复上限。
- **提示已到每分钟请求上限**：在「用量上限与隐私」里调高每分钟次数。
- **提示今天的云端请求已到上限**：点宠物气泡或「用量上限与隐私」里的「再用 500 次」，或者把每天的上限调高。
