## 先读这一页

### 它在哪

Baobox 是**菜单栏常驻**应用，没有 Dock 图标（`LSUIElement`）。启动后所有入口都在菜单栏的
Baobox 图标里：点开是一级菜单，每个工具一行，鼠标停上去展开该工具的二级菜单。

菜单里工具的顺序 = 代码里注册的顺序，不可拖动。

### 三种操作方式

1. **菜单** —— 所有功能都能从菜单栏点到，不需要记任何快捷键。
2. **全局快捷键** —— 常用动作可以在「设置 → 快捷键」里绑定，任何 App 前台时都生效。
   出厂只绑定了少数几个不易冲突的组合，见[快捷键总览](shortcuts.md)。
3. **设置窗口** —— `⌘,` 或菜单里的「设置…」。左侧是「通用 / 快捷键 / 各工具 / 关于」。

### 设置窗口的结构

| 标签页 | 内容 |
|---|---|
| 通用 | 界面语言（中文 / English / 跟随系统，切换需重启）、开机自启、权限状态与跳转、终端应用选择 |
| 快捷键 | 所有工具声明的可绑定动作，点击键位即录制；与系统或其他 App 冲突会即时提示；可恢复默认 |
| 各工具 | 每个工具一页，内容见各自章节 |
| 关于 | 版本号 |

「终端应用」影响 Claude Code / Codex 助手的「续接会话」用哪个终端打开。自动模式优先
已安装的第三方终端（iTerm2 → Ghostty → kitty → WezTerm → Alacritty），否则用系统终端。

### 首次启动

首次启动会弹出权限引导，请求两项权限：

- **屏幕录制** —— 截图、录屏、屏幕取字需要。
  ⚠️ 系统限制：在系统设置里勾选后**必须重启 Baobox** 才生效，引导窗与设置页都提供了一键重启。
- **辅助功能** —— 剪贴板回填粘贴、窗口管理、键盘点击、关键字展开需要。未授权时相关功能
  降级（例如剪贴板只复制不自动粘贴），不会报错也不会崩。

跳过也没关系，之后可以随时在「设置 → 通用 → 权限」里补齐。

麦克风权限只有在录屏时打开「录制麦克风」才会请求，默认关闭。

### 数据存在哪

所有数据都在本机，不上传：

```
~/Library/Application Support/Baobox/<模块>/
```

各工具独立子目录。截图默认存 `~/Pictures/Baobox`（可改）。详见[数据与隐私](privacy-and-data.md)。
