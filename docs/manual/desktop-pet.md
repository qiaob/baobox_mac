# 桌面宠物

简体中文 · [English](en/desktop-pet.md)

菜单栏 → **桌面宠物**。桌面上的一个小伙伴，同时也是 Baobox 统一的通知中心：会议提醒、专注休息、Claude Code / Codex
的任务动态都由宠物转达。关掉宠物后，通知自动改走系统通知中心，不会丢。

## 显示与隐藏

- 菜单「隐藏宠物」/「显示宠物」，或「设置 → 桌面宠物 → 启用宠物」（默认开）。
- 快捷键「显示 / 隐藏宠物」，出厂不绑定。
- 环形菜单外圈的「隐藏」。

出现、消失、换形象时有动画：脚下张开一个黑洞，宠物从里面蹦出来 / 钻进去。不想要就关掉「出场 / 退场动画」。
系统打开了「减弱动态效果」时只淡入淡出。

## 和宠物互动

| 操作 | 反应 |
|---|---|
| 单击 | 做个小动作，说一句话（「嘿！」「在呢～」） |
| 双击 | 击掌 |
| 在宠物身上左右来回蹭鼠标 | 摸摸头：「好舒服～」 |
| 睡着时单击或动鼠标 | 醒过来，伸个懒腰 |
| 拖动 | 搬到别处，气泡跟着走 |
| 右键 | 打开环形菜单 |

勿扰时（见下面的「勿扰」），或者你离开电脑 5 分钟以上，宠物会睡着。

开会记录时，会议的控制条挂在宠物头顶；该休息时，宠物会走到屏幕中间陪你休息（见[专注与健康](focus-health.md)）。

## 环形菜单

右键宠物，宠物身边弹出一圈按钮：

- **内圈**：专注、防休眠、换形象、手机互传、翻译、安静（1 小时），再加一格外圈排第一的工具，最后一格是「更多」。
- **点「更多」**展开外圈：取字、休息一下、Codex、画笔、线上会议、截图、剪贴板、框选翻译、录屏、键盘点击、最大化，
  以及清除通知（通知多时才有）、测试通知、设置、隐藏。没绑快捷键的工具排在前面，绑了的排在后面（反正键盘按得到）。没有的工具不显示。
- 开关类按钮的标题跟着状态走：防休眠开着时是「关闭防休眠」，专注中是「暂停专注」，录屏中是「停止录屏」……
- 点了看不出结果的（比如开关防休眠、暂停专注），宠物会说一句告诉你。
- 点空白处、点别的 App 或按 Esc 收起。

## 通知

| 样式 | 例子 | 怎么消失 |
|---|---|---|
| 轻提示 | 宠物说的话、操作回执、「已超过预定结束时间 5 分钟」 | 一行字，3 秒后自己消失 |
| 卡片 | 「纪要已生成」、Claude Code 任务完成、喝水提醒 | 标题、正文，有的带按钮，8 秒后自己消失 |
| 常驻 | 会议提醒、Claude Code 等你确认、每天固定时刻的提醒 | 点按钮或 × 才走；宠物每隔 25 秒招手提醒你一次 |

- 最多同时叠 3 条，最新的贴着宠物；多出来的排队，顶上写「还有 N 条」。
- 攒了一堆（4 条以上，比如锁屏回来）：气泡顶上点「全部清除」，或菜单「清除所有通知」、环形菜单「更多 → 清除通知」，一次清掉，
  勿扰时攒着还没合并出来的也一起清掉。清除等于每条都点了 ×，不会触发任何按钮。
- 鼠标停在气泡上时倒计时暂停。
- 点没有按钮的卡片本体，等于「打开」（比如跳到对应的会话）；点 × 只是关掉。
- 想先看看效果：菜单「发送测试通知 ▸」，三种各发一条。

### 勿扰

下面这些时候，一般通知先攒着，宠物睡下；结束后合成一条「N 条提醒已合并」：

- 菜单「安静一下 ▸」安静 1 小时 / 今天安静（「取消安静」恢复）；环形菜单的「安静」= 安静 1 小时；
- 前台 App 是全屏；
- Baobox 正在录屏、记录会议、专注中、休息画面在场。

重要提醒（会议提醒、Claude Code 等你确认这类）照常出来。你刚点的操作的回执也照常出来。

### 宠物关着时

通知改走系统通知中心，按钮照样能点。第一次关掉宠物（或宠物关着时启动 Baobox）会请求通知权限。

## 走动和待在哪

- **走动**：
  - 不走动：停在原地；
  - 安静：找个空地待着（默认）：走到一个不碍事的地方，以原地动作为主，一两分钟挪一两步，十几分钟换个地方；
  - 适中：多走动些，几分钟换个地方；
  - 活泼：到处溜达。
- **不挡我（自动避开正在用的窗口）**（默认开）：挡住你正在用的窗口时会走开（切换 App / 桌面后，或你在它旁边连着点的时候），
  远了就钻进黑洞、从空地冒出来。你亲手放的地方先待 10 分钟。
- **识别屏幕内容找空白处**（默认开，「不挡我」开着时才有）：找不到空桌面时，看一眼屏幕的低分辨率画面找空白的地方。
  用的是截图功能已有的屏幕录制权限，没有这个权限就不用，不会弹授权；画面在本机分析完立即丢弃，不保存、不上传。
- **活动范围**：
  - 屏幕底边（默认）：沿着 Dock 上沿走；
  - 窗口上：也会站到别的 App 窗口顶上、趴一会儿，你拖窗口它跟着走（「活泼」时隔几分钟自己跳上去，其他档只在那儿是个好地方时才上去）；
  - 自定义区域：点「框选区域…」拖出一块范围，它只在这块的底边活动；
  - 随意放：停在你放下的高度，不会往下掉。
- **大小**：拖动滑块。

「窗口上」只看窗口在哪，不读窗口的标题和内容。

## 形象

- 内置 3 个：小猫、小狗、小兔。在「当前形象」里换，或者点环形菜单的「换形象」轮着换。
- 「更多形象」里还能下载 18 个：柴犬、哈士奇、狐狸、巴哥犬、熊猫、长耳兔、青蛙、浣熊、小鸡、团子猫、方块猫、方块狗、
  方块兔、方块猪、方块狮、机器人，以及两个二次元形象凍香、炼金术师少女。点「下载」，下完自动换上；不要了点「删除」。
- **自制形象**：点「打开素材文件夹」，在里面建一个子文件夹，放 `pet.json` 和帧图，或者一个 `.glb` / `.vrm` 模型文件
  （格式见 [docs/desktop-pet/PACKS.md](../desktop-pet/PACKS.md)）。帧图形象的互动只有跳一下、说一句话。

## 设置

「设置 → 桌面宠物」：

| 分组 | 设置项 | 说明 |
|---|---|---|
| 宠物 | 启用宠物 | 默认开；关掉后通知回退系统通知中心 |
| | 走动 | 不走动 / 安静：找个空地待着（默认）/ 适中 / 活泼：到处溜达 |
| | 不挡我（自动避开正在用的窗口） | 默认开 |
| | 识别屏幕内容找空白处 | 默认开 |
| | 出场 / 退场动画 | 默认开 |
| | 活动范围 | 屏幕底边（默认）/ 窗口上 / 自定义区域（「框选区域…」）/ 随意放 |
| | 大小 | 滑块 |
| 形象 | 当前形象 | 下面写着素材来源 |
| | 打开素材文件夹 | 放自制形象 |
| 更多形象 | 每个形象一行 | 下载 / 删除 / 重试 |
| 通知 | 重要提醒响提示音 | 默认关 |
| | Claude Code、Codex、实时翻译纪要、专注与健康 | 各类通知的开关，默认都开 |

## 数据与隐私

- 设置存在 UserDefaults；下载的形象和自制形象在 `~/Library/Application Support/Baobox/Pets/`。
- 通知不落盘。
- 下载形象会连 GitHub（连不上时换 jsDelivr），下完核对文件校验值。除此之外宠物不联网。

## 常见问题

- **宠物挡住东西了**：「不挡我」默认开着，切一下 App 它就会让开；也可以把它拖走，或者把「走动」改成「不走动」再放到角落。
- **宠物一直在睡**：正在勿扰（安静中、全屏、录屏、会议记录、专注），或者你离开电脑 5 分钟以上。
- **某类通知没收到**：看看「设置 → 桌面宠物 → 通知」里那一类是不是关了，或者宠物正在安静中（攒着的会在结束后合并出来）。
- **下载形象失败**：检查网络后点「重试」。
- **别的程序能通过宠物发通知吗**：还不能。设计文档里写的对外通知接口（socket / 命令行 / URL）还没有做。

技术细节见 [docs/desktop-pet/](../desktop-pet/DESIGN.md)。
