# 会议

简体中文 · [English](en/meeting.md)

菜单栏 → **会议**。记录线上会议（麦克风 + 系统声音，标出「我 / 对方」）或线下会议（只录麦克风），会后用 AI
写纪要、整理行动项。接上日历后，还能提醒下一场会议、一键入会、自动发现正在开的会。原来的「实时翻译」也并进了
这里，叫「自由听译」。

所有内容默认只存在这台 Mac 上。

## 三种记录

| | 线上会议 | 线下会议 | 自由听译 |
|---|---|---|---|
| 适合 | Zoom、腾讯会议、钉钉、Teams、飞书、Google Meet 等线上会 | 面对面开会 | 看视频、听播客、上网课（就是原来的实时翻译） |
| 录什么 | 麦克风 + 系统声音（对方的声音），混成一路 | 只录麦克风 | 按「字幕与同传」里选的音源 |
| 标说话人 | 标「我 / 对方」 | 不标 | 不标 |
| 字幕和翻译 | 默认不开，控制条上点「字幕」打开 | 同左 | 照「字幕与同传」的设置，字幕条照常出 |

会议记录、自由听译、[语音听写](dictation.md)同一时间只能用一样（它们共用麦克风）。正在用时再开别的，
会提示「正在 XX，先停止再开始」。

## 开始记录

- 菜单：「开始线上会议记录」或「开始线下会议记录」。
- 「设置 → 会议」最上面也有这两个按钮。
- 会前提醒、会议检测的气泡上点「开始记录」或「加入并记录」。
- 快捷键「开始 / 结束线上会议记录」「开始线下会议记录」，出厂不绑定，在「设置 → 快捷键」或会议设置页里设。
- 桌面宠物的环形菜单（右键宠物）里点「线上会议」。

第一次开始会弹一次「开始记录前」：请先告诉参会人这场会议会被录音转写，并征得同意。告知是你自己的事，Baobox
只提醒，不会替你通知任何人。点「我已告知」开始，以后不再问。

手动开始线上会议时，如果日历里正有一场会（或 5 分钟内开始），会自动关联上：标题、参会人都从日历来。线下会议
不自动关联。

## 记录中：控制条

开始后屏幕上出现一条小控制条，不抢焦点：

- 宠物开着时，控制条挂在**宠物头顶**，跟着宠物走（要挪就拖宠物）；宠物关着时在屏幕顶部居中，可以拖，位置会记住。
- 左边：「● REC」和已录时长、类型（线上 / 线下）。
- **麦克风、喇叭两个图标**：有声音时亮绿色。点一下 = 这一路先不录（变红、带斜杠），再点恢复，记录里会记一行。
  这只是 Baobox 不录，会议里的人照样听得到你。线下会议只有麦克风。
- 按钮：
  - **暂停 / 继续**；
  - **标记重点**：标记前 20 秒左右说的内容，纪要里优先写；
  - **速记**：展开一个输入框，随手记的内容随转录一起保存，整理纪要时作参考，按 Esc 收起；
  - **字幕**：打开字幕条和译文（语言、朗读等照「字幕与同传」的设置）；
  - **结束**。

记录中菜单栏多一个红色的「● 32:15」，点开就是会议菜单。

会议进行中 Baobox 自动勿扰：宠物安静，一般通知先攒着，专注与健康的提醒顺延。关联了日历会议时，超过预定结束
时间 5 分钟会轻提示一次。

## 结束与纪要

点控制条上的「结束」、菜单「结束并生成纪要」，或再按一次「开始 / 结束线上会议记录」快捷键。

结束后先保存转录，再用 AI 写纪要。写好后宠物说「纪要已生成」，点「打开」进会议库。

- 纪要分四节：摘要、决议、行动项（负责人、事项、截止）、重点（标记过的地方）。
- 「纪要模板」可选默认 / 站会 / 1:1 / 面试，四节不变，侧重不同。
- 纪要默认用本机模型 Qwen3-1.7B 写，不联网（在会议设置「AI 纠错」分组的「纠错模型」，或「设置 → AI → 本机模型」里下载）。
  没有可用的模型、或内容太少时只保存转录，状态显示「仅转录」；之后可以在会议库里点「重新生成纪要」。
- 想写得更好，在会议设置的「会议纪要」一行换成更大的本机模型；也能选云端模型，选了才会把整场的转写和速记
  发给那个服务商。见 [AI](ai.md)。
- 一句话都没记下的会议不保存。
- 自由听译默认不保存记录。在「字幕与同传」里打开「保存记录（Markdown）」后，每次自由听译也存进会议库（类型「自由」），
  停止后整理出要点 / 结论 / 待办。

## 会议库

菜单「会议库」。窗口顶上切换两种视图：

- **会议**：按类型筛选（全部 / 线上 / 线下 / 自由），搜索标题、参会人、纪要内容。每行显示标题、类型、时间、
  时长、参会人和纪要状态（记录中 / 整理中 / 已生成 / 仅转录 / 生成失败）。
  鼠标停在一行上或右键：纪要、原文、复制纪要、重新生成纪要、导出…、在文件夹中显示、删除。
  右边的详情分三页：**纪要**（下面是可以勾选的行动项）、**原文**（转录和速记）、**系列**（同一系列的会议按时间排开）。
- **行动项**：所有会议的行动项，分「未完成 / 已完成」。勾选即完成，点来源可以跳回那场会议；
  「复制全部未完成」「导出…」。

「同一系列」= 日历里同一个重复事件，或标题相同（去掉日期、编号后）。

删除会把那场会议的文件夹移到废纸篓，可以放回。正在记录、正在整理纪要的不能删。

### 本周周报

菜单「生成本周周报」：汇总本周（周一到周日）各场线上、线下会议的决议和未完成的行动项，再加一段 AI 写的概述，
存进会议库并打开。本周没有会议时只提示一句。概述用哪个模型，在会议设置的「周报概述」一行选。

## 接上日历

「设置 → 会议 → 日历」打开「读取日历」，第一次打开时系统会问日历权限。读的是这台 Mac 上的日历
（含已同步的 Google、Outlook 等账户），只读，内容不出本机。下面可以勾选读哪些日历。

接上以后：

- **下一场会议**：菜单最上面一行显示「下一场：设计评审 · 25 分钟后」。打开「菜单栏显示下一场倒计时」后，
  菜单栏也常驻一个倒计时，点开是会议菜单。
- **会前提醒**：开会前 1 分钟（可改 5 分钟或关）宠物冒一个常驻气泡：标题、时间、参会人、来自哪个日历，
  此前有未完成的行动项也会写上。按钮：「加入并记录」（有会议链接时）或「开始记录」、「看简报」（有简报时）、「忽略」。
- **一键入会**：从日历事件的链接、地点、备注里找会议链接（Zoom、腾讯会议、钉钉、Google Meet、Teams、飞书、Webex），
  菜单「加入下一场会议」直接打开。没有链接时这一项是灰的。快捷键「加入下一场会议」出厂不绑定。
- **会前简报**：同一系列上一场的纪要摘要，加上这个系列所有未完成的行动项。从菜单「会前简报」或提醒气泡打开，
  窗口里有「加入会议」「开始记录」「打开上次纪要」「关闭」。没有可看的简报时菜单项是灰的。
- **暂停会议提醒** ▸ 1 小时 / 今天 / 直到明天（今天和明天都不提醒，后天恢复）。暂停期间会前提醒、检测的询问、
  自动开始都停；菜单里换成「恢复会议提醒」。

全天事件、已取消的、你已拒绝的会议不算。

## 自动发现正在开的会

「自动检测会议」默认开。下面这些时候会问你要不要记录（只问，不自己开始；同一场只问一次）：

- 日历里带会议链接的会议已经开始，还没在记录；
- 会议 App（Zoom、腾讯会议、钉钉、Teams、飞书、Webex、FaceTime、微信、Slack）开始开会：打开了会议窗口
  （钉钉，静音入会也算），或者用麦克风几秒以上；
- 浏览器在会议网站（Google Meet、Teams、Zoom、腾讯会议、飞书会议、Webex、Jitsi 的网页版）上用麦克风。

放音乐、看视频不算；浏览器用麦克风也不会算到 Slack、微信头上。

气泡上的按钮：「开始记录」「忽略」「不再检测此 App」。点了「不再检测此 App」的会进「忽略名单」，在设置里可以移除。

**命中日历会议时自动开始记录**（默认关）：打开后不再问。带链接的日历会议开始时，或日历会议期间会议 App 在用
麦克风时，直接开始记录并关联这场会议。某场会议的提醒点过「忽略」，那一场就不会自动开始。

## 设备自检

「设置 → 会议 → 记录 → 设备自检」点「试录 3 秒」：同时录麦克风和系统声音 3 秒，显示两路有没有声音，再把混在一起的
声音放给你听，这就是线上会议时识别听到的声音。试的时候说句话，同时放点声音（比如一段视频）。系统声音显示
「采不到」，说明还没给屏幕录制权限。

## 权限

| 权限 | 什么时候要 |
|---|---|
| 麦克风、语音识别 | 第一次开始记录（含自由听译）时 |
| 屏幕录制 | 线上会议录系统声音（对方的声音）。macOS 经屏幕采集提供系统声音；授权后要**重启 Baobox** 才生效 |
| 日历（完全访问） | 打开「读取日历」时 |

## 数据与隐私

```
~/Library/Application Support/Baobox/Meetings/
├── <年>/<日期 时间 标题>/    # 每场一个文件夹
│   ├── meeting.md           # 纪要、速记、转录
│   └── meta.json            # 参会人、行动项等
└── weekly/                  # 周报
```

- 只存文字，不存录音。
- 原实时翻译文件夹里的旧记录已按引用导入会议库，文件原地不动。
- 转录用 Apple 的语音识别，怎么在本机识别见[字幕与同传](live-translate.md#隐私)。
- 纪要、周报默认用本机模型。给「会议纪要」「周报概述」选了云端模型，才会把转写发给那个服务商；打开「字幕」后的翻译
  用「字幕翻译」选的模型，选了云端，识别出来的每一句也会发过去。见 [AI](ai.md)。
- 日历只读，不出本机。

## 常见问题

- **「我 / 对方」不准**：它按麦克风和系统声音两路的音量判断。外放时麦克风会收进对方的声音，戴耳机更准；判不准的句子不标。
- **录不到对方的声音**：线上会议录系统声音要屏幕录制权限，授权后重启 Baobox。用「设备自检」可以看出来。
- **提示「正在 XX，先停止再开始」**：语音听写或自由听译正在用麦克风，先停掉它。
- **只有转录、没有纪要**：多半是还没下载模型，或者内容太少。下载后在会议库里点「重新生成纪要」。
- **在开会却没问我**：浏览器里的会，会议标签页要在前台才认得出来；会议 App 静音入会、又没有专门的会议窗口时，
  要等你解除静音、用了麦克风才问。别的 App 的屏幕共享、录屏不检测。
- **没有会前提醒**：确认打开了「读取日历」、会前提醒不是「关」、会议提醒没有被暂停。
