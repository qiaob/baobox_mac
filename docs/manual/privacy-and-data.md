# 数据与隐私

简体中文 · [English](en/privacy-and-data.md)

一句话：**所有数据都只存在这台 Mac 上，Baobox 不上传任何东西，也没有账号体系。**

## 需要哪些权限

| 权限 | 谁要用 | 不给会怎样 |
|---|---|---|
| **屏幕录制** | 截图、录屏、屏幕取字、屏幕标注画笔 | 这些功能无法使用 |
| **辅助功能** | 剪贴板回填粘贴、窗口管理、键盘点击、关键字展开 | 降级：剪贴板只复制不自动粘贴；窗口管理与键盘点击不可用 |
| **麦克风**（可选） | 只有录屏时打开「录制麦克风」才请求 | 本次录制不含麦克风声音，录制继续 |

> ⚠️ 屏幕录制有个系统限制：在系统设置里勾选之后**必须重启 Baobox** 才生效。
> 权限引导窗和设置页都提供了一键重启。

不需要的：**没有网络账号、没有后台上传、不收集使用数据**。

## 数据存在哪

```
~/Library/Application Support/Baobox/
├── <各模块独立子目录>      # 避免相互串扰
~/Pictures/Baobox/           # 截图与录屏的默认保存位置（可改）
```

各工具的具体情况：

| 工具 | 存了什么 | 位置 |
|---|---|---|
| 截图 | 截图历史（默认 20 张）、录屏文件 | 支持目录 / `~/Pictures/Baobox` |
| 剪贴板 | 历史条目（文本、图片）、收藏、文本片段 | 支持目录，**默认 AES-GCM 加密** |
| 窗口管理 | 布局快照 | 支持目录 |
| 防休眠 | 只有设置项 | UserDefaults |
| 专注与健康 | 提醒项、当前这一轮、专注记录（最近 400 天） | 支持目录 |
| 语音听写 | 听写历史（只有文字，不存录音） | 支持目录 |
| 键盘点击 | 只有设置项 | UserDefaults |
| Claude Code 助手 | **不存**——全部实时读 `~/.claude` | — |
| Codex 助手 | **不存**——全部实时读 `~/.codex` | — |

设置项统一存在 UserDefaults（`com.baobox.app`）。

## 剪贴板的隐私设计

剪贴板是唯一会长期留存内容的工具，所以单独说明：

- **落盘加密（默认开）**：文本与图片写盘前用 **AES-GCM** 加密，密钥是随机 256-bit，
  存在**登录钥匙串**里，**不离开这台 Mac、不同步 iCloud**
- **密码管理器的内容默认不记录**：被标记为 `org.nspasteboard.ConcealedType` 的内容
  （1Password / Bitwarden / 钥匙串复制出来的密码）默认跳过。手动开启时会二次确认并
  说明风险；再次关闭时会**删除已记录的全部敏感条目**
- **临时内容始终忽略**：标记为 `org.nspasteboard.TransientType` 的内容没有开关，
  永远不记录——来源 App 明确要求不要保存
- **忽略名单**：指定的 App 在前台时复制的内容不入库
- **自动清理**：可设 1 / 7 / 30 / 90 天，超时的未收藏条目自动删除

关闭加密时会二次确认，因为已有历史会被**明文重写回磁盘**。

## 导出与导入（换电脑）

**设置 → 通用 → 数据**：「导出个人数据…」把文本片段、听写历史、专注与健康的提醒 / 设置 / 专注记录存成一个 JSON 文件；
在新 Mac 上「导入…」，先看摘要（各类几条、新几条、哪些关键字撞了），确认后**合并**，不覆盖已有的东西。

- 导出的文件**不加密**，里面有你的片段和听写内容，请放在安全的地方
- 不含：剪贴板历史（片段以外）、密码管理器复制来的敏感条目、截图、会议记录、API Key（钥匙串里的东西一律不出来）、本地模型
- 设置只在新 Mac 上还是出厂值时才用导入的值，你在新 Mac 上改过的不动

## 关键字展开的按键监听

文本片段的「打字时展开关键字」需要监听按键来匹配前缀，这是全 App 唯一涉及按键监听的功能，
所以边界写得很死：

- **默认关闭**，要用得自己开
- 内存里**最多保留 32 个字符**，用于匹配前缀
- **绝不落盘、绝不进剪贴板历史**
- 忽略名单里的 App 不展开
- 密码框等场景 macOS 本身就不会把按键交给应用

## 会联网吗

常规使用下不会。只有两个地方会发起网络请求，且都需要你**主动点击**：

- Claude Code 助手 → 维护 → 检查最新版（查 npm 上的版本号）
- Codex 助手 → 维护 → 检查最新版（同上）

Claude Code / Codex 助手的所有会话、用量、花费数据都是**读本地文件算出来的**，
不调用任何 AI API，也不需要登录。

**云端 AI 模型**（设置 → AI）默认不用。你可以在那里接入服务商和模型，再给每个功能选模型（划词翻译、字幕翻译、AI 纠错、
会议纪要、周报概述、听写润色）。**只有选了云端模型的功能**才会把它用到的文字发出去，「设置 → AI → 用量上限与隐私」里列着现在会把什么发给哪个服务商；
其余都在本机处理。API Key 存在钥匙串里。

- 地址必须是 `https://`；只有这台 Mac 上的服务（如 Ollama）可以用 `http://`——否则 Key 和内容会明文经过网络。
- 同一栏里能看到今天发了多少次、用了多少 token；每天最多 500 次（可调），到了就改用本地模型，宠物问你要不要「再用 500 次」。

## 会改我的文件吗

会，但只在你明确操作时，并且遵守同一套规则：

- **只动自己的键**，保留文件里的未知字段与注释
- **写前备份**同名 `.baobox.bak`
- JSON 用 `JSONSerialization`；TOML 做行级 / 块级编辑，不写通用解析器
- 遇到无法安全编辑的值就**置灰对应控件**，宁可不做也不改坏

涉及的文件：`~/.claude/settings.json`、`~/.claude.json`（MCP）、`~/.codex/config.toml`。
