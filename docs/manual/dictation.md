# 语音听写

简体中文 · [English](en/dictation.md)

菜单栏 → **语音听写**。用说的代替打字：说的话直接写进你正在用的输入框，光标在哪就写到哪。

出厂快捷键 **⌥Space**：按一下开始，每说完一句停一下，这句就上屏，可以一直说下去；再按一下结束。

## 三种用法

| 用法 | 怎么唤起 | 适合 |
|---|---|---|
| **开始 / 结束听写** | ⌥Space（出厂绑定），或菜单「开始听写」 | 日常输入：一句说完就上屏，可以一直说 |
| **按住说话** | 快捷键「按住说话」（出厂不绑定） | 说一句短的：按住说，松开就上屏 |
| **长听写** | 快捷键「长听写」（出厂不绑定），或菜单「长听写…」 | 一大段：文字先进收集面板，改好再一次插入 |

### 开始 / 结束听写

- 按一下开始。每句说完停约 1 秒，这句就写进当前输入框，接着说下一句。
- 再按一下（或菜单「结束听写」）结束，最后一句也会上屏。一直安静 30 秒会自动结束（可改 10 / 60 秒，或关掉）。
- 中途点进别的输入框，后面的句子就写到新的地方。
- 按 **Esc** 或点录音条上的 ✕ 停止：还没说完的那句丢掉，已经上屏的保留。

### 按住说话

按住快捷键说话，松开就写进去。快捷键可以用普通组合键或 F1–F12；单独一个修饰键（比如右 ⌥）暂不支持。

### 长听写

一直听到你结束。说的话一段段出现在「长听写」面板里，可以直接改。面板按钮：「插入」（插到刚才的输入框）、
「复制」「清空」「结束」（结束后变成「继续听写」）。

## 录音条

听写时出现一条小录音条，不抢焦点，文字要进的那个 App 一直在前台。默认在光标旁，取不到光标位置时在屏幕底部
（设置里可以固定在屏幕底部）。上面有音量、计时、正在识别的文字和提示，比如「松开结束」「再按一次结束」
「Esc 取消」。

结束后显示 2 秒结果：「已插入」，或「已复制，⌘V 粘贴」（没能直接写进去，文字在剪贴板里，录音条上也有「复制」按钮）。

## 文字怎么进输入框

「插入方式」默认「自动」：

1. 原生 App 的输入框：直接写到光标处（选中了文字就替换掉）。
2. 写不进去的（Electron App、终端、网页）：借剪贴板粘贴，用完把你原来的剪贴板还原，不进剪贴板历史。
3. 在密码框里、或者没有可输入的地方：只复制到剪贴板，自己按 ⌘V。

改成「总是粘贴」则一律借剪贴板粘贴。

开始 / 结束听写时，如果某句插不进去，不会每句都覆盖剪贴板：先攒着，结束时一次复制。开着听写历史的话，
历史里也有全文。

## 上屏前的整理

按顺序处理：

1. **语音指令**（默认开）：说「换行 / 新的一行 / new line」换行，「新段落 / new paragraph」空一行，
   「句号 / 逗号 / 问号 / 感叹号」打对应标点，「删除上一句 / delete last sentence」删掉这次听写里的上一句
   （已经上屏的用退格删，只删这次听写在当前 App 里输入的字）。
2. **口头禅过滤**（默认开）：去掉「嗯、呃、额、唔」、句首孤立的「啊、那个」、um / uh / er / hmm，以及「我我我」
   「the the」这样连说的字词。拿不准的不动。
3. **标点规整**：中文用全角标点，中英文之间不乱加空格；整段没有结尾标点时补一个。
4. **AI 润色**（默认关）：见下一节。

### AI 润色

把口语整理成书面语（去口水、顺句子），不增删信息。设置里「整理成书面语」可选：关（默认）/ 所有 App /
仅这些 App（比如只给文档、邮件润色，聊天保持原样）。

- 按住说话：整段说完再润色上屏，最多等 8 秒，超时就上原文。
- 开始 / 结束听写、长听写：逐句润色，每句多等一两秒。
- 默认用本机模型 Qwen3-1.7B（和字幕的「AI 纠错」是同一个），第一次要在设置里的「润色模型」下载，内容不出本机。
  模型没下载时这次先上原文，并提示一次。
- 也可以在「AI 润色」一行换成别的本机模型或云端模型。选了云端，听写出来的文字会发给那个服务商。见 [AI](ai.md)。

## 识别

- **识别语言**：自动（中英自动判别，默认）/ 跟随实时翻译 / 中文 / English。「自动」先按主语言认（系统是英文就先英文，
  否则先中文），一段拿不准时换另一种语言再认一遍，取更像的那份。开始 / 结束听写和长听写按句判断，可以一句中文、
  一句英文。中文识别本身就能认出夹杂的常见英文词。
- **优先设备端识别**（默认开）：这台 Mac 有这种语言的本机模型时，声音不出这台 Mac。设置页会写清每种语言是本机识别，
  还是走 Apple 服务器。没有本机模型的语言，在「系统设置 → 键盘 → 听写」里加上这种语言就能下载。
- **术语表**：人名、产品名等专有名词放进术语表，识别更准。和字幕与同传共用一份，点「去实时翻译编辑…」编辑。

听写和会议记录、自由听译不能同时用。它们在用麦克风时听写不开，会提示「正在 XX，先停止再听写」。

## 听写历史

菜单「复制上一次听写」「听写历史…」。历史窗口里可以搜索、复制、再次插入、删除、清空。

只存文字、时间和目标 App，不存音频。默认保留最近 50 条（10–500 条可调），也可以关掉。

## 设置

「设置 → 语音听写」：

| 分组 | 设置项 | 说明 |
|---|---|---|
| （顶部） | 三个快捷键 | 「开始 / 结束听写」出厂 ⌥Space；「按住说话」「长听写」出厂不绑定 |
| 识别 | 识别语言 | 默认「自动（中英自动判别）」 |
| | 安静多久自动结束 | 只管开始 / 结束听写：关 / 10 / 30（默认）/ 60 秒 |
| | 优先设备端识别 | 默认开；下面写着每种语言走本机还是 Apple 服务器 |
| 文本处理 | 语音指令、口头禅过滤 | 默认都开 |
| AI 润色 | 整理成书面语 | 关（默认）/ 所有 App / 仅这些 App（「添加 App…」） |
| | AI 润色、润色模型 | 用哪个模型、本机模型的下载（不是「关」时才显示） |
| 插入 | 插入方式 | 自动（默认）/ 总是粘贴 |
| 录音条 | 位置 | 光标旁（默认）/ 屏幕底部 |
| | 开始与结束提示音 | 默认关 |
| 听写历史 | 保存听写历史 | 默认开，保留最近 50 条；「听写历史…」「清空历史…」 |
| 术语表 | 共 N 条（与实时翻译共用） | 「去实时翻译编辑…」 |
| 权限 | 麦克风、语音识别、辅助功能 | 显示有没有授权，没有时点「去设置」 |

## 权限

第一次用时才按需申请，不预先弹窗：

| 权限 | 用来 | 没有会怎样 |
|---|---|---|
| 麦克风、语音识别 | 听 | 听写开不了，会打开系统设置对应的页面 |
| 辅助功能 | 写进输入框、模拟粘贴、拦截 Esc | 文字只复制到剪贴板，自己 ⌘V；Esc 不能取消，点录音条上的 ✕ |

## 数据与隐私

- 听写历史存在 `~/Library/Application Support/Baobox/Dictation/history.json`，只有文字。
- 默认在本机识别；没有本机模型的语言走 Apple 的语音识别服务（和系统自带的听写一样）。
- AI 润色默认在本机。只有给「AI 润色」选了云端模型，听写出来的文字才会发出去。

## 常见问题

- **按 ⌥Space 没反应**：可能被别的 App（比如启动器）占了，在「设置 → 快捷键」里换一个。
- **字没写进去，提示「已复制，⌘V 粘贴」**：没有辅助功能权限、在密码框里，或者当前没有可输入的地方。手动 ⌘V 即可。
- **提示「语音识别暂时不可用」**：检查网络，或在「系统设置 → 键盘」里开启听写。
- **提示「正在 XX，先停止再听写」**：会议记录或自由听译正在用麦克风，先停掉它。
