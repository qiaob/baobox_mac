# 划词助手

简体中文 · [English](en/selection-assistant.md)

菜单栏 → **划词助手**。在任何 App 里选中文字（浏览器、Google 文档、PDF，单个词也行），选区上方就弹出一排小按钮：
**翻译、学习、润色、改写、地道英文、解释、总结**，后面还能加你自己的动作。改写类的结果可以直接替换原文。
根本不能选中的文字（图片、扫描版 PDF、视频画面）用「框选取字」。

需要**辅助功能**权限（读选中的文字）。框选取字另需屏幕录制权限。

## 动作条

选中文字、松开鼠标约 0.4 秒后弹出动作条。动作条只是按钮，**点了哪个才跑哪个**，不点就什么都不做。

- 这 0.4 秒里按了 ⌘C（或任何键）、或者剪贴板变了，这次就不弹 —— 只是想复制时不打扰你。
- 点别处、开始打字、滚动页面，或者 4 秒没碰它（鼠标也不在条上），动作条自己消失。
- 「改写 ▾」可以直接选语气：更正式 / 更口语 / 更简洁。
- 最右边「⋯」打开设置，可以加动作、排顺序。

| 动作 | 做什么 | 结果 |
|---|---|---|
| 翻译 | 翻译选中的文字 | 译文，可朗读、复制 |
| 学习 | 音标、发音、释义，学这个词或这句话 | 见下面的「学习」 |
| 润色 | 改错字、语病和标点，不改意思 | 可以替换原文 |
| 改写 | 改写得更正式、更口语或更简洁 | 可以替换原文 |
| 地道英文 | 写成能直接发出去的地道英文（Slack、邮件、PR） | 可以替换原文 |
| 解释 | 这段话、术语、代码或报错是什么意思 | 只显示 |
| 总结 | 3–5 条要点 | 只显示 |

## 结果面板

点了动作，动作条展开成结果面板：

- 顶上还是那排动作，当前的高亮。点别的动作就在原处换结果；结果会记住，切回来不用重跑。
- 改写类（润色、改写、地道英文，和结果类型是「改写」的自定义动作）：主按钮「替换 ⏎」，另有「复制」。
- 其他动作：主按钮「复制」。
- 还有「重新生成」和朗读按钮。最下面写着用的是哪个模型、花了几秒；云端出错改用本地时会注明「云端不可用，已改用本地」。

### 替换原文

只在改写类动作、并且选中的文字在一个**能编辑的输入框**里时才有「替换 ⏎」。终端（借剪贴板取来的）、框选取字的、
网页正文这类只读的文字只能复制 —— 往终端里粘多行文字可能直接被执行。

替换前会再核对一次选区：和刚才选的对不上（你改过、换了地方），就不替换，改成复制，并提示「选区变了，没有替换，已复制」。
替换后想撤销，在原 App 里按 ⌘Z。

## 翻译

- 原文语言自动识别。「译成」选目标语言，「原文已是该语言时译成」选备选语言：比如「译成」中文、备选 English，
  外文一律译成中文，中文译成英文。浮层里也能临时换目标语言。
- 可以朗读原文、朗读译文，复制译文。打开「翻译完成后自动朗读译文」就自动读。
- 翻译引擎在「翻译引擎」分组里选，默认「自动」：macOS 15 起用系统翻译，系统不支持的语言或失败时改用离线翻译模型
  （腾讯混元 Hy-MT2，33 种语言，下载一次，断网也能翻）。macOS 14 上只能用离线模型，浮层里会给下载入口。

## 学习

看设置里的「我的母语」和「在学的语言」（目前只支持中文和英文，默认母语中文、在学英文）：

| 选中的是 | 显示什么 |
|---|---|
| 在学的语言（英文）的 1–3 个词 | **词典卡**：单词、音标、美 / 英两个发音按钮、慢速、释义、词形变化（比如 became 是 become 的过去式），还有它所在的那句原文 |
| 在学的语言（英文）的句子、段落 | **整句学习**：每个词都能点，点了显示音标和释义（再点「详细」看词典卡）；按 0.5× / 0.75× / 1×、美音或英音朗读，读到哪个词标出来；母语译文；**跟读** |
| 母语（中文） | 先告诉你用英文怎么说，再按上一行展示这句英文（能点词、朗读、跟读） |
| 在学的是中文、选中中文 | 拼音、朗读、母语译文 |

- **跟读**：点「跟读」把这句读一遍，本机语音识别比对，读对的词变绿，没读对的标红，再显示「读对了 N / M 个词」。
  要麦克风和语音识别权限；会议记录、听写在用麦克风时不能跟读。
- **离线英汉词典**：音标、释义、词形变化来自开源的 ECDICT，要在设置的「学习」分组里下载一次（约 66 MB，下完整理成本地索引）。
  没下载时，「学习」只给译文和发音。

## 框选取字

菜单「框选取字…」或快捷键「框选取字」：屏幕定格，拖出一块区域，识别里面的文字（在本机识别），然后对这段文字弹出动作条。
图片、扫描版 PDF、视频画面、游戏里的字都能取。要屏幕录制权限，授权后要重启 Baobox。

## 键盘

- **按住 ⌥ 用数字选**：动作条或结果面板在屏上时，按住 ⌥，按钮上会显示编号，⌥1–⌥9 直接选。
- **唤出动作条**（快捷键，出厂不绑定）：对选中的文字以键盘模式弹出动作条：按字母直达（T 翻译、L 学习、P 润色、R 改写、
  E 地道英文、X 解释、S 总结，自定义动作按数字），← → 移动，回车执行，Esc 关闭。这些键只在动作条在屏上时临时占用。
- **一键直达**：「翻译选中文字」和每个内置动作都有自己的快捷键（「选中文字：学习」等），选中后按一下直接出结果，
  跳过动作条。出厂都不绑定。

## 自定义动作

设置 → 动作 →「新建动作」，填：

- **名称**；
- **提示词**：`{text}` 代表选中的文字，不写的话文字接在提示词末尾；
- **结果类型**：改写（可以替换原文）/ 回答（只显示）。

内置动作也能关掉、调顺序（「翻译」不能关）。列表从上到下的顺序，就是动作条上从左到右的顺序；动作条上的前 9 个
对应 ⌥1–⌥9。

## AI 动作用哪个模型

润色、改写、地道英文、解释、总结和自定义动作，都用「划词助手 AI 动作」这一行选的模型。默认是本机的 Qwen3-1.7B
（和字幕纠错、听写润色是同一个），第一次用要在「本地 AI 模型」那一行下载，第一次启动要等几秒。

- 选中的文字太长、本机模型一次处理不了时会直接告诉你，不会悄悄截断；接了云端模型的话，可以点「这次用云端」。
- 也可以选更大的本机模型或云端模型。选了云端，**只有你点了动作**，那段文字才会发出去；只是选中、不点，什么都不发。
- 翻译有自己的模型设置（「划词翻译」那一行），和 AI 动作分开。见 [AI](ai.md)。

### 借用剪贴板取词

有些 App（比如很多终端）不告诉辅助功能选中了什么。这时 Baobox 让它用自己的「拷贝」把选区放进剪贴板，读完立即还原
你原来的剪贴板，Baobox 的剪贴板历史也不会记。自动弹出只在拖选或双击之后这样做；剪贴板里是密码时不做。

## 权限

| 权限 | 用来 | 没有会怎样 |
|---|---|---|
| 辅助功能 | 读选中的文字、监听选中、替换原文 | 读不到选中的文字，也不会自动弹出；「框选取字」不受影响 |
| 屏幕录制 | 框选取字 | 框选取字用不了；授权后要重启 Baobox |
| 麦克风、语音识别 | 跟读 | 跟读用不了 |

## 数据与隐私

- 只在弹出时读一次选中的文字，不记录、不保存。
- AI 动作、翻译默认都在本机（或用系统翻译）。只有给对应的一行选了云端模型才会发出去：AI 动作只发你点了动作的那段文字，
  划词翻译发要翻译的文字。
- 离线词典在 `~/Library/Application Support/Baobox/SelectionTranslate/`，从 GitHub 下载；翻译模型和其他本机模型在
  `~/Library/Application Support/Baobox/Translation/models/`。

## 常见问题

- **选中了不弹**：先看辅助功能权限；再看菜单里「选中后自动弹出」是不是勾着。选完马上按了 ⌘C 的那次不会弹。
- **终端里选中不弹**：确认「辅助功能读不到选区时，借用剪贴板取词」开着；终端里要拖选或双击，单击不算。
- **没有「替换」按钮**：只有改写类动作、并且文字在能编辑的输入框里才能替换；其他情况点「复制」。
- **提示文字太长**：本机模型一次能处理的长度有限，分几段选，或者点「这次用云端」。
- **macOS 14 上不能翻译**：系统翻译要 macOS 15，在设置的「翻译引擎」里下载离线翻译模型就能翻。

技术细节见 [docs/selection-translate/ASSISTANT.md](../selection-translate/ASSISTANT.md)。
