# 防休眠

简体中文 · [English](en/caffeinate.md)

菜单栏 → **防休眠**。临时阻止 Mac 自动进入睡眠，适合跑构建、跑测试、下载大文件等挂机场景。

基于 IOKit 电源管理断言（`IOPMAssertionCreateWithName`），不调用外部命令，不常驻进程。

## 用法

二级菜单顶部是**状态行**：

- 未开启
- 已开启 · 剩余 N 分钟
- 已开启 · 无限期

下面是四个预设：**开启 15 分钟 / 1 小时 / 2 小时 / 无限期**，当前生效的那个会打勾。
再下面是「关闭」。

还有一行「按默认时长开启」，用「设置 → 防休眠」里配的默认时长。

到点自动关闭，菜单里的剩余时间实时更新。

## 设置

| 设置项 | 说明 |
|---|---|
| 菜单点击或快捷开启时的时长 | 15 分钟 / 1 小时 / 2 小时 / 无限期 |
| 同时防止显示器休眠 | 默认**关**。开启后屏幕也不会自动熄灭；改动会**立即作用于当前正在生效的防休眠** |

默认只阻止系统休眠，屏幕仍会正常熄灭——大多数挂机场景并不需要屏幕亮着。

## 说明

- 本工具**没有快捷键**，纯菜单操作（避免占用组合键）
- App 退出时自动释放断言，绝不会把系统永久保持在唤醒状态
- 系统没能创建断言时会弹窗给出错误码，不静默失败
