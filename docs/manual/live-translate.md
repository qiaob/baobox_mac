# 实时翻译

简体中文 · [English](en/live-translate.md)

把**麦克风**或**系统声音**里的语音实时转成字幕，**英文 ⇄ 中文**互译，显示在屏幕底部的一条字幕条上。
看英文视频 / 网课、开线上会议、和外国同事当面聊天都能用。

## 开始与停止

- 菜单栏 → 会议 → **开始自由听译**；再点一次（或字幕条右上角的 ×）停止。会议记录进行中，这一项变成「打开 / 收起字幕」。
  （独立的「字幕与同传」入口已并入会议，#106。）
- 全局快捷键「开关实时翻译」出厂不绑定，可在「设置 → 快捷键」或「设置 → 会议」里自设。

## 音源

| 音源 | 适合 | 需要的权限 |
|---|---|---|
| **系统声音**（默认） | Mac 正在播放的声音：视频、网课、会议里对方说的话 | 屏幕录制（macOS 经屏幕采集接口提供系统声音） |
| **麦克风** | 你自己或现场的人说的话 | 麦克风 |

在「设置 → 会议 → 字幕与同传」里切换；正在运行时切换会自动重启识别。麦克风用的是系统默认输入设备
（「系统设置 › 声音 › 输入」里选）。Baobox 自己发出的声音不会被采集。

## 语言

- **说**：说话的语言。选「自动」时在两种语言之间逐句判断；也可以固定一种。
- **译成**：翻译成哪种语言。某句说的本来就是这种语言时**不翻译**，直接把原文当字幕显示（例如「译成 English」时说英文，只显示英文原文，不会出中文）。

关掉「显示翻译」就只显示原文字幕（当作实时听写用）。

## 字幕条

- 最新的一句在最下面实时刷新，之前的淡一些。**拖字幕条的边或角可以改大小**（右下角有拖拽角），拉高了就多显示几句；
  用触控板 / 滚轮往上翻能看前面的（最多 200 句），翻上去时字幕不会把你拽回来，点右下角「回到最新」或翻回底部就接着跟。
  在字幕条上切换音源、语言等设置时历史会留着，关掉字幕条才清空。
- 显示样式：**原文 + 译文** / **仅译文** / **仅原文**。
- 字号、背景不透明度可调，改了立刻生效。
- 拖动字幕条可移动，位置和大小会被记住；全屏 App、切换桌面时都在最上层。
- 每次打开 Baobox 后第一次实时翻译，要先把本地翻译模型加载进内存（约 6～9 秒），字幕区底部会转圈显示「正在加载翻译模型」，
  加载好就消失；之后 10 分钟内再开不用重新加载。
- 右上角是**延迟监控**：「识别」= 停顿后开口到出字，「翻译」= 一截话说完到译文出来（开了 AI 纠错含纠错），都是最近 5 次的中位数。
  变黄 / 变橙说明慢了；翻译后面带「…」表示有一截还在等，显示的是它已经等了多久。

## 记录与纪要

- 「保存记录」默认关。点字幕条上的「记录」按钮（或在设置页「记录与纪要」里打开）就立刻开始记（字幕条上已有的几句也会补进去），
  之后每次开始实时翻译都会记一份；关掉就把这一份收尾。
- 记录是 Markdown，写进会议库（菜单栏「会议 › 会议库」）：每句的时间、原文和译文，说完一句就写进去，中途退出也不丢。
  以前存在「文稿 › Baobox 实时翻译记录」里的旧记录已经按引用导入会议库，文件原地不动。
- 停止后用 AI 整理出**纪要**：要点、结论、待办，写在记录最前面，整理好会发通知。用哪个模型在「设置 → AI」里给「会议纪要」选，
  默认是本机的 Qwen3-1.7B（不联网）。选的模型还不能用（本地模型没下载、云端没配好）时只保存原文和译文。
- 字幕条上的「记录」按钮一点就开 / 关；旁边的小按钮打开本次记录（还没有就打开记录文件夹）；停止后在菜单栏「会议 › 会议库」里找到这次记录。
- 设置页「记录与纪要」里可以开关记录、关掉纪要。

## 速度与准确率

- **macOS 26 及以上**自动使用新一代本地识别引擎：出字更快、整段上下文不丢、准确率更高，声音不离开这台 Mac。
  首次使用会自动下载语音模型，字幕条上会提示「正在下载语音模型」。旧系统或下载失败时自动用旧引擎。
- **专有名词**：在设置里填上容易听错的人名、产品名、术语（逗号或换行分隔），识别会优先匹配这些词。

## 隐私

- macOS 26 上识别全程在本地。更早的系统上，设置里「优先本地识别」默认打开：本机有本地语音模型时，**声音不会离开这台 Mac**；
  没有时使用 Apple 的语音识别服务（与系统听写相同）。
- 翻译默认用系统自带的本地翻译（macOS 15+）或离线模型，不经过任何第三方服务；只有给「字幕翻译」（或「AI 纠错」）选了云端模型
  （「设置 → AI」的功能表，或本页的同一行），识别出来的每一句才会发给那个服务商。云端不可用时自动改用本地模型（已下载的话）。
- 记录默认不保存；打开「保存记录」后只存在这台 Mac 上（默认「文稿 › Baobox 实时翻译记录」）。

## 系统要求与常见问题

- **翻译需要 macOS 15 或更高版本**。macOS 14 上只显示原文字幕。
- 首次翻译时系统可能提示下载语言包；没弹出或下载失败时，到
  「系统设置 › 通用 › 语言与地区 › 翻译语言」里手动下载英语与中文。
- 首次开始会请求**语音识别**权限；被拒后到「系统设置 › 隐私与安全性 › 语音识别」打开。
- 提示「语音识别不可用」：确认「系统设置 › 键盘」里已打开**听写**；未安装本地模型时需要联网。
- 选了系统声音但没有屏幕录制权限：授权后需**重启 Baobox** 才生效（系统限制）。
