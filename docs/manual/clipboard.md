# 剪贴板

简体中文 · [English](en/clipboard.md)

菜单栏 → **剪贴板**。出厂快捷键 **⌘⇧V** 打开历史面板。

记录文本、图片、文件、链接四类内容，支持搜索、回填粘贴、收藏、格式识别与文本片段。
回填粘贴需要**辅助功能**权限（未授权时降级为仅复制）。

## 历史面板

**⌘⇧V** 唤出浮层面板，光标直接在搜索框里，**即输即搜**。

| 按键 | 动作 |
|---|---|
| 输入文字 | 实时过滤历史 |
| ↑ / ↓ | 在结果间移动 |
| ⏎ | 粘贴到刚才那个 App（**回填粘贴**） |
| ⌘⌫ | 删除选中条目 |
| esc | 关闭面板 |

面板顶部是类型筛选：**全部 / 文本 / 链接 / 图片 / 文件 / 收藏**。

底部工具条给出当前条目可用的动作：粘贴、纯文本粘贴、收藏、删除、展开（大窗编辑）、
预览等，并显示「N 条历史」。

### 回填粘贴

选中条目按 ⏎，Baobox 会把内容写入剪贴板并模拟 ⌘V 粘贴到你**刚才所在的 App**。

没有辅助功能权限时会提示一次：「已复制，但自动粘贴未开启」，并给出前往授权的按钮。
此时内容已经在剪贴板里，手动 ⌘V 即可。

图片条目的源文件如果被清理掉了，会提示「无法粘贴该条目」并建议删除该条记录。

### 纯文本粘贴

**⌘⌥V** 直接把最近一条以纯文本粘贴（丢掉富文本格式）；面板里也有对应按钮。

### 收藏

收藏的条目：

- 置顶在「收藏」筛选里
- **不受历史条数上限淘汰**
- **不受自动清理影响**
- **不会被「清空历史」删掉**

[文本片段](#文本片段)本质上就是你自己手写的收藏条目。

## 预览区与文本工具

选中一条时，面板右侧（或下方）是预览区，显示完整内容、来源 App、字符数。

打开「在预览区识别内容格式」后，Baobox 会**只对选中的这一条**跑格式识别，认出来就在
预览区给出对应的转换动作：

| 识别到 | 可用动作 |
|---|---|
| JSON | 格式化、压缩 |
| JWT | 解码、提取 Header、提取 Payload；过期会标「已过期」 |
| XML / HTML | 格式化 |
| 时间戳 | 秒 / 毫秒 / 微秒 / 纳秒 / Apple 绝对时间自动判别，给出本地时间、UTC、ISO 8601、相对时间 |
| URL | URL 编码 / 解码、提取 URL |
| Base64 | 编码 / 解码 |
| curl 命令 | 展开成多行 / 压缩成一行、拆出方法 / 认证 / 请求体 / 表单 / 其他参数 |
| 任意文本 | MD5 / SHA1 / SHA256、转义 / 去转义、**生成二维码**、钉住卡片、大窗编辑 |

动作都是**就地预览**，点「还原」回到原文。二维码超过容量上限（2900 字节）会提示。

**⌘⇧V 之外还有一个快捷键**：「最近一条生成二维码」（出厂不绑定），不开面板直接把最近
一条文本的二维码钉到屏幕上——手机扫一下就拿走了。

### 大窗编辑

预览区放不下时点「展开」，打开独立的编辑窗口：等宽字体、自带撤销、⌘F 查找条，
改完点「复制」。

### 钉住卡片

把一段文本钉在屏幕最上层（同截图贴图的思路，只是内容是文字），随时可复制或关闭。

## 文本片段

「设置 → 剪贴板 → 文本片段」。片段就是**你自己写的收藏条目**：不会过期，也不会被
「清空历史」删掉，在面板的「收藏」里和普通收藏混在一起——同一个搜索框、同样 ⏎ 粘贴。

新建片段可以填三样东西：**名称**（可选）、**内容**、**关键字**（可选）。

### 关键字展开

给片段设了关键字之后，打开「打字时展开关键字」，在**任何输入框**打
「触发前缀 + 关键字」（默认前缀可改），就会就地展开成片段内容。

需要辅助功能权限，**默认关闭**。

关于隐私，设置页里写得很清楚：关键字展开需要监听按键来匹配前缀，**内存里最多保留 32 个
字符，绝不落盘、绝不进历史**；忽略名单里的 App 不会展开；密码框等场景 macOS 本身就不会
把按键交给应用。

展开的实现是「片段写入剪贴板 + 模拟 ⌘V」，会顶掉你之前复制的内容，所以有一个开关：

- **展开后还原原本的剪贴板内容**（默认开）—— 展开完约半秒把剪贴板还原
- 关掉则片段内容留在剪贴板里，方便接着去别处 ⌘V

## 隐私

「设置 → 剪贴板 → 隐私」。

### 密码管理器的内容

被标记为 `org.nspasteboard.ConcealedType` 的内容（1Password / Bitwarden / 钥匙串复制出来的
密码）**默认不入库**。推荐保持关闭。

打开时会二次确认，并明确告诉你：历史文件在磁盘上是加密的，但条目**在面板里明文显示**
——任何能操作你这台已解锁 Mac 的人都看得到。再次关闭时会**删除已记录的全部敏感条目**。

### 临时内容

标记为 `org.nspasteboard.TransientType` 的内容**始终忽略**，没有开关——来源 App 明确要求
不要保存。

### 忽略的 App

把 App 加进忽略名单，它在前台时复制的内容不会被记录。

## 存储与加密

「设置 → 剪贴板 → 存储」。

- **历史条数上限** —— 超出时自动淘汰最旧的**未收藏**条目
- **历史自动清理** —— 1 天 / 7 天 / 30 天 / 90 天 / 永不。超时的未收藏条目自动清理，
  收藏始终保留
- **加密存储历史**（默认开）—— 文本与图片写入
  `~/Library/Application Support/Baobox/` 前用 **AES-GCM** 加密。密钥是随机 256-bit，
  存在**登录钥匙串**里，不离开这台 Mac、不同步 iCloud

切换加密开关时已有历史会自动转换格式。**关闭加密会二次确认**，因为已有历史（含图片）
会被明文重写回磁盘，之后任何能访问你这个用户账户的人都能直接读出来。

钥匙串不可用时（登录钥匙串未解锁）会提示「历史暂以明文写入」，解锁后重启 Baobox 生效。

## 清空历史

设置页里的「清空历史…」会二次确认。**收藏条目会保留**。
