# 手机互传

简体中文 · [English](en/phone-transfer.md)

菜单栏 → **手机互传** → 打开手机互传…。在 Mac 和手机之间互传文件和文字，**手机不用装 App**：
用相机扫窗口里的二维码，在浏览器里就能用。

## 两种模式

| | 局域网 | 公网 |
|---|---|---|
| 什么时候用 | 手机和 Mac 在同一个 Wi-Fi | 手机在别的网络（流量、别处的 Wi-Fi） |
| 速度 | 跑满 Wi-Fi | 取决于两边网络 |
| 加密 | 明文（同一 Wi-Fi 的人理论上能窃听） | 端到端加密 |
| 依赖 | 无，断网也能用 | 需要能上网；信令经公共服务中转（内容加密） |

窗口左上角切换模式，切换后二维码会变，需要重新扫。

## 用法

1. 打开窗口，手机相机扫码，在浏览器里打开网页。
2. Mac 窗口里出现「某某设备请求连接」，点 **允许**（只允许你认识的设备）。
3. **手机 → Mac**：手机网页上点「选择文件」或输入文字发送。文件存进接收文件夹（默认 `~/Downloads/Baobox`），
   窗口里能看到进度，传完可「在 Finder 中显示」。
4. **Mac → 手机**：把文件拖进窗口（或点「选择文件…」）、输入文字发送。局域网模式下手机网页会列出这些文件，
   点「下载」；公网模式下文件直接推到手机，点「保存」。

关闭窗口即结束会话：局域网服务停止、公网连接断开，原来的二维码失效。二维码 10 分钟没人扫也会过期，点一下刷新。

## 公网模式连不上怎么办

公网模式靠 UDP 打洞让两台设备直接连接，**不使用中继服务器**。两边的网络都很严格时（例如手机走运营商网络、
电脑在公司网络）可能打不通，窗口会显示两边的网络类型判断。这时可以：

- 让手机连上和电脑相同的 Wi-Fi，切回局域网模式；
- **电脑连上手机的个人热点**，再用局域网模式（一定可用）；
- 换个网络再试。

手机网页切到后台可能导致公网连接断开，传输时请保持在前台。

## 设置

| 设置项 | 说明 |
|---|---|
| 接收文件夹 | 默认 `~/Downloads/Baobox`，可改 |
| 收到文字时自动复制到剪贴板 | 默认关 |
| 手机页面地址 | 公网模式二维码打开的网页，默认是本项目 GitHub Pages 上的那份；自己部署了一份时才需要改 |

快捷键「打开手机互传」出厂不绑定，可在「设置 → 快捷键」里设置。

## 隐私

- 局域网模式：二维码里的随机令牌 + Mac 端确认，未经允许的设备什么都拿不到。
- 公网模式：会话 ID 和密钥只在二维码的 `#` 后面（浏览器不会把这部分发给任何服务器）。连接信息经
  ntfy.sh / 公共 MQTT 服务中转，全程用这个密钥加密，中转服务看不到内容，也无法冒充；文件走 WebRTC 加密通道，
  只在两台设备之间直传。
- 不保存传输历史，关窗后列表清空（收到的文件当然还在接收文件夹里）。
