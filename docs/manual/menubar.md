# 菜单栏

简体中文 · [English](en/menubar.md)

菜单栏 → **菜单栏**。菜单栏右上角的图标太多、被刘海挡住或被前台 App 的菜单挤掉时，用它整理：
在 Baobox 设置里给每个图标选「显示」或「隐藏」，隐藏的不占菜单栏，在 Baobox 菜单最上面一行点得到。

## 打开

「设置 → 菜单栏」里打开「启用菜单栏管理」。默认是关的：打开后菜单栏里会多一个**看不见**的占位项（你看不到它，
也不用碰它），Baobox 靠它把隐藏的图标推出屏幕。

需要两项权限，Baobox 的截图、窗口管理早就要过，一般已经有了：

| 权限 | 用来 |
|---|---|
| 屏幕录制 | 记下每个图标的样子，好在 Baobox 菜单里原样显示 |
| 辅助功能 | 认出每个图标是哪个 App 的；隐藏 / 显示时替你把图标挪过去；替你点开被藏的图标 |

## 显示 / 隐藏

设置页列出菜单栏上现有的每个图标：图标 + 名字 + 「显示 / 隐藏」。

- 选「隐藏」：这个图标马上从菜单栏消失，出现在 Baobox 菜单最上面一行。
- 选「显示」：回到菜单栏。
- 改的那一下 Baobox 会替你把那一个图标挪过去，鼠标指针会消失一瞬，别的图标不动。
- 选择会一直记着：App 退出再开、Mac 重启后照旧（位置是 macOS 自己记在各 App 里的）。
- 时间和控制中心图标系统不让挪，不列出来；Baobox 自己的图标也不列。
- **第一次出现的图标**（刚装的 App 第一次启动）系统会排到最左，会先落进隐藏区；想常显示就去设置里改成「显示」。

## Baobox 菜单最上面那一行

点菜单栏上的 Baobox 图标，菜单第一行（「截图」上面）就是：

- **隐藏的图标**；
- 一道细竖线后，**此刻被挤掉、被刘海挡住的图标**（设置里「被挤掉的图标也临时放进这一行」可关）。

图标和菜单栏上长得一样，鼠标停上去显示名字，点一下就跟点了菜单栏上的它一样，打开它的菜单。
点隐藏的图标时，Baobox 只把它一个临时挪到 Baobox 图标左边、点开它的菜单，你用完、菜单关掉后再挪回原处，别的隐藏图标不动、顺序也不变。
万一挪不动、或者 Baobox 旁边也放不下（前台 App 的菜单一直排到了 Baobox 跟前），宠物会提示，不会把别的隐藏图标带出来。
接了多块屏幕时，在哪块屏的菜单栏上点的 Baobox，图标的菜单就开在哪块屏上。

一个都没藏、也没被挤掉的时候，这一行不出现。

## Baobox 图标的位置

Baobox 图标默认排在最左边，所以菜单一多第一个被挤掉的就是它。**打开菜单栏管理时，Baobox 会自动把自己挪到电池、时间旁边，
并且始终保持看得见**：万一它落进隐藏区（比如你按住 ⌘ 把它拖了过去）或被挤掉，几秒内会自己挪回最右边 —— 它要是被藏了，
就没人能把别的图标放出来了。没打开菜单栏管理时，也可以用菜单「菜单栏 → 把 Baobox 图标放到最右边」手动挪。专注倒计时、会议录音指示这些 Baobox 自己的临时图标会出现在它右边。

另有快捷键「打开 Baobox 菜单」（出厂不绑，「设置 → 快捷键」里设）：Baobox 图标被挡住、或者在全屏 App 里菜单栏收着时，
在鼠标位置弹出 Baobox 菜单；接了多块屏幕时，开在鼠标所在那块屏的 Baobox 图标下面。

## 说明

- 关掉「启用菜单栏管理」后，隐藏的图标全部回到菜单栏。
- 某些 App 每次启动都不记图标位置，它的图标每次都会排到最左、进隐藏区，在 Baobox 菜单里照样点得到。
- 全屏 App 里菜单栏是收着的，这时认不出哪些被挤掉；图标的样子也只能在菜单栏露着时记下，从没露过面的图标先用 App 图标代替。
