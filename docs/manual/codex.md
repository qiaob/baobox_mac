# Codex 助手

简体中文 · [English](en/codex.md)

菜单栏 → **Codex 助手**。为本地 Codex CLI 做的助手，结构与 [Claude Code 助手](claude-code.md)
对齐，但**独立实现、互不影响**。

**数据全部来自 `~/.codex` 下的本地文件——不调用任何 AI API、不需要登录**
（例外同样是主动点「检查最新版」时会查 npm）。

没装 Codex 时（`~/.codex` 不存在）菜单里只有一行置灰提示。

## 菜单

| 区块 | 内容 |
|---|---|
| 状态行 | `N 个会话 · 今日 $X（估算）` |
| 额度 | `5 小时：已用 X ≈ $Y · Z 后重置`、`本周：已用 X ≈ $Y · Z 后重置` |
| 最近会话 | 点击即在终端 `codex resume <id>` 续接 |
| 快速续接… | Spotlight 式搜索面板 |
| 浏览会话 / 用量… | 打开中心窗口 |
| 用量报表… | 中心窗口的用量页 |
| 回合完成通知 | 通知开关 |

## 快速续接面板

快捷键出厂不绑定（避免与 Claude Code 的 ⌃⇧空格 撞车），可自设。

| 按键 | 动作 |
|---|---|
| 输入 | 按标题、项目或路径搜索 |
| ↑ / ↓ | 选择 |
| ⏎ | 在终端续接 |
| ⌘C | 复制续接命令 |
| esc | 关闭 |

## 中心窗口

两个标签页：

### 会话

搜索、续接、复制命令、删除。

### 用量

- **5 小时窗口**与**本周窗口**卡片，设了预算的话带进度条
- 按**天** / 按**项目** / 按**模型**三维报表
- 内置工具 / MCP 调用统计

费用来自内置定价表，均标「估算」。

### 用量是怎么算出来的

把 rollout JSONL 里的 Codex `token_count` 事件聚合成滚动 5 小时窗口与周窗口。

两种记账方式都能正确处理，**不会双计**：

- 增量型（`last_token_usage`）
- 累计型（`total_token_usage`）

周窗口默认按**近 168 小时滚动**估算，也可以改成**按固定星期 / 小时重置对齐**。

## 完成通知

「设置 → Codex 助手 → 回合完成通知」。

开启后 Baobox 会把 `notify` 钩子写进 `config.toml`，Codex 每个回合结束时调用它，
Baobox 收到就发系统通知（**含最后一条回复的摘要**）。可选提示音。

移除开关后 `config.toml` 里不留残余。

如果 `config.toml` 里的 `notify` 键是本应用无法安全编辑的形式，会明确提示「请手动管理」，
而不是强行改写。

### 额度预算提醒

- **5 小时预算**与**周额度预算**（k tokens）
- 达 **80%** 时提醒一次

## 配置可视化

「设置 → Codex 助手」把 `config.toml` 里三个最常动的键做成了控件：

| 设置 | 选项 |
|---|---|
| 审批策略 | 从不询问 / 按需（模型判断）/ 仅信任（可信命令外都询问） |
| 沙箱模式 | 只读 / 可写工作区 / **完全访问（危险）** |
| 默认模型 | 常用模型下拉，或直接输入 Codex 支持的任意模型名 |

「完全访问」会红字警告——Codex 可任意读写并访问网络。

**写入是安全的**：对 `config.toml` 做**行级 / 块级编辑**，保全注释与未知键，
每次写入前备份 `config.toml.baobox.bak`。遇到无法安全编辑的值会自动识别并**置灰对应控件**，
不会把你的配置改坏。

## 维护

- **磁盘占用**：`~/.codex/sessions` 占了多少、多少个会话
- **清理旧会话**：清理早于 N 天的 rollout JSONL，二次确认，完成后报告删除数量与释放空间
- **版本**：本机 `codex --version`，可检查 npm 上 `@openai/codex` 的最新版并复制升级命令

## MCP（只读）

列出 `config.toml` 中的 `[mcp_servers.*]`，可打开配置文件自行编辑。这里**只读不写**。
