# 窗口管理

菜单栏 → **窗口管理**。移动与缩放**前台窗口**：半屏、四分屏、最大化、居中、跨显示器移动、
恢复原始位置，共 13 个动作，全部可绑定快捷键。

需要**辅助功能**权限——它要去操作其他 App 的窗口。未授权时菜单里会显示一行
「需要辅助功能权限（点击开启）」，点它直接跳转系统设置。

所有键位都能在「设置 → 快捷键」里重录或清空。

## 多显示器

这块是重点，规则是明确的：

- **目标屏**取与当前窗口**交集面积最大**的那一块，不是鼠标所在屏
- 分屏基准是各屏的**可见区域**——自动避开菜单栏与 Dock，不会把窗口塞到菜单栏底下
- 跨屏移动按**相对位置与尺寸等比映射**，并做边界裁剪。不同分辨率、不同排列之间移动
  都不会变形或溢出

## 窗口间距

「设置 → 窗口管理 → 布局 → 窗口间距」：半屏、四分屏与最大化时在窗口四周及切分线处留出的
间距，单位 pt。设为 0 就是紧贴。

## 布局快照

把当前所有窗口的位置和大小存成一份布局，之后一键还原。适合「接上外接屏 / 回到工位」
这种反复发生的场景。

- **保存**：菜单 → 窗口管理 → 保存当前布局…，给它起个名字。
  会记录当前所有**常规、非最小化**窗口的位置与尺寸
- **恢复**：菜单里点对应的布局名
- **管理**：「设置 → 窗口管理 → 布局快照」里查看与删除，每条显示「N 个窗口 · 保存时间」

恢复的匹配规则：**标题优先匹配，顺序兜底**；当时开着但现在没运行的 App 自动跳过，
不会报错。

快照里每个窗口都记了**所属显示器的稳定 UUID 与屏内相对位置**，所以即便分辨率变了、
显示器排列换了，恢复时依然对得上。
