# 专注与健康（FocusHealth）· 需求

对应 issue #43。**专注计时（番茄钟）与健康提醒是同一个工具**：专注管工作段，提醒与休息管间歇段。提醒经桌面宠物（#44）呈现；**强提醒 = 宠物跑到屏幕中央变大、陪你休息**（2026-11-06 用户定），传统的全屏覆盖只在宠物关闭时作为回退。技术设计见 `TECH_DESIGN.md`。

## 1. 第一版范围（M1）

- 专注计时：开始 / 暂停 / 继续 / 提前结束（记为完成或作废），专注中勿扰，结束后衔接休息，满 N 轮或长专注接休息画面。
- 提醒项：预置四项，可增删改；两种计时（每隔 X 分钟 / 每天固定时刻），两种呈现（宠物提醒 / 休息画面）。
- 休息：三档强度——轻松只发宠物提醒；标准由宠物走到屏幕中央变大、变暗并拦截键鼠；严格再把背景模糊掉。
- 智能避让、自然休息、休息预告、撞车合并、重启接着计、菜单栏倒计时。
- **不在本版**：统计、语音提醒与提示音、浮动间隔、逐项强度、#42 会议状态接入。

## 2. 提醒项

| 字段 | 说明 |
|---|---|
| 名称 | 预置项没改过名时随界面语言显示 |
| 计时 | 每隔 X 分钟 / 每天 HH:mm |
| 计时口径（每隔类） | 按用电脑的时间（离开不计）/ 按实际时间 |
| 呈现 | 宠物提醒（气泡 + 按钮）/ 休息画面（强提醒，带时长） |
| 仅工作时间 | 工作时段与「仅工作日」在设置里统一配置 |
| 离开算完成 | 离开电脑够久就算做过了（自然休息） |

预置四项：

| 项 | 间隔 | 口径 | 呈现 | 离开算完成 |
|---|---|---|---|---|
| 喝水 | 45 分钟 | 实际时间 | 宠物提醒（宠物坐下喝水） | 否 |
| 站立活动 | 60 分钟 | 用电脑的时间 | 宠物提醒（宠物伸懒腰） | 是（离开 ≥ 5 分钟） |
| 护眼 20-20-20 | 20 分钟 | 用电脑的时间 | 休息画面 20 秒 | 是（离开 ≥ 2 分钟） |
| 整段休息 | 50 分钟 | 用电脑的时间 | 休息画面 5 分钟 | 是（离开 ≥ 5 分钟） |

「吃药」这类按钟点的提醒用「每天固定时刻」自己建（如 9:00、21:00 各一条）。

## 3. 计时规则

- **在电脑前** = 键鼠空闲不到 2 分钟，或别的程序正在阻止屏幕休眠（播视频、放幻灯片）。按用电脑的时间计时的项只在人在电脑前时累加。
- **自然休息**：人离开后回来，离开时长达到该项阈值的「离开算完成」项重新计时。阈值：休息画面项 = max(休息时长, 2 分钟)，宠物提醒项 = 5 分钟。看视频不算离开。
- **睡眠**：睡眠期间不计时，醒来后按睡眠时长套用自然休息。锁屏期间键鼠空闲照样增长，自然覆盖。
- **按实际时间的项**：到点时人不在电脑前，等人回来再提醒。
- **每天固定时刻**：当天到点后 4 小时内、人在电脑前时提醒一次；错过超过 4 小时当天不补。
- 到点但被挡住（专注、避让、人不在）时保持到点状态，能提醒时立刻提醒，不重复累计。

## 4. 宠物提醒与回应

- 卡片气泡（8 秒自动消失）：[好的][推迟 10 分钟]。**提醒一发出计时就重新开始**；没点、气泡自己消失 = 错过，不追着再提醒；推迟 = 10 分钟后再提醒一次。
- 同一时刻到点的几项合成一个气泡。
- 喝水时宠物坐下喝水，站立时宠物伸懒腰；当前形象没有这几段动画时只跳一下。
- 每天固定时刻的提醒用常驻气泡（必须点掉才消失）。
- 休息画面预告（标准 / 严格档）：到点前 1 分钟冒卡片「1 分钟后休息」[现在休息]，不能推迟。轻松档的休息提醒本身就是气泡，不预告。

## 5. 休息画面（强提醒）

流程：宠物从原位走到屏幕中央，边走边变大（约 1 秒）→ 背景变暗，宠物下方出现标题、倒计时与按钮 → 休息中宠物躺下（护眼时转头看远处）→ 倒计时走完，宠物起身伸懒腰，「休息好啦」→ 缩小走回原位。

三档强度（设置里选，默认「标准」；2026-11-06 用户调整）：

| 档 | 呈现 | 背景 | 拦截键鼠 | 推迟 5 分钟 | 跳过 |
|---|---|---|---|---|---|
| 轻松 | 宠物在原地冒气泡，不出休息画面 | 不变 | 否 | 可（每次休息最多 N 次，默认 2） | 不理它即可 |
| 标准 | 宠物走到屏幕中央变大 | 所有屏变暗 | 是 | 不可 | 长按 3 秒 |
| 严格 | 同标准 | 变暗 + 模糊 | 是 | 不可 | 长按 3 秒 |

- 轻松档的休息气泡：[好的] = 去休息了（算一次完整休息）；没点、气泡自己消失 = 错过。专注后的长休息也只是宠物提醒 + 菜单栏倒计时。
- 轻松档下手动「现在休息」：出不变暗、不拦截的休息画面（宠物照样走到中央陪你），点一下就能跳过。
- 点暗处想接着干活：宠物摇头，「还没休息完哦」。
- 多屏：宠物去鼠标所在的屏，其余屏只变暗（严格档也模糊）并显示小字倒计时。
- 宠物关闭或没就绪：标准档回退成传统画面——渐变色（3 款可选）或自选图片铺满，居中显示倒计时与按钮；严格档照样是模糊（不退成渐变，否则和标准档一样）；宠物提醒改成系统通知，按钮照样能点。
- 触发时正在按键或按着鼠标：等这一下结束（最多 15 秒）再出画面。
- 拦截是尽力而为：⌘Tab、⌘⌥Esc、调度中心等系统快捷键挡不住，也不去挡。

## 6. 专注

- 开始：菜单「开始专注」用默认时长，或选 25 / 50 / 90 分钟。
- 专注中：勿扰（宠物睡下，其他模块的非重要通知攒到结束再补），健康提醒顺延到专注结束，菜单栏显示剩余时间。
- 暂停：暂时退出勿扰，提醒照常；继续后接着计。
- 结束（到点，或提前「记为完成」）：轮次 +1。
  - 长专注（≥ 50 分钟）或满 N 轮（默认 4 轮）→ 休息画面（长休息，默认 15 分钟）；
  - 否则 → 卡片「专注完成，休息 5 分钟」[再来一轮][结束]，短休息在菜单栏倒计时。
- 专注期间顺延的提醒并进休息文案（「顺便：喝口水」），算已提醒。
- 休息结束：常驻气泡「休息好啦，开始下一轮？」[开始][结束]；设置里可改成自动开始下一轮。
- 作废：不计轮次，不接休息。
- 专注后的休息结束时，「离开算完成」的提醒项一并重新计时，不会刚休息完又被要求休息。
- App 关着期间专注已经过点超过 10 分钟：只记一轮，不再补休息。

## 7. 避让（顺延）

到点时满足任一条件就顺延，条件解除后再提醒：

- 开会：默认输入设备（麦克风）正在被使用；#42 会议上线后改用会议状态；
- 前台 App 全屏（演示、视频、游戏）；
- Baobox 正在录屏；
- 宠物「安静一下」中，或其他模块挂了勿扰；
- 本工具的「暂停提醒 1 小时 / 今天」。

另外：

- 顺延超过 45 分钟的休息画面项，解除后**降级为宠物提醒**「刚才一直在忙，起来活动一下吧」[好的][现在休息]，不再突然盖屏。
- 撞车：休息画面项到点时，若另一项更长的休息画面项 10 分钟内也要到点，当前项直接算完成；宠物提醒项与休息画面同时到点，并进休息画面的文案。
- 别的 App 的录屏 / 屏幕共享用公开 API 测不准，不检测；会议中麦克风通常在用，能覆盖大部分场景。

## 8. 菜单与入口

- Baobox 菜单「专注与健康」：状态行（专注剩余 / 下一个提醒）、开始专注 ▸、暂停 / 继续、提前结束 ▸、现在休息、暂停提醒 ▸。
- 专注或休息时菜单栏多一个倒计时项，点开是同一份菜单；空闲时不占菜单栏。
- 快捷键（出厂不绑定）：开始 / 暂停专注、现在休息。桌面宠物环形菜单外圈加「专注」。
- 设置页：总开关、专注、提醒项（增删改、恢复预置）、休息画面（强度、推迟次数、回退背景）、工作时间、预览（10 秒试看休息画面）。

## 9. 数据

`~/Library/Application Support/Baobox/FocusHealth/`：`items.json`（提醒项）、`state.json`（进行中的专注、今日轮次、各项计时进度、暂停状态）。App 重启后接着计，全部本地。
