# 会议（Meeting）· 需求

对应 issue #42，**一次做完，不分期**（2026-11-06 用户定）。技术设计见 `TECH_DESIGN.md`。

## 1. 定位

一个工具、三种会话。实时翻译在用户层面并入「会议」，退到引擎层与设置层（「字幕与同传」）。

| 会话 | 场景 | 音源 | 说话人 | 翻译 / 字幕 | 绑日历 |
|---|---|---|---|---|---|
| 线上会议 | Zoom / 腾讯会议 / 钉钉 / Meet / Teams / 飞书… | 麦克风 + 系统声音混成一路 | 标「我 / 对方」（按两路音量判，近似） | 默认关，可开 | 手动开始时若正有事件则自动绑定 |
| 线下会议 | 面对面 | 仅麦克风 | 不标 | 默认关，可开 | 可选 |
| 自由听译 | 看视频、播客、网课（即原实时翻译） | 沿用实时翻译设置 | 不标 | 沿用实时翻译设置（字幕条照常） | 否 |

- **同一时刻只有一个会话在采集**：会议记录、自由听译、听写（#45）共用一个「麦克风占用」登记（设备端语音识别同一时间只能跑一个请求）。记录中再点「自由听译」= 给当前会话打开字幕，不另开。
- 会议会话默认**只转录原文、不翻译、不出字幕条**；控制条上「字幕」开关打开后叠加字幕条与译文（同实时翻译）。

## 2. 会前

- **日历**：EventKit 读本机日历（含已同步的 Google / Outlook / 企业微信等账户），只读、数据不出本机。设置里多选要读的日历。
- **下一场会议**：菜单顶部显示「下一场：设计评审 · 25 分钟后」；可选在菜单栏常驻倒计时（默认关）。
- **会前提醒**：提前量 关 / 1 / 5 分钟（默认 1）。宠物常驻气泡：标题、时间、参会人前 3 位、来源（来自日历），有上次未完成行动项时加一行「上次会议有 2 项未完成」。按钮：[加入并记录]（有会议链接时，主按钮）或 [开始记录]、[看简报]（有简报时）、[忽略]。
- **一键入会**：从事件的 URL / 地点 / 备注里解析会议链接（Zoom、腾讯会议、钉钉、Google Meet、Teams、飞书、Webex），菜单「加入下一场会议」直接打开。
- **暂停会议提醒** ▸ 1 小时 / 今天 / 直到明天。
- **会前简报**：同系列（重复事件或同名）上一场的纪要摘要 + 该系列所有未完成行动项；菜单「会前简报」与提醒气泡都能打开。按钮：[加入会议][开始记录][打开上次纪要][关闭]。
- **设备自检**：设置里「试录 3 秒」，同时录麦克风与系统声音，显示两路电平并回放混音。
- **会议检测**：满足任一条件就问是否记录（宠物气泡 [开始记录][忽略][不再检测此 App]）：
  1. 日历事件已开始且带会议链接，且还没在记录；
  2. 会议 App（Zoom、腾讯会议、钉钉、Teams、飞书、Webex、FaceTime、微信、Slack）正在开会：它开会时才起的进程开着（钉钉的会议进程 —— 入会就静音也算），或按进程查出来是它在用麦克风（专门开会的 App 连续 2 秒、聊天 App 连续 10 秒；Baobox 自己用的不算）。说不清是谁在用麦克风（Safari 里的通话、FaceTime）时只算前台的会议 App。
  3. 浏览器里开的会：浏览器（Chrome、Safari、Edge、Arc、Firefox 等）在用麦克风，且窗口标题是会议网站（Google Meet、Teams、Zoom、腾讯会议、飞书会议、Webex、Jitsi 的网页版），连续 2 秒；这一轮用麦克风期间认出过一次就一直算（入会后切了标签页、标题变了也算），浏览器松开麦克风才重新认。
  - 问得及时：麦克风一被占用就马上去查是谁（参照 Notion），有人在用麦克风时每秒查一次，平时 5 秒一次 —— 进会两三秒就问到。
  - 放音乐、看视频不触发（不是会议 App 就不算）；浏览器在用麦克风不会算到常驻的 Slack、微信头上；同一个 App 的同一场只问一次（专门开会的 App、会议网站静音时也开着麦克风，松开 10 秒以上就算退会、下一场照样问；钉钉、飞书、微信这类聊天 App 静音时会松开麦克风，3 分钟内还算同一场），同时几个 App 在开会也只弹一个；忽略名单可在设置里管理。

## 3. 会中

- **开始记录**：菜单「开始线上会议记录 / 开始线下会议记录」、提醒 / 检测气泡、快捷键（出厂不绑定）。首次使用弹一次合规说明（告知义务在用户；只提醒，不代为通知）。
- **控制条**（不抢焦点的小浮条）：宠物开着时挂在**宠物头顶**，跟着宠物走（要挪就拖宠物）；宠物关着时置顶在屏幕顶部居中，可拖动、记住位置。内容：`● REC` + 时长 + 类型徽标 + 两路电平点（麦克风 / 系统声音：有声音亮，没声音变灰；**点一下单独不录这一路**（红色带斜杠），再点恢复，记录里记一行「麦克风静音 / 恢复」—— 只是 Baobox 不录，会议里别人照样听得到；线下会议只有麦克风那个）；按钮 [⏸ 暂停 / ▶ 继续][🔖 标记重点][✎ 速记][字幕][⏹ 结束]。速记展开一个内嵌编辑区，会后并入纪要上下文。
- **菜单栏录音指示**：记录中常驻「● 32:15」，点开是会议菜单。
- **会中勿扰**：记录中挂 `meeting` 勿扰令牌（宠物安静、非重要通知攒批、专注与健康的提醒顺延）。
- **会议超时**：超过日历预定结束时间 5 分钟，宠物轻提示一次。
- **字幕 / 同传**：控制条「字幕」开关 = 打开实时翻译字幕条（语言、朗读等沿用「字幕与同传」设置）；字幕条上的「记录」开关即当前会议会话的状态，两处同步。

## 4. 会后

- **结束** → 写完转录 → 本地模型生成纪要 → 宠物通知「纪要已生成」[打开]。
- **纪要模板**：自由听译出「内容摘要」；会议出「会议纪要」：摘要、决议、行动项（负责人 · 事项 · 截止）、重点（🔖 标记的段落加权）。会议模板可选：默认 / 站会 / 1:1 / 面试。模型没下载或内容太少时只存转录，状态标「仅转录」。
- **会议库**（窗口）：搜索（标题 / 参会人 / 纪要内容）、类型筛选（全部 / 线上 / 线下 / 自由）、「行动项」视图切换。列表行：标题、类型徽标、日期时间、时长、参会人、纪要状态（已生成 / 整理中 / 仅转录）。行操作（悬停与右键）：纪要、原文、复制纪要、重新生成、导出…、删除。详情：纪要、行动项（勾选完成、负责人）、按钮 [复制纪要][导出 Markdown][在文件夹中显示][重新生成纪要]。
- **行动项**（跨会议）：未完成 / 已完成分组；每行勾选框、内容、负责人、来源会议（可跳转）；[复制全部未完成][导出]。未完成项自动带进同系列下一场的会前简报。
- **系列时间线**：同系列会议按时间串起来，每场一行摘要，可点开。
- **会议周报**：菜单「生成本周周报」，汇总本周各会议的决议与未完成行动项（规则汇总 + 模型写一段概述），存进会议库并打开。

## 5. 菜单（Baobox 主菜单「会议」）

顶部状态行（空闲：「下一场：设计评审 · 25 分钟后」；记录中：「● 记录中 32:15 · 线上会议」）。菜单项：加入下一场会议（无链接置灰）、开始线上会议记录 / 结束并生成纪要、开始线下会议记录、开始自由听译（记录中 = 打开字幕）、会前简报（无简报置灰）、会议库、行动项（标题带未完成数）、生成本周周报、暂停会议提醒 ▸、设置…。

## 6. 设置「会议」

- 日历：读取的日历（多选）、会前提醒提前量（关 / 1 / 5 分钟）、菜单栏显示下一场倒计时。
- 检测：自动检测会议（开关）、忽略名单（App）。
- 记录：手动开始时的默认类型、命中日历会议时自动开始记录（默认关）、保留时长（默认长期）、纪要模板（默认 / 站会 / 1:1 / 面试）、设备自检（试录 3 秒）。
- 字幕与同传：原实时翻译的全部设置（整组平移，键名不变）。
- 快捷键（全部出厂不绑定）：加入会议 / 开始线上 / 开始线下 / 开始自由听译（沿用 `livetranslate.toggle`）/ 标记重点 / 打开速记。

## 7. 迁移

- 原实时翻译菜单保留一个版本，改名「字幕与同传」，第一行注明「已并入「会议」」，其余菜单项不变；设置 Tab 同理。下个版本删掉入口。
- 原有记录（`livetranslate.record.folder`，默认 `~/Documents/Baobox 实时翻译记录`）首次启动时按引用导入会议库，标为自由听译，文件原地不动、不丢历史；之后的新会话（含自由听译）都写进会议库。
- `livetranslate.*` 设置键全部保留兼容。

## 8. 数据

`~/Library/Application Support/Baobox/Meetings/`：每场一个目录（`meeting.md` 纪要 + 速记 + 转录，`meta.json` 元信息与行动项），根目录 `index.json` 索引，`weekly/` 周报。全部本地。

## 9. 边界

- 「我 / 对方」是按两路音量判的近似：外放时麦克风会收进对方声音，建议戴耳机；判不准的句子不标。
- 别的 App 的屏幕共享 / 录屏不检测（公开 API 测不准）。
- 浏览器里的会按窗口标题认会议网站：会议标签页不在前台（窗口标题不是它）时认不出来，会议网站换了标题格式也要跟着改；会议 App 静音入会、又没有专门的会议进程时，要等解除静音用了麦克风才问。
- 纪要质量受本地小模型（Qwen3-1.7B）限制；纪要、周报不提供云端模型（数据不出本机，issue #86 P0 维持）。
- 翻译（字幕开关打开后）沿用「字幕与同传」的翻译引擎：那里选了「云端服务」，会议里识别出来的每一句也会发给云端去翻译；
  只转录、不翻译时的 AI 纠错一律走本地（docs/ai-service/DESIGN.md §5.4）。
- 日历只走 EventKit，不直连 Google Calendar API。
