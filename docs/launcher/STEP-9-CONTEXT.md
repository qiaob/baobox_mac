# 第 9 步 · 刚呼出、还没打字时就给建议

> 2026-11-24 设计，2026-11-25 写成文档。分支 `feat/launcher-context`，worktree `~/cmb/worktrees/baobox-launcher-pr9`。
> 工作规则见同目录 `WORKFLOW.md`。完成后本文的内容并入 `REQUIREMENTS.md` §3.7 / `TECH_DESIGN.md`，本文件可删。

## 背景

用户的原则是「我放入任何东西，都能给我一些建议」。文字、路径、文件、图片放进去都有建议了，但都要先贴进来。这一步让它不用贴：

1. 呼出时自动带上**刚选中的文字**和**刚复制的内容**，回车放进输入框，后面的建议照常出。
2. 空着的时候按**当前情况**给建议：正在专注就给「暂停专注」，会议快开始就给「入会」，有 Claude Code 会话在等你就给「切过去」。

改动前空输入的行为：有使用记录就显示最常用的最多 8 行，没有就显示一行提示文字。

## 设计

### 1. 呼出时带上「选中的」和「刚复制的」

**选中的文字**

- `show()` 里、面板拿焦点之前（和 `LauncherFocus.capture()` 同一时刻），读呼出前那个 App 里选中的文字。
- 只走辅助功能，不用借剪贴板那条路（它要合成 ⌘C，呼出快速入口不该有这种副作用）。
- 这是 AX 调用，个别 App 响应慢：硬上限 80 ms，**不能拖慢面板出现**（放后台带时限，取到了再补上那一行）。**不许改进程级的 AX 超时**（不要对系统级元素调 `AXUIElementSetMessagingTimeout`，那会改掉本进程所有 AX 调用的默认超时）。
- 每次读的耗时和结果（取到 / 没有 / 超时 / 没权限）记进日志，只记字数不记内容。
- 没权限、读不到、选中的是空白：就没有这一行，不提示、不弹窗。
- 取词这一小块下沉到 `Core/SelectedTextReader.swift`，划词助手改成调它，行为不变。

**刚复制的**

- 剪贴板历史里最新的一条（文字或图片；`isConcealed` 的不算），并且是 5 分钟内复制的（常量）。
- 从快速入口每次呼出时已经取到的条目里拿（`clipboard` 来源里最新的那条，带 `date`），不直接读系统剪贴板。
- 文字要完整原文：`LauncherEntry` 带一个可选的「完整文字」取法（懒取的闭包，零 IO）。
- 和选中的文字相同（去空白后）时只出一行，留「选中的」。

**显示**

- 只在输入框为空、没有图片附件时，列表最前面出这两行（各最多一行，「选中的」在前）。
- 标题是内容的开头（压成一行、截断）。右侧小字：「选中的文字 · N 字」「刚复制 · 2 分钟前」。图片的行首是缩略图，标题「图片」。行首图标和普通剪贴板条目区分开。
- ⏎ 或 Tab = **放进输入框**：文字填进去（多行的走 `pastedText` 机制保住换行），于是建议照常出；图片挂成附件。放进去后这两行消失。
- 不记使用记录；⌘1–⌘9 照常算位置。
- 默认选中第一行（照统一的选中规则）。「选中文字 → 呼出 → ⏎ → ⏎」是有意的两步，不做成一步直达。

**开关**：设置键 `launcher.context.selection`、`launcher.context.clipboard`，都默认开；设置页各一行开关，一句话说明（「呼出时带上你选中的文字」「呼出时带上你刚复制的内容」）。

**隐私**：这两样只读进内存显示成一行，不发给任何模型、不联网、不写盘；收起面板就丢。

### 2. 空着时的情景建议

- 机制：各模块自己声明「此刻值得提一句的动作」，快速入口只收集和显示。`ToolModule.launcherContextSuggestions() -> [LauncherCommand]`，默认 `[]`。要求只读内存、零磁盘 IO、不阻塞；每次呼出时调一次。
- 要接的（状态能从内存拿到才做；拿不到或要读盘的先不做，回报里说明）：

| 情况 | 建议 | 模块 |
|---|---|---|
| 正在专注 | 暂停专注 / 结束专注 | FocusHealth |
| 防休眠开着 | 关闭防休眠 | Caffeinate |
| 正在录屏 | 停止录屏 | Screenshot |
| 会议记录进行中 | 结束会议 | Meeting |
| 下一场会议 10 分钟内开始，或已开始还没入会 | 入会 / 开始会议记录 | Meeting（日历没开就没有） |
| 有 Claude Code / Codex 会话在等你回复 | 切到那个会话 | ClaudeCode / AITools（有现成的「等待中」状态才做） |

- 能复用 `HotkeyDefinition` 的动作和 `stateTitle` 的就复用，不重写业务逻辑。
- 显示：排在「选中的 / 刚复制的」之后、最常用的行之前，最多 4 条；右侧小字写所属工具名。执行时记使用记录（和对应命令同一个键）。
- 最常用的行接在后面；空状态总行数不超过 9 行。同一条命令既是情景建议又在最常用里时只出一次（留在情景建议里）。
- 什么都没有时，照旧显示那一行提示文字。

### 3. 呼出延迟

改动前日志里 `panel shown in … ms` 热的时候是 30–45 ms，不能变差。把新增的耗时拆开记进同一条日志（选区读了多久、情景建议收集了多久）。

### 4. 不做

把上下文发给 AI；读屏幕；借剪贴板取词；⌘K；完整设置页（只加两行开关）；系统设置页 / 系统命令。不改已定的面板外观、按键行为、选中规则、焦点规则。
