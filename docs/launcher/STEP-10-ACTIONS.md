> 2026-11-24 设计，2026-11-25 写成文档。分支 `feat/launcher-more-actions`，worktree `~/cmb/worktrees/baobox-launcher-pr10`。
> 工作规则见同目录 `WORKFLOW.md`。完成后本文的内容并入 `REQUIREMENTS.md` §3.11 / `TECH_DESIGN.md` §5.4，本文件可删。

## 背景

快速入口的原则是「放进去任何东西都有建议」。文字的兜底建议已有：翻译、解释、总结、润色、学习（划词助手），存为片段、钉成贴卡、二维码（剪贴板），上网搜、搜文件名。图片已有：取字、翻译图里的文字、钉在屏幕上、预览、保存。它们都是各模块用 `launcherCommands()` 声明的「文字动作」「图片动作」（恰好一个必填 `.text` / `.image` 参数的 `LauncherCommand`），快速入口本身不认识具体模块。

这一步加七样：

1. 发到手机（手机互传）：文字、文件、图片。
2. 在终端里运行：贴进来的是一条命令时。
3. 交给 Claude Code 开一个新会话：贴进来的是报错或需求时。
4. 朗读。
5. 带时间的句子（「明天下午三点开会」「20 分钟后提醒我取快递」）：给「到时提醒我」。
6. 会议链接（Zoom / Google Meet / 腾讯会议…）：给「入会并开始会议记录」。
7. 文件夹：在终端打开、复制路径。文件：复制路径、发到手机。

某一条读完代码发现接不上或要动很多现有行为，就先不做那一条，回报里说明原因。

## 设计

### 1. 输入分类加两类（纯逻辑，测试要充分）

**像命令（`command`）**

- 单行。以 `$ ` 开头；或第一个词在一张常见命令表里（git、npm、npx、pnpm、yarn、brew、cd、ls、cat、curl、wget、ssh、scp、docker、kubectl、make、python、python3、pip、node、swift、xcodebuild、open、sudo、rm、mv、cp、mkdir、chmod、grep、find、tail、ps、kill、export）**且后面还有参数**。
- 要排除普通英文句子（`open the door`、`make it work`、`find my phone`）。规则：除 `$ ` 开头的以外，后面至少有一个词形如选项（`-x`、`--xx`）、路径（含 `/` 或 `.`）、赋值（`a=b`），或该命令的常见子命令（给 git、npm、docker、kubectl、brew 各列一小组：status、commit、push、pull、clone、install、run、build、ps、get、logs…）。
- 单独一个词不算。

**带时间的句子（`reminder`）**

- 能解析出一个将来的时间点 + 一段事由。
- 支持的说法：`N 分钟后 / N 小时后 / 半小时后 / 一刻钟后 …[提醒我] X`、`in 20 minutes …`、`明天 / 后天 / 今晚 / 今天 + 上午 / 下午 / 晚上 + 几点（几点半、15:30、3pm）+ X`、`周五 下午三点 X`。
- 结果是一个 `Date`（`now`、日历、时区作为参数传入，测试里写死）和事由文字（去掉时间那部分和「提醒我」）。
- 中文数字支持常见的（一二两三…十、半、一刻）。
- 已经过去的时间、解析不出来的、没有事由的都不算。

**和现有分类的关系**：路径 > 网址 > 邮箱 > 颜色仍然优先。「像命令」「带时间的句子」可以和单词 / 长文本 / 普通文字同时成立（多一个标记）。有计算结果时不算这两类。

### 2. 适用性判断（框架机制）

「某条动作只在特定输入下出现」现在靠 `LauncherSuggestionTraits.kinds`。会议链接这类条件光靠类别不够：给文字动作加一个可选的「对这段文字是否适用」的判断（闭包，纯内存、不阻塞），加在 `Core/Launcher/`，默认恒真，不影响现有声明。

### 3. 二次确认（通用机制）

把一段文字当命令执行、取消一条提醒，都要按两次回车。做成通用机制，任何 `destructive` 的行都适用（`LauncherCommand.destructive` 从第 1 步就有，一直没人实现）：

- 第一次 ⏎ 不执行，那一行的标题变成「再按一次回车<做什么>：<对象>」。对象太长就中间截断，开头和结尾都要看得到。
- 再按 ⏎ 才执行。
- 选中移开、输入改了、面板收起，就复位。
- ⌘1–⌘9 直接执行第 N 行时，对 destructive 的行同样只算第一次。

### 4. 各模块声明的新动作

**手机互传（`PhoneTransferTool`）**

- 文字动作「发到手机」；图片动作「把图片发到手机」；文件动作「把文件发到手机」（见第 5 节）。
- 有手机连着：直接发，回执一句（`NotifyCenter`，照防休眠回执的写法）。
- 没有手机连着：打开手机互传的窗口，回执「连上手机后再发一次」（现有代码支持「连上后自动发」就用它）。
- 档位：兜底建议里和「存为片段」并列。

**在终端里运行（快速入口自己提供，像「上网搜」一样）**

- 只在输入类别是「像命令」时出现，排在兜底组第一条。`$ ` 前缀去掉。
- 走 `TerminalLauncher.run(command:in: nil)`。
- 必须二次确认：「再按一次回车运行：<完整命令>」。

**交给 Claude Code（`ClaudeCodeTool`）**

- 在偏好终端里开一个新的 claude 会话，把这段文字作为第一条消息：`claude '<转义后的文字>'`，用 `Shell.quote`；多行文字保住换行。
- 目录：最近一次 Claude Code 会话所在的项目目录（从会话索引的内存缓存拿，零磁盘 IO），标题写成「交给 Claude Code（<项目名>）」。拿不到时用主目录，标题不写项目。
- 没安装 Claude Code 时不声明这条（约定 7：未安装即降级）。
- 长文本、多行文本时档位提前；普通文字时排在靠后。
- Codex 助手（`AIToolsTool`）启动方式同样简单的话加一条「交给 Codex」，否则不做。

**朗读（`SelectionTranslateTool`）**

- 按语种选嗓音（现有逻辑）。正在读时再触发一次 = 停止。档位靠后。

**提醒（快速入口自己提供）**

- 输入类别是「带时间的句子」时，最前面出一行（排在计算行那个位置）：「14:35 提醒我：取快递」。时刻写具体的，今天以外的带日期。右侧小字「提醒」。
- ⏎ = 设好提醒，回执「已设好：今天 14:35 提醒你取快递」。
- 到点：`NotifyCenter.shared.post` 一条 `alert` 级别的通知。
- 存储：`~/Library/Application Support/Baobox/Launcher/reminders.json`。启动时在后台读回；过期没响的补响一次并标明晚了多久；写盘失败走 `StorageWriteFailure.report`。
- 计时：一个到最近一条为止的计时器；系统睡眠唤醒后重新对表（监听唤醒通知）。
- 管理：输入「提醒」/「reminders」时，每条还没到点的提醒作为一行出现（标题「14:35 取快递」，右侧「提醒」）。⏎ = 取消，按两次。不做新窗口。

**会议链接（`MeetingTool`）**

- 文字动作「入会并开始会议记录」，只在 `MeetingLinkParser` 认得这段文字是会议链接时适用（用第 2 节的判断）。排在「打开网址」之后紧接着。
- 执行 = 复用会议模块现有的「一键入会 + 开始线上会议」。现有入口不好单独调用就不做这条。

### 5. 路径行的更多动作

在**完整存在的路径**（不是半截补全）的第一行后面、文件夹内容列表之前，接最多 3 条动作行：

- 文件夹：「在终端里打开」（`TerminalLauncher` 只开目录不跑命令）、「复制路径」。
- 文件：「复制路径」、「发到手机」。
- 「文件动作」的声明办法：把图片动作那套推广。给接受 `LauncherImage.file(URL)` 的命令加一个「也接受任意文件」的标记，或加一种「恰好一个必填文件参数」的命令，选改动小的。
- 文件搜索结果里的文件行（不是路径输入）不加这些。

### 6. 执行与安全

- 执行动作走现有的路径：收起面板 → `LauncherFocus` 等焦点回去 → 执行。不另起一套。
- 「在终端里运行」「交给 Claude Code」：文字一律用 `Shell.quote` 转义后再拼进命令。单元测试覆盖带单引号、反斜杠、换行、`$()`、反引号的输入。
- 分类、适用性判断、建议行的生成都是纯内存计算。

### 7. 隐私（写进 `REQUIREMENTS.md` §4）

这些动作里会把内容送出快速入口的：发到手机（传给自己的手机）；交给 Claude Code（把文字交给 claude 命令行）；上网搜（已有）。都只在用户选了那一行并回车之后发生。

### 8. 不做

AI 理解一句话；往日历里写日程；⌘K；完整设置页；系统设置页 / 系统命令；空输入时的建议（那是第 9 步）。不改已定的面板外观、按键行为（除了二次确认）、选中规则、焦点规则。

## 验证后定（2026-11-25）

独立验证没有严重问题，下面是设计者对 4 条中等、7 条低的决定（实现照这里，`TECH_DESIGN.md` 对应位置同步）。

### 中等

1. **按住 ⏎、双击会绕过「按两次」**。⏎ 和 ⌘1–⌘9 的自动重复（`NSEvent.isARepeat`）一律忽略，对所有行（按住 ⏎ 本来也不该连续执行）。鼠标：点一下上膛；上膛后 `NSEvent.doubleClickInterval` 之内的再一次点击不算确认（什么都不做）。键盘的两次分开的按键不设间隔。「这一下算不算确认」写成纯逻辑（传入上膛时刻、现在、来源是点击还是按键），有单元测试。
2. **确认时显示的必须是将要执行的全部内容。** 二次确认加一种「完整显示」，只给「在终端里运行」用：上膛后那一行的对象部分用等宽字换行完整显示，最多 6 行；别的要按两次的行（取消提醒）仍用中间截断。完整显示放不下 6 行的命令不出「在终端里运行」（太长的命令没法靠眼睛确认，用户自己贴进终端）。「放不放得下」按字符宽度算，纯逻辑，和视图用同一个每行宽度常量。行高随之变：面板高度、选中行滚到可见、第 9 行露一半都要对；渲染图看上膛 1 行、3 行、6 行，深浅各一遍。文字里有控制字符（去首尾空白后剩下的换行以外的 C0 控制符、NUL）、双向控制符（U+202A–202E、U+2066–2069）、零宽字符（U+200B–200F、U+FEFF）的不认成命令；交给 Claude Code / Codex 的文字去掉 NUL。
3. **「一点也不好玩」「两点之间直线最短」不是提醒。** 钟点是「中文数字 + 点」、而且句子里没有别的时间信号时不算提醒。别的时间信号：日子词（今天、明天、后天、今晚、周几）、时段词（上午、下午、晚上、凌晨、中午、早上、夜里）、「提醒我 / 叫我」、点后面紧跟「钟 / 半 / 一刻 / 三刻 / N 分 / 整」。阿拉伯数字的钟点（`3点开会`、`15:30`、`3pm`）不受限制。**取舍**：「三点开会」不再认（写「下午三点开会」或「3点开会」）—— 这一行排第一且默认选中，误判比漏判糟。「N 点多」（三点多）不算提醒。
4. **「晚上 / 今晚 / 夜里 + 1–5 点」是那一晚之后的凌晨**，即所指那天的次日那个钟点（「明天晚上一点」= 后天 01:00）。例外：没有日子词（或写的是今天 / 今晚）而且现在还没到今天的那个钟点（00:30 说「晚上1点」）→ 今天那个钟点。和「晚上12点 = 次日 0 点」一致。测试覆盖 00:30、10:00、23:50 三个「现在」。

### 低

5. **文字恰好是子命令名**（`codex 'logout'`、`claude 'update'`）：不依赖 `--`。文字去首尾空白后是单个 ASCII 词（只有字母、数字、`-`、`_`）时不出「交给 Claude Code」「交给 Codex」。以 `-` 开头前面加 `--` 的做法保留。
6. **目录**：「在终端里运行」显式在主目录跑。交给 Claude Code / Codex 时项目目录不存在：脚本里落到主目录再跑（`cd <目录> 2>/dev/null || cd ~`），不在主线程查盘。PATH 和非交互 shell 是 `TerminalLauncher` 的老问题，写进「已知限制」，这一步不改。
7. **发到手机的临时图片**：手机互传模块 `activate()` 时在后台清空 `$TMPDIR/Baobox-PhoneTransfer/`，`willTerminate()` 时也清一次；发送过程中不删。
8. **「像命令」的误判和漏判**：`$ ` 后面第一个词要像命令名（以字母、`_`、`.`、`/`、`~` 开头，只含字母数字和 `_ . + - /`）；以 `.` 结尾的词不算路径证据（`U.S.`、`e.g.`）；没有选项形状的词时，只要有一个不在引号里的词（含 `/` 的拆开看）是英文虚词（the、a、an、and、or、is、are、was、be、to、of、on、in、for、with、my、your、you、i、it、this、that、me、we、not、sure）就不算命令 —— 子命令位置上、是该命令列出的子命令的那个词不查（`npm i lodash` 仍算）。补漏判：`make` 加常见目标（build、install、test、clean、all、run、dev、lint）；`ssh` / `scp` 后面有含 `@` 的词算证据。`echo hello`、`ssh host` 不补。验证者列的误判、漏判例子都进测试；现有正例不许变。
9. **提醒事由切错**：时间后面紧跟「前 / 之前 / 以前」→ 照那个时刻提醒，事由去掉这个词（「下午3点前交报告」→ 15:00「交报告」）。时间段（「3点到5点开会」「3点-5点」「3点至5点」）→ 按开始时刻，事由去掉后一个时刻和连接词（→「开会」）。「明天6点起床」按 18:00 是现有规则，不改（行上写着具体时刻）。
10. **取消一条已经响过的提醒**：回执「这条提醒已经响过了」。
11. **`launcherCommands()` 每次呼出被调 4 次**：Claude / Codex 模块已有内存里的「是否安装」状态就用，没有就不动（不强求）。
