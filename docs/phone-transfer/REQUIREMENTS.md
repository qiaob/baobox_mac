# 手机互传 —— 需求

## 1. 目标

Mac 和手机之间互传文件和文字。手机**不装 App**：用相机扫 Mac 上的二维码，在浏览器里打开网页就能用。

两种模式：

| | 局域网模式（默认） | 公网模式 |
|---|---|---|
| 适用 | 手机和 Mac 在同一个 Wi-Fi | 不在同一个网络（手机走流量、在别处） |
| 手机网页从哪来 | Mac 自己开的 HTTP 服务 | GitHub Pages（本仓库的静态页） |
| 传输 | 纯 HTTP（上传 / 下载） | WebRTC DataChannel（P2P，UDP 打洞） |
| 外部依赖 | 无，断网也能用 | 公共信令（ntfy.sh、EMQX / HiveMQ 公共 MQTT）+ 公共 STUN |
| 中继 | — | **不做**。两边 NAT 都打不通时明确提示原因和替代办法 |

## 2. 用户故事

1. 菜单栏 → 手机互传 → 打开窗口，默认显示局域网二维码。
2. 手机扫码打开网页，Mac 窗口里出现「某某设备请求连接 [拒绝] [允许]」，点允许后连上。
3. 手机点类型按钮选文件发给 Mac（「图片」直接进相册，其他类型只列出对应的文件，都可多选）：存进接收文件夹（默认 `~/Downloads/Baobox`），
   窗口里显示进度，传完可「在 Finder 中显示」。收到的是图片时，列表里显示缩略图，点开预览，一键复制到剪贴板。
4. Mac 拖文件进窗口（或点「选择文件…」）：手机网页上出现这个文件，点一下下载；是图片时点「查看」看大图，长按存进相册。
5. 手机发一段文字：Mac 窗口里显示，可一键复制（设置里可选自动复制到剪贴板）。Mac 也可以发文字给手机。
6. 不在同一网络：切到「公网」，扫新的二维码，流程同上。连接成功后显示连接方式（局域网直连 / 公网直连）。
7. 公网连不上：约 20 秒内给出失败原因（例如「手机网络是对称型 NAT」「UDP 被拦截」）和办法：连同一个 Wi-Fi、电脑连手机热点、换网络。

## 3. 功能要求

### 3.1 会话

- 二维码只对当前窗口有效：关窗即结束会话（局域网停掉 HTTP 服务，公网断开 P2P），下次打开换新的令牌 / 密钥。
- 每个新设备都要在 Mac 上点「允许」；拒绝后该设备在本次会话内不能再请求。
- 局域网模式可以同时连多部手机；公网模式一次连一部（再连要点「新会话」重新生成二维码）。

### 3.2 安全

- 局域网：URL 里带 128 位随机令牌，没有令牌的 API 请求一律 403；还要 Mac 端点允许。局域网内是明文 HTTP，界面上标注「同一 Wi-Fi 下的其他人理论上可以窃听，在公共 Wi-Fi 上建议用公网模式」。
- 公网：二维码 `#` 后面带会话 ID 和 256 位密钥（`#` 后的内容浏览器不发给任何服务器）。信令消息用 AES-GCM 加密并认证，公共信令服务看不到内容，也伪造不了 SDP；文件走 WebRTC 的 DTLS 端到端加密，不经过任何服务器。
- 局域网服务默认只在一块网卡上监听：「自动」= 默认路由那块（通常是 Wi-Fi）。窗口里可以换成别的网卡
  （有线、互联网共享的网桥、Tailscale 这类 VPN），或选「所有网卡」不限制；选择会记住。没选中的网卡、IPv6 上不接受连接。
- 二维码 10 分钟没人扫就过期，点「刷新」重新生成。

### 3.3 文件类型与图片

- 手机网页「发送到电脑」是一组类型按钮，点哪个就直接打开那种类型的选择器（九种类型 3×3，「全部文件」占满一行）。
  筛选由手机系统的选择器做：安卓只列出匹配的文件，iPhone「文件」App 里不匹配的置灰。

  | 按钮 | 包含 |
  |---|---|
  | 图片 | `image/*`（打开系统相册 / 照片选择器） |
  | 视频 | `video/*` |
  | 音乐 | `audio/*` |
  | PDF | .pdf |
  | Word | .doc / .docx，WPS 的 .wps |
  | Excel | .xls / .xlsx / .csv，WPS 的 .et |
  | PPT | .ppt / .pptx，WPS 的 .dps |
  | 文本 | .txt |
  | 压缩包 | .zip / .rar / .7z |
  | 全部文件 | 不限 |
- 手机网页上**不显示缩略图**。
- Mac 窗口：图片（能解码的 jpg / png / heic / gif / webp 等）行首显示缩略图（按 EXIF 方向转正）。
  点缩略图在窗口里预览大图，预览里可复制、用「预览」打开、在 Finder 中显示；行上有「复制」。
  收到的和发出的图片都这样，其他文件保持原样。
- 复制图片：写 PNG + TIFF（和截图一样），粘到聊天软件里是图片，不是文件。
- 手机收到图片：按钮是「查看」，点开在页面里看大图并提示「长按图片可存到相册」（iPhone 点「下载」只能存到「文件」App）。
  浏览器显示不了的格式（例如安卓上的 HEIC）提示改用下载。

### 3.4 传输时间

- 每条记录显示时刻，传完的再显示用时：`2.4 MB · 已接收 · 17:30:12 · 用时 1.2 秒`。文字只显示时刻。
- Mac 发给手机（局域网）：没下载时显示共享的时刻；下载过显示最近一次下载的时刻和用时，以及下载次数。
- 手机收到的局域网文件由浏览器自己下载，量不到用时，只显示时刻。

### 3.5 不做

- 中继（TURN）、断点续传、文件夹整体传输（可以多选文件）、传输历史持久化、手机原生 App。

## 4. 设置

| 项 | 默认 |
|---|---|
| 接收文件夹 | `~/Downloads/Baobox` |
| 收到文字自动复制到剪贴板 | 关 |
| 公网模式的手机页面地址（高级，fork 仓库自己部署 Pages 时改） | `https://qiaob.github.io/baobox_mac/transfer/` |

快捷键「打开手机互传」，出厂不绑定。
