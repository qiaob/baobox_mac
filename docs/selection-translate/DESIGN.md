# 划词助手（SelectionTranslate）设计

> 2026-11-09 起模块改名「划词助手」：选中后先弹动作条（翻译 · 学习 · 润色 · 改写 · 地道英文 · 解释 · 总结 · 自定义），
> 见同目录 `ASSISTANT.md`。本文仍是取词、触发、翻译、浮层这些底层的设计。

## 1. 需求

在**任何 App**里选中一段文字（英文或中文，单词、句子、整段都行），
就在选区旁弹出浮层：英 → 中 / 中 → 英翻译 + 朗读原文 / 朗读译文，
省掉「复制 → 切到浏览器 Google 翻译 → 看完 → 再复制回来」的来回。

仅 macOS（本模块只有 Mac 实现）。

## 2. 取词：按可靠性排序

| 路径 | 覆盖 | 代价 |
|---|---|---|
| **AX 读选中文字**（默认） | 原生 App、浏览器网页、Google Docs 大多数情况 | 需要辅助功能权限 |
| **借剪贴板：按 App 自己的「拷贝」菜单项**（AX 读不到时） | 很多终端（Otty 等 Metal 自绘的）、部分 Electron / 自绘界面、Docs 个别状态 | 短暂改动剪贴板（读完立即还原）；Baobox 剪贴板历史不记 |
| **借剪贴板：合成 ⌘C**（仅手动触发，且菜单栏里找不到「拷贝」时） | 菜单栏读不到的 App | 同上；没有选区时可能响提示音 |
| **框选 OCR**（手动） | **根本不能选中**的文字：图片、扫描版 PDF、视频画面、游戏 | 框选一次；复用 Core 的 `TextRecognizer`（Vision 本地识别） |

### 2.1 借剪贴板（2026-11-05 起自动弹出也用）

起因：在终端 Otty 里选中文字不弹浮层 —— 它用 Metal 自绘文字，辅助功能拿不到选区，而自动弹出原先只走 AX。
现在 AX 读不到时，自动弹出在**同时满足**下面几条时借剪贴板（设置「辅助功能读不到选区时，借用剪贴板取词」，默认开）：

- 手势像在选文字：按下到抬起拖动 ≥ 5pt，或双击选词 / 三击选行。普通单击不借。
- 前台 App 菜单栏里有快捷键为 ⌘C 的菜单项且没置灰 —— 按快捷键认，不认标题（标题随系统语言变）。
  「拷贝」置灰 = 没有选区，这时不碰剪贴板。先用 AX 按这一项（`AXPress`）；剪贴板约 0.3 秒没动静再合成一次 ⌘C ——
  实测 Otty 的「拷贝」菜单项被按下并不拷（拷贝选区走的是视图自己的快捷键处理），只认真按键。哪个 App 要按键
  本次运行内记住，之后直接按 ⌘C。找不到菜单项时自动弹出不借（没有选区的信号，按键会响提示音）。
- 剪贴板里当前不是密码（`org.nspasteboard.ConcealedType`）：借用会改 changeCount，密码管理器的
  「N 秒后自动清除」会据此以为用户复制了别的而不再清除。
- 只收一段文字：带文件（Finder 选文件）或图片（设计软件拖图层）的当没取到，并且本次运行内
  不再对这个 App 自动借剪贴板。
- 同一段文字不重复弹，直到一次普通单击 —— 终端里选区会一直留着，之后拖窗口还会把它再拷出来一次。
- **先看 App 自己有没有复制**：按下鼠标时记下剪贴板 changeCount，抬起后（最多再等 ~0.25s）它变了、且不是 Baobox
  自己借用 / 还原的那次 → App 已经把选区拷进了剪贴板（终端的「选中即复制」、TUI 自己用 OSC 52 复制），直接用这段文字，
  不再借剪贴板。实测在 Otty 里的 Claude Code 界面中选字：鼠标被 TUI 接管，Otty 自己没有选区，按「拷贝」/ ⌘C 都拷不到。

快捷键：两个手动触发（翻译选中文字、框选 OCR）出厂不绑定，设置页「快捷键」分组里可直接录（与「快捷键」页同一份存储）。

借用本身在 Core `PasteboardBorrow`：快照原内容 → 让 App 拷贝 → 最多等 ~0.35s → 读文字 → 剪贴板变过才还原
（没变就不碰）。剪贴板历史在借用期间不入库、还原后的那次变更整体跳过；借用前先补一次轮询，用户刚复制、
还没轮到的那条照常入库。手动触发同样先按菜单项，找不到菜单项才合成 ⌘C，且带图片的文字也收
（Office 拷文字会顺带一张图）。

## 3. 触发

- **选中后自动弹出**（设置开关，默认开）：CGEventTap（listen-only）监听全局
  左键按下 / 抬起，抬起后等 ~0.4 秒查 AX 选区（2026-11-09 由 120ms 改长：这段时间里按了键 / 剪贴板变了就不弹，见 `ASSISTANT.md` §1.2）；有非空选区且与上次不同才弹；
  AX 读不到时按 §2.1 借剪贴板。点在浮层自身、或前台是 Baobox 时忽略。
  无辅助功能权限时 tap 建不起来，静默降级为手动触发。
- **全局快捷键**（出厂不绑定，仓库惯例）：菜单 / 快捷键页触发，走 AX，
  读不到时按设置借剪贴板（§2.1）。
- **框选 OCR**：菜单 / 快捷键触发。冻结鼠标所在屏（与截图覆盖层同款
  `CGWindowListCreateImage` 底图），拖出矩形 → 按图像自身像素密度裁剪
  （不假设 backingScaleFactor，见 PR #32 的教训）→ Vision 识别 → 走翻译浮层。

## 4. 翻译与朗读

> 2026-11 起语种检测、目标语言、翻译引擎都走共享层，详见 `docs/translation-engine/DESIGN.md`。

- 语种判定：`LanguageDetector`（本地 `NLLanguageRecognizer`，21 种语言，偏向目标 / 备选语言，按文字系统兜底）。
- 目标语言：设置「译成」+「原文已是该语言时译成」；浮层方向行的目标语言可点开当场切换、重新翻译。
- 翻译：macOS 15+ 默认系统 Translation 框架（会话挂在浮层视图的 `.translationTask` 上）；系统不支持
  或失败时（「自动」引擎）改用离线模型 Hy-MT2；macOS 14 直接用离线模型，没下载时浮层里给下载入口，
  下完自动开翻。
- 朗读：`AVSpeechSynthesizer`，按语种选嗓音（没装该语言嗓音则用系统默认）；浮层关闭即停。

## 5. 浮层

不抢焦点的 NSPanel（`.nonactivatingPanel` + `canBecomeKey = false`），
跨 Space、全屏 App 上可见；优先贴在选区下方，放不下翻到上方，
始终夹在当前屏 visibleFrame 内。内容：方向（English → 中文）、原文
（可选中复制）、译文、按钮行（朗读原文 / 朗读译文 / 复制译文 / 关闭）。
Esc、点击浮层外任意处关闭。

高度跟内容走（2026-11-05）：原文 / 译文区内容多高就多高，各自超过上限（原文 150pt、译文 230pt）才收进等高的滚动框 —— 是否超高按同字体 NSString 排版量出，避免 ScrollView 只给 maxHeight 时被压成一两行、半行被切。整个内容的理想高度回报给面板控制器，译文到了 / 换目标语言后窗口跟着改高；没被拖过就按选区重新摆放，拖过则上沿不动往下长。

## 6. 设置（UserDefaults 键，前缀 `selectiontranslate.`）

- `autoPopup`：选中后自动弹出（默认开）
- `copyFallback`：AX 读不到选区时借剪贴板取词（自动弹出与快捷键都用，条件见 §2.1；默认开）
- `autoSpeak`：翻译完成后自动朗读译文（默认关）
- `target`：译成什么语言（默认系统首选语言）
- `secondaryTarget`：原文已是目标语言时译成什么（默认 English；目标是英文时默认中文）
- 引擎选择是两个翻译模块共用的 `translation.engine`

## 7. 文件

```
mac/Sources/Modules/SelectionTranslate/
  SelectionTranslateTool.swift        模块壳（菜单 / 快捷键 / 设置页）
  SelectionTranslateController.swift  状态机：触发、事件 tap、TTS、面板调度
  SelectionText.swift                 AX 取词 + 借剪贴板（「拷贝」菜单项 / 合成 ⌘C）
mac/Sources/Core/PasteboardBorrow.swift  借剪贴板：快照 → 拷贝 → 读 → 还原，剪贴板历史据此跳过
  SelectionTranslatePanel.swift       浮层窗口与 SwiftUI 内容（含翻译会话）
  RegionTextPicker.swift              冻结屏框选 → OCR
  SelectionTranslateSettingsView.swift 设置页
```

权限：辅助功能（取词 + 事件 tap，与键盘点击 / 窗口管理共用一份授权）；
框选 OCR 另需屏幕录制。无新第三方依赖。
