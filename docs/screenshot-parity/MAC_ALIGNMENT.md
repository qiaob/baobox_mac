# 截图 UI 对齐标准（以 macOS 实现为准）

> **这份文档是 Windows / Linux 截图 UI 的对齐依据。** 所有值都提取自 macOS 端
> 当前实现（出处为文件:行号，提取日 2026-08-08），设计稿 `docs/design/ui-design-v1.html`
> 与实现不一致之处**以实现为准**（差异清单见 §7）。改 UI 之前先读这一页；
> 改完把 §8 的核对表勾上。

主要出处：
- `mac/Sources/Modules/Screenshot/CaptureOverlayView.swift`（选区 + 标注同一视图）
- `mac/Sources/Modules/Screenshot/AnnotationToolbar.swift`（工具条）
- `mac/Sources/Modules/Screenshot/Annotation.swift`（绘制参数）

## 0. 阶段状态机

mac 是四相：`hovering →（拖拽 >4pt）dragging →（松手且 ≥3×3）adjusting →（点工具条上的工具）annotating`。

- **松手即出工具条**，选区保持可拖动、可拉八向手柄（CaptureOverlayView:360-375）。
- **进入标注后选区锁定**：不再能移动/缩放，手柄消失（:254-282, :583-607）。
- 单击窗口（hovering 相）→ 转成 `adjusting` 的普通选区，**不是**立即截图（:875-884）。
- mac 无独立编辑器窗口：标注在同一 overlay 原地进行，进入时冻结选区底图（:839-868）。
- mac 坐标系原点在左下（y 向上）；Windows/Linux 要整体翻 y。

### 2.6 摆放算法（:234-252）

基准 `screen.frame`，gap/margin = 8：
1. 水平 `x = selection.right - width`，clamp 进 `[screen+8, screen.right-8-width]`；
2. 首选选区**下方** 8pt → 放不下翻**上方** 8pt → 再不行压进选区内部顶端（含 8pt 内边距）；
3. 选区拖动/拉手柄/方向键/切工具（参数行改变高度）时**实时重摆**。

## 3. 标注阶段

- 进入方式**只有**点工具条上的工具按钮（无默认工具、无 ⌘⏎）。
- 工具条同一条，只是参数行按工具显隐。
- 图像四周仅 1.5pt 白边框，外部仍 45% 压暗；无内边距/底色/阴影。
- 各工具绘制参数（Annotation.swift）：箭头头长 `max(10, lw*3.5)`；荧光笔 = lineWidth×4、
  色 alpha 0.35；马赛克笔刷 `max(16, lw*7)`、CIPixellate scale `max(8, min(w,h)/45)`；
  文字 = bold system font；橡皮整笔删除、容差 8pt；矩形/椭圆最小 3×3、箭头最短 6。
- 键盘：⏎ 复制并完成 · ⌥⏎ 保存 · esc 取消 · ⌘Z/⇧⌘Z 撤销重做。

### 内联文字输入框（:1015-1045，phase 2）

无边衬 NSTextField，layer 边框 1pt `white 0.45`，初始 60 宽、高 = fontSize+8，
以点击点垂直居中；随输入自增宽；Enter 提交 / Esc 取消 / 失焦提交。

## 6. 平台差异的既定取舍

- Windows/Linux 用**冻结底图**代替 mac 的实时透出（分层窗口命中测试的限制，见
  `windows/baobox-windows/src/overlay.rs` 模块注释）。视觉上等价：选区内亮、外 45% 暗。
- Windows/Linux 的标注在独立窗口进行（覆盖同一屏幕位置），mac 原地标注。工具栏
  由同一份 `Toolbar::layout` 摆位，两阶段位置连续。
- 图标：mac 用 SF Symbols；Windows/Linux 用 `baobox-render` 矢量图元近似（§2.2 的
  Symbol 名是形状依据）。

## 7. 设计稿 vs 实现（以实现为准）

设计稿 v1 中以下内容与 mac 实现不符，**不要照抄设计稿**：浅色工具条（实现是深色）、
选中态背景块（实现是图标染色）、5 色盘（实现 7 色）、默认工具箭头（实现无默认工具）、
6 工具（实现 8 个）、手柄 8pt 带描边圆角（实现 6pt 纯白）、选区青色渐变填充（实现全透）、
adjusting 态提示条（实现已刻意移除）、圆形放大镜（实现圆角矩形）。
