解密 HTTPS

设备信任了 Baobox 的证书，它的 HTTPS 才解得开。关掉这个开关，所有 HTTPS 都原样放行。

范围
全部域名，除了下面这些只解密下面这些
这些域名不解密（每行一个）
apple.com icloud.com mzstatic.com

范围之外的域名原样放行、不解密。域名按后缀匹配：填 x.com 也包括 api.x.com。手机不信任证书的域名会自动放行，不用填进来。改了立即生效。

  • 「解密 HTTPS」那一行的小字说明当前范围：「全部域名」「不解密 3 个域名」「只解密 2 个域名」。
  • 两个名单各自保留：切到「只解密下面这些」显示另一份名单，切回来原来那份还在（和现在一样）。
