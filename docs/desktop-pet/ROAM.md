# 桌面宠物 · 活动范围与窗口互动

> 用户需求（2026-11-06）：「活动范围支持定义」「最好能和桌面的应用有一些交互，比如趴在应用窗口上」。
> 现状：`PetEngine` 只在水平方向溜达（`origin.x` 来回走，高度停在用户放下的位置），走动范围 = 当前屏幕可见区的宽度。

## 1. 活动范围

设置 → 桌面宠物 → 新增「活动范围」：

| 选项 | 行为 |
|---|---|
| 当前屏幕（默认，即现在的行为） | 在当前高度左右溜达，不出屏 |
| 屏幕底边 | 一直站在屏幕可见区底边（Dock 上沿）溜达；被拖到半空松手会「掉」下来 |
| 自定义区域 | 在屏幕上框选一块矩形（复用截图的框选界面），只在这块区域的底边溜达；拖出去松手会走回来 |
| 窗口上（见 §2） | 除了地面，还会跳到别的 App 窗口的顶边上走、趴着 |

「不走动」沿用现有的「溜达」开关。

## 2. 和窗口互动（Shimeji 那种）

### 2.1 看得到哪些窗口

- 每 0.5 秒取一次屏幕上的窗口列表（`CGWindowListCopyWindowInfo`，只要位置和层级，不读窗口内容 / 标题），
  只认普通 App 窗口（layer 0、够大、不是 Baobox 自己的、不是全屏）。
- 一个窗口的顶边哪一段没被它前面的窗口挡住，才算能站的「台面」。

### 2.2 宠物会做什么

| 行为 | 说明 |
|---|---|
| 跳上窗口 | 溜达时偶尔挑一个附近的窗口顶边，蹲下 → 跳上去（抛物线）→ 落稳 |
| 在窗口顶边走 | 只在没被挡住的那段上来回走，走到头转身或跳下来 |
| **趴在窗口上** | 肚子贴着标题栏趴下、双手托腮、小腿在身后一翘一翘；趴一会儿再起来 |
| 窗口被拖动 | 跟着窗口一起移动（站稳不掉） |
| 窗口关了 / 最小化 / 被别的窗口挡住 | 掉下来：手脚乱挥 → 落地缓冲 → 拍拍裙子 |
| 用户把宠物拖到窗口顶边附近松手 | 吸附到那条边上（站上去） |

- VRM 新加的片段：`jump_up`、`fall`、`land`、`lie_prone`（趴、托腮、晃小腿，循环）。
  趴的姿势身体横过来、脸朝屏幕外，裙子在身体后面，不会走光。
- 毛绒动物也能上窗口：用它们已有的跳 / 坐 / 躺片段。2D 帧图形象只在地面走。

### 2.3 需要的改动

- `PetEngine`：从「只有水平位置」改成「站在某个台面上」（地面 / 某个窗口的顶边），加跳上、下落两个状态和重力。
- 新的窗口观察器：定时取窗口列表、算台面、在宠物所在窗口移动 / 消失时通知引擎。
- 宠物窗层级仍然是浮动层（在所有普通窗口之上），所以只上**最前面没被挡**的那段边，不会出现宠物「浮」在别的窗口前面。
- 权限：只读窗口的位置，不需要新权限（不读窗口标题和内容）。

## 3. 实现要点（2026-11-06 用户确认「就按这个做，频率几分钟一次」后实现）

- 默认活动范围改成**屏幕底边**（试用反馈「感觉是飘在空中的」：随意放的宠物常停在半空）；原来的行为改名「随意放」。
- 台面：`PetEngine` 记着宠物站在哪（随意放 / 地面 / 某个窗口顶边）。地面 = 屏幕可见区底边或自定义区域底边；
  宠物窗底边 = 台面高度 − 脚离窗口底边的距离（`footInset`，人形约 2.4% 窗高、毛绒约 9%、2D 为 0）。
- 空中：跳是抛物线（0.45–1.1 秒），掉是重力（2600 点/秒²）每帧找脚下的台面。拖到窗口顶边附近（24 点内）松手会「吸」上去；
  往下掉的途中不吸，免得刚跳下的那条边又把它接住。
- 窗口模式：落地后 2–5 分钟跳上一个窗口（近的优先），在上面待 1–3 分钟（期间溜达、8–25 秒后趴 20–60 秒），
  然后从近的那一头蹦出去往下掉。脚下那段被挡住 / 窗口没了也会掉。
- 窗口观察器平时每秒刷一次，宠物在窗口上或在空中时每秒 10 次（跟得上拖窗口）。
- 新片段：`jump_up`（起跳停在空中姿势）、`fall`（乱挥手脚，循环）、`land`（落地屈膝缓冲）、`lie_prone`（趴着托腮晃小腿，循环）；
  趴下 / 起来的交叉淡入淡出 0.6 秒。毛绒形象按名字猜（jump / fall / lie…），2D 帧图借用 happy / idle / sleep 帧。
- 自定义区域用自己的框选层（`PetRegionPicker`，不截屏、不要权限）。
