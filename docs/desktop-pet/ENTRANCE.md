# 桌面宠物：出场 / 退场动画

对应 issue #54（关联 #44）。宠物出现、消失、换形象时不再「一下子」，而是跳上来、挥手、跳下去。

## 1. 什么时候播

| 时机 | 播什么 | 入口 |
|---|---|---|
| 打开宠物（菜单 / 设置 / 快捷键）、Baobox 启动 | 出场 | `applyVisibility()` 发现窗口没显示 |
| 关掉宠物 | 退场，播完收起窗口 | `applyVisibility()` |
| 换形象（设置里选、环形菜单「换一个」、下载完自动换上） | 旧形象退场 → 换 → 新形象出场 | `selectCharacter` → `characterShown()` |
| 休息画面结束归位 | 只打招呼（不从屏幕外跳上来，休息画面已经把它送回原位） | `returnRenderView()` |
| 退出 Baobox（含 `make install`） | 短退场：只有掉下去那一段，最多等 0.5 秒 | `DesktopPetTool.willTerminate` → `PetController.stop()` |

设置页重扫素材包（`reloadCharacter`）不算换形象，不播。启动时当前形象是 3D 的：模型在后台读（VRM 要好几秒），
读好再出场，不先拿占位图跳一遍。

## 2. 动作

**出场（约 1 秒）**

1. 0–0.5 s：从所在屏幕的底边外（窗口完全在屏外）沿抛物线跳上来，越过落点再落下。渲染状态前半程 `jump`、后半程 `fall`。
2. 0.5–0.78 s：落在原位，压扁再拉长一下（2D 与毛绒 / 动物模型用形变；VRM 自动播已有的 `land` 落地片段）。
3. 0.78–1.0 s：转身面向用户。有出场片段的（VRM 默认 `wave`）播完编排后接着播片段；没有的在这一段弹一下、放大一点。

**退场（约 0.8 秒）**

1. 道别 0.4 s（有道别片段时 0.5 s）：VRM 播新加的 `bye`（0.55 s 的快速挥手），其他形象弹一下。
2. 掉下去 0.35–0.4 s：往近的那侧屏幕边一蹦，加速掉出屏幕底边；后 40% 淡出，2D 一路缩小到 0.4。

**减弱动态效果**（系统设置 › 辅助功能 › 显示）：原地淡入 0.3 s / 淡出 0.25 s，不跳、不招手。

**设置 › 宠物 ›「出场 / 退场动画」**（`pet.entrance`，默认开）：关掉就和以前一样直接出现 / 消失。

## 3. 实现

- **编排**（`PetEntrance.swift` 的 `PetEntrancePlan`）：纯函数，时间 → 窗口位置、渲染状态、朝向、跳动、透明度、形变。
  不碰窗口，好推演。
- **执行**：`PetEngine` 加 `entering` / `leaving` 两个状态和一个「脚本」：`runScript(as:_:)` 期间每一拍（30 fps）
  由脚本给位置与外观，状态机其余部分（溜达、睡觉、跳窗口、重力）全部跳过；脚本返回 nil 即结束，回到 `idle`。
  渲染层看到的永远是脚本给的外观状态（jump / fall / idle / notify），不认识 entering / leaving（都按 idle 画）。
  - 换脚本时递增代号：退场的旧脚本结束时不会把刚换上的出场脚本清掉；被打断的那段的完成回调不会再调。
  - 动画期间来的提醒只记时间，不改状态；落地后按 `notifyUntil` 补上提醒动作。
- **控制器**（`PetController`）：
  - `beginChoreography`：记下原位（`choreographyHome`）、关环形菜单、窗口不接鼠标、气泡收起排队、头顶挂件摘下。
  - `endChoreography`：外观复原，退场后把引擎与窗口放回原位（下次出场、记住的位置都用它），恢复鼠标。
  - 出场的完成回调里放出气泡、挂回头顶挂件、打招呼。
  - 快速开关：出场途中关掉 → 从此刻位置退场，播完仍放回出场终点；退场途中打开 → 直接重新出场。
- **气泡**（`BubbleController.setSuspended`）：气泡是宠物窗的子窗口，不收起会跟着飞出屏幕。收起期间新来的排队，
  放出时按到达顺序补上。关掉宠物时照旧清空（之后的通知走系统通知）。
- **换形象**：退场播完窗口收起，`switchingCharacter` 期间 `isReady` 仍为真 —— 通知交给宠物排队，等新形象出场后再显示，
  不在几秒的读取空档里掉到系统通知。新形象（含读取失败回退的占位图）一显示就出场。
- **头顶挂件**（会议控制条）：`updateAccessory` 在动画期间判为「不挂」，控制条收到 `onChange(false)` 自己回到屏幕顶部；
  落地后再挂回来。
- **退出**：`stop()` 里开一个短退场，就地转主循环（`RunLoop.run(mode: .default)`）让引擎定时器与 3D 渲染跑起来，
  播完或满 0.5 秒就收起，不拖慢退出。

## 4. 每个角色自己的出场 / 退场（pet.json）

3D 形象可以在 `pet.json` 里写 `enter` / `leave`，值是一个片段名或一串片段名（与 `interactions` 的候选同格式）：

```json
{ "model": "model.vrm", "enter": ["spin", "wave"], "leave": "bow" }
```

不写的：VRM 用 `wave` / `bye`，其他 3D 形象不播片段（出场弹一下）。模型里缺任何一段，整串不用。

## 5. 没做的（issue #54 的 P1）

- 几种出场随机选（从屏幕边走进来、从顶上掉下来、从 Dock 里蹦出来）。
- 离开电脑很久回来补「醒来伸懒腰」—— 现有的「睡醒 `wake`」互动已覆盖大半。
