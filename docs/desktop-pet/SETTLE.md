# 桌面宠物 · 找个不碍事的地方待着 + 原地动作

> 用户需求（2026-11-07）：
> - "一直走来走去，影响我操作电脑，但是不走动动作又很单调。"
> - "可以走动，但是最终能停留在不影响我操作的地方，比如空白的地方。"
> - "切换屏幕后，他挡住内容了，就自动走开。"
> - 多加一些原地动画。
>
> 用户确认按草案一起做（与 #54 出场动画、唤醒卡住的修复同一个分支）。

## 1. 目标

- 宠物大部分时间待在一个不碍事的地方，以原地动作为主。站着不单调：换站姿、做小动作、偶尔来段大动作、头跟着鼠标转。
- 挡住你正在用的窗口时自己让开：切换 App / 桌面以后、窗口挪过来以后、你在它旁边连着点的时候。
- 你亲手放的地方要尊重：先在那儿待着。

## 2. 走动方式（设置 › 宠物 ›「走动」）

| 档位 | 行为 |
|---|---|
| 不走动 | 停在原地（原来"溜达"关掉的样子）。开着"不挡我"时，挡住正在用的窗口仍会让开 |
| **安静（默认）** | 走到一个不碍事的地方待着，以原地动作为主。散步：45–100 秒在家附近挪一两步（0.3 个身位以内），挪不动就原地转个身。每 12–25 分钟换个同样不碍事的地方 |
| 适中 | 同上，散步更勤（18–40 秒，0.8 个身位以内），每 4–8 分钟换地方 |
| 活泼 | 原来的到处溜达，隔几分钟自己跳上窗口 |

- 老版本关过"溜达"（`pet.roam = false`）的，迁移为"不走动"；其余默认"安静"。
- 窗口模式下，"安静 / 适中"不再自己隔几分钟跳上窗口。只有找空地选中某个窗口顶边时才上去；在窗口上照样会趴着休息。

## 3. 怎么判断"碍事"（`PetSpotScorer`）

给每个候选落脚点打"碍事分"，越低越好。

### 3.1 按窗口位置（默认，不需要权限）

- **候选点**：只在宠物所在的那块屏上找。
  - 地面模式：脚下那条线上每隔约 1/8 个窗宽取一个。地面 = 屏幕底边或自定义区域底边。窗口模式再加每个窗口顶边上没被挡住的段。
  - 随意放（没有重力）：整块屏的可见区里撒网格，每隔约 1/5 个窗宽一个，上下左右都能去。2026-11-07 用户选"整个屏幕都找"，原先只在当前高度找。
- **挡住多少**：在宠物身子上撒 4×6 个点，看每个点下面最上层是什么，取平均。
  - 正在用的 App（最前面那个）的窗口：1 分；
  - 刚用过的 App 的窗口：刚切走时 0.9 分，十分钟内线性降回 0.35 分。并排的两个 App 来回切换时，两边都碍事，它就待着不动；不会每切一次就跑到另一边，除非找到真正的空地；
  - 别的窗口：0.35 分；
  - 桌面：0 分。
  - 身子按身形估：VRM 占窗口宽 36%、高 84%，毛绒 / 动物 70% × 75%，2D 帧图 80% × 80%。
- **你在旁边点过**：离最近 8 秒内在它旁边点过的位置太近，加分（最多 +0.45）。
- **鼠标只影响挑哪儿，不会把它赶走**：选点时略微避开鼠标跟前。但宠物不会因为鼠标靠近就跑，不然你想摸它、点它，它就跑了。
- **挑选时的小偏好**：近的、不用换台面的优先，免得为了好一点点横穿整个屏幕。

### 3.2 按屏幕内容（可选，"识别屏幕内容找空白处"，默认开）

- **什么时候用**：只在按窗口位置找不到空桌面时才看屏幕内容（最好的点也有 0.25 分以上，比如窗口铺满了屏幕）。
- **怎么看**：截一张宠物所在屏的低分辨率灰度画面。
  - 宽 480 像素，用 ScreenCaptureKit，不含 Baobox 自己的窗口。
  - 按区域算相邻像素差：文字、图片多的地方差得大，纯色空白处几乎为 0。
  - 挡住窗口的那部分分数乘以 `0.3 + 0.7 × 满的程度`，纯色空白处只算三成。
- **隐私与开销**：
  - 只用截图功能已有的屏幕录制权限。没有就不用，绝不弹授权。
  - 10 秒内最多截一次。
  - 画面只在内存里留 20 秒供打分，不写盘、不上传、不进日志。
  - 切换 App / 桌面时作废。

## 4. 什么时候挪、怎么挪（`PetSettler`）

### 4.1 什么时候看

| 时机 | 做什么 |
|---|---|
| 切换 App（0.8 秒后）、切换桌面（1 秒后）、屏幕变了（1.5 秒后）、系统唤醒（2 秒后） | 当前位置挡着正在用的窗口（≥ 0.3 分），且别处至少好 0.15 分 → 让开，跑过去 |
| 每 2 秒 | 当前位置连续三次（6 秒）都 ≥ 0.55 分（身子一多半挡在正在用的窗口上；窗口只是拖过去不算）→ 慢慢走开。刚挪过的 60 秒内不看 |
| 8 秒内在它旁边点了两下（点击穿透到下面的窗口；点到宠物身上的不算） | 你在那儿干活 → 让开，跑过去 |
| 安静 12–25 分钟、适中 4–8 分钟 | 换个同样不碍事的地方：离开至少一个半身位，不比现在差，近的机会大 |

2026-11-07 试用反馈："刚往右挪一点，就像命中了'走回空白处'，很快走回去。"原因是散步和让开各管各的：散步走到了碍事的位置，马上又被急着拉回来。为此做了三处改动：
- 散步前先问一声，只去不碍事、也不比现在更碍事的位置（`PetEngine.strollFilter`）；
- 只有事件触发（切换、旁边点击）才跑过去，每 2 秒检查到的挡着只是慢慢走开；
- 每 2 秒那一档调得更钝：0.45 → 0.55，2 次 → 3 次，挪完 60 秒内不看。

### 4.2 什么时候不挪

- **你亲手放的**：先待 10 分钟，期间每 2 秒的检查和换地方都不做。只有切换 App / 桌面后挡住了、或者你在它旁边连着点，才会让开。
- **刚挪完 / 刚落地**：5–6 秒内不再看。
- **刚看过、没必要挪**：8 秒内不再看；用过屏幕内容的 20 秒内不再看，免得老截屏。
- **宠物在忙**：有气泡 / 菜单、在做互动、在睡、在空中、被拖着、在出场退场、借给了休息画面，这些时候都不挪。

### 4.3 怎么挪

按路线过去（`PetEngine.travel`，见 §4.4）。横向 700 点或 4 个窗宽以内、需要往上爬的高度在 260 点或 2 个窗宽以内，才按路线走；否则钻黑洞。

- **让路**（切换 App / 桌面、旁边连着点）：跑过去。
  - 有跑步片段的按跑步的步幅移动，脚不打滑。
  - 没有跑步片段的快走：速度 ×1.8，走路片段同步加快。
- **其余**（每 2 秒检查到的挡着、换换风景）：慢慢走。
- **太远、太高、排不出路线**：脚下张开黑洞钻进去，从目的地的黑洞里冒出来。
  - 复用出场 / 退场编排（ENTRANCE.md），不道别、不招手，约 1.6 秒。
  - 关了出场动画就直接过去；系统开了"减弱动态效果"就淡出淡入。
- **新家**：走到、爬到、送到的地方就是新家。散步围着它挪一两步，家不会越散越远。窗口被拖走时，家跟着窗口一起挪。

### 4.4 上下：踩着冒出来的台阶（`PetStairs`）

2026-11-07 用户反馈"自由移动都是平移，没有纵向移动"。用户选了"攀爬"，又提议"像黑洞一样，给脚底下渲染一个台阶，爬上去后就消失"。

- **台阶**：和黑洞一个画风，是一块块发光的紫 / 青色小台面。
  - 每踩高（低）一级，脚下冒出一块：先放大，再淡入。
  - 走过的那块淡掉，往下沉一点。爬完，剩下的也淡掉。
  - 台阶画在一个铺满宠物所在屏的透明窗口里，排在宠物窗下面，不接鼠标。
- **动作**：踏台阶片段，侧身朝着要去的方向。每级抬高约身高的 15%，一个循环两级。没有这个片段的形象原地走着上下。
- **路线**：
  - 随意放：先踩台阶到目标高度，再走过去。
  - 地面 → 窗口顶：走到那个窗口离你近、且在屏幕内的一侧，贴着窗口边踩台阶上去，到顶迈到顶边上最近、站得稳的位置，再走到目标。
  - 窗口顶 → 地面：走到这段顶边离目标近的那一头，跳出去，重力下落着地，再走过去。原先是一条抛物线直接跳到地面，全程停在起跳姿势，看着像飘下去。
  - 窗口顶 → 别的窗口顶：钻黑洞。
- **规则**：踩台阶的途中不睡，被气泡拴住也不停在半空，等爬完。被拖走、被黑洞送走时台阶立即收起。

## 5. 原地动作（`PetModelView`，片段在 `VRMMotion`）

### 5.1 站姿轮换

站着超过 35–90 秒，就在平常的待机和下面 4 种站姿之间换一种，交叉淡入淡出 0.6 秒：
- `idle_hands_behind` 背手
- `idle_arms_crossed` 抱臂
- `idle_hands_front` 双手交握
- `idle_hip` 重心落在一条腿上、一只手叉腰

4 种都是首尾无缝的循环片段，带呼吸和摇摆。

### 5.2 小动作与大动作

- **小动作**：站着时每 5–10 秒做一个，不和上一个重样。原有 8 个，另加 8 个：
  - `rock_heels` 踮脚摇
  - `kick_ground` 蹭地
  - `fix_hair` 撩头发
  - `look_up` 搭手远眺
  - `hum_bounce` 哼歌颠
  - `arms_cross_tap` 抱臂点脚
  - `neck_stretch` 活动脖子
  - `peek` 探身偷看
- **大动作**：自娱自乐用，跳舞、扭一扭、欢呼、得意、开飞机、开合跳、转圈、原地跑。两分钟内最多一次，每次做小动作时约 15% 的机会换成大动作。
- 都是大幅度的全身动作：宠物只有一两百像素高，手指、表情看不出来。都不坐、不跪、不蹲，因为裙子没有布料模拟，见 VRM.md。

### 5.3 头跟着鼠标转

- **什么时候转**：鼠标最近 3 秒动过、离头 700 点以内。
  - 站着时转 85%，做小动作时 35%；
  - 走路、跳、睡、互动时回正。
- **怎么转**：给头骨挂一个朝向约束（`SCNTransformConstraint`），在动画算出来的朝向上再转一点：左右最多约 34°，上下 17°。
  - 身子 3/4 侧转的角度要扣掉，这样看起来是转头看你的鼠标。
  - 角度和力度都慢慢跟过去，鼠标一甩，头不会跟着一甩。
- **线程**：主线程每帧算好角度，写进加锁的 `PetLookState`；约束在 SceneKit 渲染线程里读。

### 5.4 你回来时

从打盹醒来（你离开 5 分钟以上又回来）："起身 + 伸懒腰 / 打哈欠 / 招手 / 大招手"里随机挑一种。

### 5.5 蹲一会儿、坐地上歇会儿（`.lounge`）

2026-11-07 用户点名要，原先因为裙子没有布料模拟、一坐就露裙底，不做坐姿（见 VRM.md）。

- **前提：假布料**。按名字找出裙子骨骼，按方位分组，按大腿姿态把前片、侧片往外翻，盖在腿上。所有片段都驱动裙子骨骼，跑步、踏台阶抬腿也受益。片段与布料在 `VRMMotion` / `VRMModel`，出预览确认不露再上。
- **什么时候歇**：
  - 只在"安静 / 适中"下，站久了才歇：安静 3–7 分钟一回，适中 5–10 分钟一回。
  - 每回 40–110 秒，蹲或坐地随机挑一种。
  - 片段：坐下（`*_down`，停在最后一帧）→ 坐着的循环 → 起身（`*_up`）。
- **起身规则**：
  - 歇够了、要挪窝、来提醒、被戳：先起身再说。引擎等起身片段播完才动。
  - 被拎起来、跳、掉：不起身，直接切走。
- **头**：坐着时头也跟着鼠标转，力度比站着小（60%）。
- **没有这些片段的形象**：不歇。

## 6. 设置项（`PetSettings`）

| 键 | 默认 | 说明 |
|---|---|---|
| `pet.activity` | `calm` | `still` / `calm` / `normal` / `lively` |
| `pet.avoid` | 开 | 不挡我（自动避开正在用的窗口） |
| `pet.contentAware` | 开 | 识别屏幕内容找空白处。只在"不挡我"开着时显示；没有屏幕录制权限时自动不用 |

窗口观察器（`PetWindowWatcher`，每秒读一次窗口位置，不需要权限）现在在三种情况下都会跑：窗口模式、"不挡我"开着、"安静 / 适中"。

## 7. 没做的

- 跨屏找空地：只在宠物所在的那块屏上找。
- 按文字光标 / 焦点控件判断你在看哪里（要辅助功能 API，先不做）。
- 指定"别在这几个 App 上停"。
