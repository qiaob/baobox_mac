# 桌面宠物 · 通知气泡与交互

> 代码：`mac/Sources/Modules/DesktopPet/` —— `BubbleWindow`（气泡层）· `RadialMenu`（环形菜单）· `PetWindow`（点击 / 双击 / 右键 / 抚摸识别）· `PetController`（把这些接起来）· `PetModelView`（互动动作）· `PetEngine`（站住 / 占用）。
> 形象与 `pet.json` 见 `PACKS.md`；上层设计见 `DESIGN.md`（PR #46）。

## 1. 气泡跟着宠物走

- 气泡窗挂成**宠物窗的子窗口**（`addChildWindow`）：宠物走动、被拖，气泡跟着动，相对位置固定。
- 贴位：尾巴尖贴在宠物头顶（宠物窗高度 86% 处）；气泡默认往宠物右边展开（尾巴在气泡宽度 28% 处）。靠屏幕边时气泡整体挪进屏内、尾巴跟着滑，始终指着宠物；宠物在屏幕顶上放不下时气泡翻到宠物下面、尾巴朝上。
- 头顶挂件：别的模块可以把一个小窗挂到宠物头顶（`PetController.dockAccessory`，目前是会议控制条，见 docs/meeting/TECH_DESIGN.md §9），同样是子窗口、跟着宠物走；挂着时气泡排在它外侧（挂件在头顶就往上让，在脚下就往下让）。宠物关掉 / 借给休息画面时先把挂件摘下来交还。
- 有气泡、环形菜单开着、或正在做互动动作时，宠物**站住并转过来正对用户**（`PetEngine.setHeld` / `occupy`），都结束 4 秒后才接着溜达。
- 实测（离屏小程序，真窗口）：宠物挪 (+300, +60)，气泡同步挪 (+300, +60)；toast 3 秒后窗口收缩，底边仍贴在宠物头顶。

## 2. 三种通知

| 样式 | 典型来源 | 行为 |
|---|---|---|
| **toast 轻提示** | 额度提醒、纪要已生成、宠物说的话 | 一行字 + 来源图标，3 秒自动消失 |
| **card 卡片** | Claude / Codex 任务完成 | 来源 + 标题 + 正文（+ 按钮），8 秒自动消失，底部细线显示剩余时间 |
| **sticky 常驻** | 会议提醒（进入 / 稍后 / 取消）、Claude 等你确认 | 不自动消失，点按钮或 × 才走；品牌色描边；每 25 秒宠物招手提醒一次 |

- 不指定样式时按级别：`ambient` → toast、`bubble` → card、`alert` → sticky —— 现有三个来源一行没改。
- 一次最多叠 3 条，最新的贴近宠物（只有它带尾巴），多出来的排队，顶上显示「还有 N 条」。
- **鼠标停在气泡上时所有倒计时暂停**，移开后至少再留 1.5 秒。悬停用 AppKit 跟踪区判断 —— Baobox 平时不是前台 App，SwiftUI 的 `onHover` 不一定触发。
- 按钮角色：`primary` 品牌色实心、`secondary` 淡底、`destructive` 红字。点按钮回调 `onAction(id)`；点没有按钮的卡片本体回调 `"open"`；点 × 只关闭、不回调。
- 气泡窗可成为 key（按钮要能点）但是 `nonactivatingPanel`，不会把 Baobox 切到前台。

              .init(id: "later", label: "稍后 5 分钟"),
              .init(id: "cancel", label: "取消", role: .destructive)]

    // "join" / "later" / "cancel"

测试：宠物右键 → 更多 → 发送测试通知，或菜单栏 → 桌面宠物 → 发送测试通知，三种各一条。

- 设计令牌（`docs/design/ui-design-v1.html`）：品牌色浅 `#17A398` / 深 `#2BC4B8`，深浅色自动切换。

## 4. 交互

| 操作 | 反应 |
|---|---|
| 单击 | 随机做个反应动作（笑、扭一扭、竖耳朵…）+ 冒一句话（「嘿！」「在呢～」） |
| 双击 | 击掌（没有击掌动作的形象就挥手 / 反应动作） |
| 在宠物身上左右来回蹭鼠标 | 摸摸头：舒服地点头 +「好舒服～」（1.5 秒内换向 4 次以上，冷却 4 秒） |
| 睡着时单击 / 动鼠标 | 醒来：起身 + 伸懒腰 / 打哈欠 |
| 右键 | 环形菜单 |
| 拖拽 | 搬家，气泡跟着走 |

**环形菜单**：两圈，都是系统菜单之外的同一套样式（不再弹回 NSMenu）。

- **内圈一整圈 8 格**，最后一格是「更多」：截图、取字、剪贴板、手机互传、实时翻译、喂食、陪玩、安静（1 小时 / 取消）里取 7 个：工具多出来时，排在最后的工具（实时翻译）挪到外圈最前；当前形象没有喂食 / 陪玩动画时，从外圈挪工具进来，内圈始终是满的。
- **点「更多」在外面展开更大的一圈**（变成高亮的「收起」，再点收回）：其他功能的快捷操作 —— 录屏、画笔、框选翻译、Claude Code 中心、Codex 中心、键盘点击、窗口最大化、防休眠 —— 加上换形象（切到下一个并报名字）、测试通知（三种各发一条）、设置、隐藏宠物。
- 工具按各模块的快捷键定义调用（`ToolRegistry.allHotkeys()`），宠物模块不认识具体工具；没注册的工具自动不显示。防休眠原本没有快捷键定义，为此补了一个出厂不绑键的 `caffeinate.toggle`。
- 排布：两圈都是围着宠物身体的椭圆（VRM 人形按骨骼投影的外包框，又高又瘦，圈也跟着瘦；其他形象按宠物窗），宠物越大圈越大。整圈放得下就从正上方顺时针按弧长均分；靠屏幕边放不下时，按钮只排在屏内最长的那段弧上（外圈常见）。宠物贴着屏幕最底（Dock 隐藏）时内圈中心会往上挪，此时挡在宠物身上的角度不放按钮，内圈成马蹄形围着头顶。Dock 显示时按钮可以压在 Dock 上，内圈仍是整圈。
- 点按钮先收起菜单再执行（截图不会把菜单拍进去）；点空白处、点别的 App、按 Esc 收起（外圈开着时先收外圈）。

动作来自 `pet.json` 的 `interactions`（见 `PACKS.md` §4.1）；没写的按片段名猜，猜不到就不支持。互动动作可被提醒 / 拖拽打断；一串动作（坐下 → 吃 → 站起）按顺序播。2D 形象的互动只有跳一下 + 一句话。
