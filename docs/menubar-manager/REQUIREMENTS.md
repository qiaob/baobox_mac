# 菜单栏管理 · 需求

> 2026-11-08 用户：「我的 mac 的系统托盘的图标经常被别的应用挤的看不到了」。给了几个办法后，用户选了
> 「做一个类 Ice 的菜单栏管理工具（收起别的图标、在刘海下方显示被藏的图标）」，并发了张截图：
> 被藏起来的图标就出现在 **Baobox 菜单最上面、「截图」上面那一行**。
> 看过效果图后又定了两点：「我可以设置哪些永远展示在 Baobox 里面」「不需要分割线，直接让我能在 Baobox 中设置哪些展示哪些隐藏就行」。
> 效果图：https://claude.ai/artifact/A7ftJyNNzRJeyCmkQnoiXh

## 1. 背景

- 用户的 Mac：14 寸 MacBook Pro（M3）。屏幕宽 1512 点，刘海占 665–850，菜单栏图标只能放在刘海右边（约 660 点宽）。
- 菜单栏上有 13 个图标：Baobox、Slack、1Password、Rectangle、控制中心的几个（Wi-Fi、显示器…）、聚焦、Tailscale、
  输入法、微信、电池 / 控制中心 / 时间（2026-11-08 探针实测）。
- 前台 App 的菜单多时会越过刘海、占掉右边的位置，放不下的图标直接藏到刘海后面。macOS 14 没有「更多」之类的入口，
  藏起来就点不到。
- **Baobox 的图标排在最左边**（从没被拖过，按系统默认位置），所以第一个被挤掉的就是它。

## 2. 目标

1. **在 Baobox 设置里给每个图标选「显示」或「隐藏」**。隐藏的不占菜单栏，改了立刻生效。菜单栏里不多出任何东西：
   没有分隔线，也不用按住 ⌘ 拖。
2. **隐藏的图标在 Baobox 菜单最上面一行，点得到**：点一下跟点了菜单栏上的它一样（打开它的菜单）。
   此刻被挤掉、被刘海挡住的图标也临时放进这一行（可关）。
3. **Baobox 自己的图标不再被挤掉**：一键挪到最右边、紧挨系统图标；另有快捷键「打开 Baobox 菜单」兜底。

## 3. 交互

### 3.1 Baobox 菜单顶部的图标行

- 位置：菜单第一行，「截图」上面（用户截图里框出来的位置），下面一条分隔线。
- 内容：先是设置里选了「隐藏」的图标；一道细竖线之后，是此刻被挤掉、被刘海挡住的「显示」图标（设置里可关）。
  图标就是菜单栏上那个样子（抓图标窗口的图像），鼠标停上去显示 App 名。
- 一个都没有的时候，这一行不出现。
- 点一下：先收起 Baobox 菜单，再打开那个图标的菜单。只把它一个临时挪到 Baobox 图标旁边（不在菜单栏最左边，鼠标不横跨屏幕），
  菜单关掉后挪回原处；别的隐藏图标不出来。接了多块屏幕时，菜单开在用户点 Baobox 的那块屏上。
- 图标多到一行放不下就换行。

### 3.2 显示 / 隐藏（Baobox 设置 → 菜单栏）

- 列出菜单栏上现有的每个图标：图标 + App 名 + 「显示 / 隐藏」两段选择。
- 选「隐藏」：这个图标立刻从菜单栏消失，出现在 Baobox 菜单顶部那一行；选回「显示」立刻回到菜单栏。
- 选择会一直记着：App 退出再开、Mac 重启后照旧（位置由 macOS 记在各 App 自己那里）。
- **第一次出现的图标**（刚装的 App 第一次启动）系统会排到最左，会先落进隐藏区，在 Baobox 菜单顶部点得到；想常显示就改成「显示」。
- 时间、控制中心、麦克风 / 摄像头的录音指示这类系统不让挪的图标不列出来；Baobox 自己的图标也不列（Baobox 的专注倒计时、会议录音指示排在 Baobox 图标右边，不会被藏）。
- 没在运行的 App 不列出来（它的图标不在菜单栏上），下次启动时位置照旧。

### 3.3 Baobox 图标的位置

- 设置里有「把 Baobox 图标放到最右边」：挪到系统图标（电池、控制中心、时间）左边紧挨着。以后被挤掉的是别的图标，
  Baobox 自己一直在，顶部图标行也就一直点得到。
- 快捷键「打开 Baobox 菜单」（出厂不绑）：在鼠标位置弹出 Baobox 菜单，图标被挡住时也能用。

### 3.4 设置页「菜单栏」

- 启用菜单栏管理。关掉后所有隐藏的图标回到菜单栏，顶部图标行不再出现。
- Baobox 图标的位置：「放到最右边」。
- 菜单栏上的图标：每个一行，「显示 / 隐藏」（§3.2）。
- 被挤掉的图标也临时放进 Baobox 菜单顶部那一行：开 / 关（默认开）。
- 权限：图标的样子要「屏幕录制」，隐藏图标、点被藏的图标要「辅助功能」。Baobox 的截图、窗口管理早就要过这两个，
  一般已经有了；没有的话给出去授权的按钮，并说明缺了哪样就少了什么。

## 4. 这一版不做

- 顶部图标行里拖动排序、分组。
- Ice 的「始终隐藏」第二层、鼠标移到菜单栏自动展开、改菜单栏颜色或图标间距。
- macOS 26 起系统自带菜单栏图标管理，到时再看要不要让路。
