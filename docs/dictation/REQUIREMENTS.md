# 语音听写（Dictation）· 需求

对应 issue #45，**P0 + P1 一次做完**（2026-11-06 用户定）。技术设计见 `TECH_DESIGN.md`。

2026-11-08 用户定：「开始 / 结束听写」改为**连续听写** —— 一句定稿就上屏，可以一直说下去（§1、§2、§3、§5）；识别语言默认改为「自动（中英）」（§3）。

## 1. 唤起

| 方式 | 行为 |
|---|---|
| 按住说话（快捷键 `dictation.hold`） | 按下开始，松开结束并上屏 |
| 开始 / 结束听写（快捷键 `dictation.toggle`，菜单同名项） | **连续听写**：按一下开始；每说完一句、停顿约 1 秒，这句就上屏，接着说下一句；再按一下结束（最后一句上屏），或安静一阵自动结束（默认 30 秒，可设 关 / 10 / 30 / 60 秒） |
| 长听写（快捷键 `dictation.long`，菜单同名项） | 持续识别直到手动结束；结果先进收集面板，可编辑，再整段插入 / 复制 |

- 「开始 / 结束听写」出厂绑定 **⌥Space**（2026-11-08 用户定）；另外两个出厂不绑定。按住说话支持普通组合键与 F1–F12（单独一个修饰键如右 ⌥ 暂不支持）。
- **Esc 取消**（听写中有效，吞掉这一下 Esc，不传给前台 App）；录音条上也有 ✕。连续听写里 Esc / ✕ = 停止：正在说、还没定稿的那句丢掉；已经定稿的照常上屏，已经上屏的保留（撤不回）。

## 2. 录音条

小浮条，**不抢焦点**（文字要进的那个 App 一直保持焦点）。位置：光标旁（能取到插入点位置时），否则当前屏底部居中。内容：麦克风电平、计时、实时识别预览（尾部一行）、提示（「松开结束」「再按一次结束 · Esc 取消」）、✕。结束后显示结果 2 秒：「已插入」或「已复制，⌘V 粘贴」+ [复制]。

连续听写：第二行是正在说的那句，空着时提示「说完一句停一下就上屏」；每上屏一句，录音条按新的光标位置挪一下（免得挡住刚输入的字）。结束时有句子没插进去就显示「已复制，⌘V 粘贴」（复制的是没插进去的那些），否则「已插入」。

## 3. 识别

- 语言：自动（中英自动判别，**默认**）/ 跟随实时翻译的说话语言 / 中文 / English。中文识别对夹杂的常见英文词本身就能识别。（2026-11-08 前默认是「跟随实时翻译」，而实时翻译出厂是固定英文，新装的听写只认英文。）
- 自动判别：先按主语言（系统语言是英文就先英文，否则先中文）识别；一段置信度低时用录下的音频按另一种语言再认一遍，取分高的，后面的段也换成它接着听。按住说话整次是一段；连续听写与长听写按停顿切段，所以**每句单独判**，可以一句中文一句英文。
- 优先设备端识别（音频不出本机）；系统只能走服务器识别时在设置里注明。
- 术语表与实时翻译共用（人名、产品名识别更准）。
- 与录音类功能互斥：会议记录 / 实时翻译正在用麦克风时，听写不开，宠物提示「正在 XX，先停止再听写」（设备端识别同一时间只能跑一个）。

## 4. 文本后处理（上屏前，按顺序）

1. **语音指令**（默认开）：「换行 / 新的一行 / new line」→ 换行；「新段落 / new paragraph」→ 空一行；「句号 / 逗号 / 问号 / 感叹号」→ 对应标点；「删除上一句 / delete last sentence」→ 删掉这次听写里的上一句。连续听写里上一句已经上屏了：按它的字数发退格删掉 —— 只删这次听写在当前 App 里输入的字（换了 App 就不再往回删）；自己挪过光标的话删的是光标前的字（退格本身的局限）。
2. **口头禅过滤**（默认开）：中文「嗯、呃、额、唔」、句首孤立的「啊、那个」、连说的「那个那个」；英文 um / uh / er / erm / hmm；连续重复的字词（「我我我」→「我」，「the the」→「the」）。保守处理，不改意思。整段只有口头禅时原样保留（可能就是「嗯」了一声当回答）；连续听写里这样的一句不上屏（多半是停下来想的时候出的声）。
3. **标点规整**：中文语境用全角标点，中英之间不乱加空格，去首尾空白；整段没有结尾标点时按语言补一个。
4. **AI 润色**（默认关）：本地模型把口语整理成书面语（去口水、顺句子）。可选「所有 App」或「仅这些 App」（按 App 单独开关，如聊天原样、文档润色）。按住说话要等整段定稿，所以开了润色的 App 会等润色完再上屏（最多 8 秒，超时上原文）；连续听写与长听写逐句润色、按顺序上屏，每句多等一两秒（含「删除上一句」的句子不润色）。模型没下载时跳过并提示一次。

## 5. 插入（按可靠性自动降级）

1. **写进当前输入框**（辅助功能）：原生 App 的文本框直接写入光标处 / 替换选中文字。
2. **模拟粘贴**：借剪贴板（快照 → 写入 → ⌘V → 恢复原剪贴板），**不进剪贴板历史**。Electron、终端、浏览器网页内容等写不进去的直接走这条。
3. **复制到剪贴板 + 提示**：没有可输入的焦点、或在密码框（安全输入开着）时。

连续听写**逐句插入当前焦点**（像打字：中途换了输入框，后面的句子就进新的地方），按顺序一句接一句，英文句子之间补空格、中文不加。某句插不进去（没有输入焦点、密码框、没权限）时不每句覆盖剪贴板：先攒着，结束时一次复制并提示。

插入失败绝不丢文字：录音条上能一键复制，听写历史里也有。

## 6. 听写历史

最近 N 条（默认 50，可设，可关）只存文本、时间、目标 App，不存音频。菜单「复制上一次听写」「听写历史…」（窗口：搜索、复制、再次插入、删除、清空）。

## 7. 设置「语音听写」

唤起方式说明（快捷键在快捷键页设）、安静多久自动结束（连续听写；关 / 10 / 30 / 60 秒，默认 30）、识别语言（默认自动）、优先设备端识别、语音指令、口头禅过滤、AI 润色（关 / 所有 App / 仅这些 App + App 列表）、插入方式（自动 / 总是粘贴）、录音条位置（光标旁 / 屏幕底部）、开始与结束提示音（默认关）、听写历史（开关 + 条数）、术语表（与实时翻译共用，链接过去编辑）。

## 8. 权限与隐私

麦克风、语音识别、辅助功能（写入焦点、模拟粘贴、Esc 拦截）—— 首次使用时按需引导，不预申请。默认设备端识别，音频不出本机。
