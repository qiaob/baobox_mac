# 语音听写（Dictation）· 需求

对应 issue #45，**P0 + P1 一次做完**（2026-11-06 用户定）。技术设计见 `TECH_DESIGN.md`。

## 1. 唤起

| 方式 | 行为 |
|---|---|
| 按住说话（快捷键 `dictation.hold`） | 按下开始，松开结束并上屏 |
| 开始 / 结束听写（快捷键 `dictation.toggle`，菜单同名项） | 按一下开始；再按一下或停顿（默认 3 秒，可设 关 / 2 / 3 / 5 秒）结束并上屏 |
| 长听写（快捷键 `dictation.long`，菜单同名项） | 持续识别直到手动结束；结果先进收集面板，可编辑，再整段插入 / 复制 |

- 快捷键出厂都不绑定。按住说话支持普通组合键与 F1–F12（单独一个修饰键如右 ⌥ 暂不支持）。
- **Esc 取消**（听写中有效，吞掉这一下 Esc，不传给前台 App）；录音条上也有 ✕。

## 2. 录音条

小浮条，**不抢焦点**（文字要进的那个 App 一直保持焦点）。位置：光标旁（能取到插入点位置时），否则当前屏底部居中。内容：麦克风电平、计时、实时识别预览（尾部一行）、提示（「松开结束」「再按一次结束 · Esc 取消」）、✕。结束后显示结果 2 秒：「已插入」或「已复制，⌘V 粘贴」+ [复制]。

## 3. 识别

- 语言：跟随实时翻译的说话语言（默认）/ 中文 / English / 自动（中英自动判别）。中文识别对夹杂的常见英文词本身就能识别。
- 自动判别：先按主语言识别；整段置信度低时用录下的音频按另一种语言再认一遍，取置信度高的。
- 优先设备端识别（音频不出本机）；系统只能走服务器识别时在设置里注明。
- 术语表与实时翻译共用（人名、产品名识别更准）。
- 与录音类功能互斥：会议记录 / 实时翻译正在用麦克风时，听写不开，宠物提示「正在 XX，先停止再听写」（设备端识别同一时间只能跑一个）。

## 4. 文本后处理（上屏前，按顺序）

1. **语音指令**（默认开）：「换行 / 新的一行 / new line」→ 换行；「新段落 / new paragraph」→ 空一行；「句号 / 逗号 / 问号 / 感叹号」→ 对应标点；「删除上一句 / delete last sentence」→ 删掉这次听写里的上一句。
2. **口头禅过滤**（默认开）：中文「嗯、呃、额、唔」、句首孤立的「啊、那个」、连说的「那个那个」；英文 um / uh / er / erm / hmm；连续重复的字词（「我我我」→「我」，「the the」→「the」）。保守处理，不改意思。
3. **标点规整**：中文语境用全角标点，中英之间不乱加空格，去首尾空白；整段没有结尾标点时按语言补一个。
4. **AI 润色**（默认关）：本地模型把口语整理成书面语（去口水、顺句子）。可选「所有 App」或「仅这些 App」（按 App 单独开关，如聊天原样、文档润色）。润色要等整段定稿，所以开了润色的 App 会等润色完再上屏（最多 8 秒，超时上原文）；模型没下载时跳过并提示一次。

## 5. 插入（按可靠性自动降级）

1. **写进当前输入框**（辅助功能）：原生 App 的文本框直接写入光标处 / 替换选中文字。
2. **模拟粘贴**：借剪贴板（快照 → 写入 → ⌘V → 恢复原剪贴板），**不进剪贴板历史**。Electron、终端、浏览器网页内容等写不进去的直接走这条。
3. **复制到剪贴板 + 提示**：没有可输入的焦点、或在密码框（安全输入开着）时。

插入失败绝不丢文字：录音条上能一键复制，听写历史里也有。

## 6. 听写历史

最近 N 条（默认 50，可设，可关）只存文本、时间、目标 App，不存音频。菜单「复制上一次听写」「听写历史…」（窗口：搜索、复制、再次插入、删除、清空）。

## 7. 设置「语音听写」

唤起方式说明（快捷键在快捷键页设）、停顿自动结束、识别语言、优先设备端识别、语音指令、口头禅过滤、AI 润色（关 / 所有 App / 仅这些 App + App 列表）、插入方式（自动 / 总是粘贴）、录音条位置（光标旁 / 屏幕底部）、开始与结束提示音（默认关）、听写历史（开关 + 条数）、术语表（与实时翻译共用，链接过去编辑）。

## 8. 权限与隐私

麦克风、语音识别、辅助功能（写入焦点、模拟粘贴、Esc 拦截）—— 首次使用时按需引导，不预申请。默认设备端识别，音频不出本机。

## 9. 数据

`~/Library/Application Support/Baobox/Dictation/history.json`（只存文本）。
