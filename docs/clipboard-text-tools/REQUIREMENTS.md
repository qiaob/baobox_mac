# 剪贴板文本工具 — 需求文档

> 版本：v1.0（2026-08-01）
> 配套：同目录 `TECH_DESIGN.md`（技术方案）
> 定位：Clipboard 模块（`id: "clipboard"`）的能力扩展，**不新增 ToolModule**。同时**移除独立的 QRCode 模块**，其能力并入剪贴板动作。

## 1. 背景与定位

剪贴板历史面板现在只能「看一眼原文 + 粘回去」。但开发者复制的东西大多是**有结构的**：时间戳、JSON、XML、URL、Base64、JWT。每次都要开一个在线工具（还得担心把生产环境的 token 贴进别人的网站）或者切到别的 App 去转换，很碎。

本期让面板**认出选中条目的格式**，在右侧预览区给出**可读的渲染**和**一排就地转换的动作**，转换结果可以直接 ⏎ 粘贴到刚才那个 App。全部本地计算，不联网。

同时：独立的「二维码」工具（菜单栏一级入口 + ⌃⇧Q）**整体移除**，因为它的真实用法就是「把刚复制的东西给手机」——本质上是剪贴板的一个动作，不值得占一个一级模块。

## 2. 术语

- **识别器（Recognizer）**：一个格式的检测 + 渲染 + 动作的实现单元。新增格式 = 新增一个识别器。
- **命中（Match）**：识别器认出了当前选中条目的文本。一条文本可以被多个识别器命中。
- **转换动作（transform）**：输入文本 → 输出文本。结果进「预览缓冲」，⏎ 粘贴的就是它。
- **终端动作（terminal）**：输出不是文本（生成二维码、用浏览器打开、在 Finder 中显示）。自己收尾，不进预览缓冲。
- **通用动作**：对任何文本条目都出现的动作（本期：二维码）。区别于格式专属动作（JSON 格式化只在识别到 JSON 时出现）。
- **预览缓冲**：当前预览区显示的文本。默认 = 条目原文；执行转换动作后 = 转换结果。**不写回历史、不落盘**。

## 3. 功能清单

### P0 — 框架与交互（里程碑一）

| # | 功能 | 说明 | 验收标准 |
|---|---|---|---|
| 1 | 格式识别 | 选中条目变化时，对**当前选中的这一条**跑一遍所有识别器（惰性、纯内存、不落盘、不进 `ClipboardItem`） | 选中一条 JSON，预览区顶部出现 `JSON` 徽章；切到别的条目徽章跟着变 |
| 2 | 多格式命中 | 命中多个时徽章行列出全部，按优先级默认选中第一个，点击 chip 可切换 | 选中一个 `https://a.com?token=eyJhbGci…`，徽章行同时出现 `URL` 和 `JWT`，可切换 |
| 3 | 预览缓冲 | 执行转换动作后预览区显示结果，徽章行出现「已转换 · 还原」；⏎ 粘贴的是**转换后**的内容，⌥⏎ 纯文本粘贴同理 | 格式化 JSON 后按 ⏎，目标 App 里粘进去的是格式化后的 |
| 4 | 转换不污染历史 | 转换结果写剪贴板时抑制监听，不产生新的历史条目 | 格式化 10 次 JSON，历史条数不变 |
| 5 | 预览区最大化 | **Tab** 切换：列表列隐藏，预览区占满面板宽度（~630pt）。最大化时徽章行显示 `3 / 57`，↑↓ 仍可换条目 | Tab 展开、再按收起；展开状态下能看清格式化后的 JSON |
| 6 | 最大化状态记忆 | 开关状态存 UserDefaults，下次开面板保持 | 展开后关面板、再开，仍是展开的 |
| 7 | Esc 渐进撤销 | 最大化时 Esc 先收起最大化；非最大化时 Esc 关面板 | 展开状态按两次 Esc 才关掉面板 |
| 8 | 动作快捷键 | 动作栏按钮依次对应 `⌘1`…`⌘9`；`⌘0` 还原转换 | 选中 JSON 按 ⌘1 = 格式化 |
| 9 | 长度保护 | 文本 > 256KB 不做识别（只显示原文，通用动作仍在）。动作只挂在识别成功的条目上，所以这一道就够，不再给转换单设更宽的门槛 | 粘一个 20MB 的文件路径列表，面板不卡顿 |
| 9b | **逐格式开关** | 设置页「文本工具」区：一个总开关 + 每个格式（含二维码）一个独立开关，全部出厂开启。**关掉的识别器完全不参与检测** —— filter 在 detect 之前，不是「跑完再藏起来」 | 只留 JSON、其余全关，选中一个时间戳 → 没有徽章、没有转换表；关总开关 → 预览区回到纯原文 |

### P0 — 首批格式（里程碑一，与上并行）

| # | 格式 | 说明 | 验收标准 |
|---|---|---|---|
| 10 | 时间 | 识别 Unix 秒/毫秒/微秒/纳秒、Apple 绝对时间、ISO 8601 / RFC 3339、`yyyy-MM-dd HH:mm:ss`、RFC 2822；输出一张转换表，每行末尾一个复制按钮 | 选中 `1785499200`，表里同时给出本地时间、UTC、ISO、毫秒、相对时间 |
| 11 | JSON | 识别 + 格式化（**保持原始 key 顺序、数字原样**）、压缩、转义成字符串、去转义（递归，最多 3 层） | 含 19 位雪花 ID 的 JSON 格式化后 ID 一字不差；key 顺序与原文一致 |
| 12 | XML | 识别 + 格式化（缩进）、压缩 | 一行 XML 格式化成带缩进的多行 |
| 13 | URL | 识别 + percent 编码 / 解码；query 参数拆成键值表（value 自动解码），每行可复制 | 选中带 5 个参数的 URL，表里列全 5 行 |
| 14 | Base64 | 识别（严格门槛，见 §5.5）+ 解码 / 编码；解出来是 JSON 时可接着走 JSON 动作 | 选中一段 base64，一键解出原文 |
| 15 | JWT | 识别（三段 + header 含 `alg`）；分段渲染 header / payload（都格式化），`exp`/`iat`/`nbf` 转成人类时间并标注是否已过期。**不做签名验证** | 选中一个过期 token，显示「已过期 2 小时」 |
| 16 | 二维码（通用动作） | 对任何 ≤2900 字节的文本可用：生成二维码并**钉到屏幕中央**，面板随之关闭。超容量时按钮置灰 | 复制一个链接 → 面板 → ⌘… → 屏幕中央出现常驻二维码，手机能扫 |
| 17 | 二维码快捷键 | `clipboard.qrcodeLast`：不开面板，直接给**最近一条**生成二维码钉到屏幕。出厂**不绑定**（`defaultCombo: nil`） | 在快捷键页自设组合后，复制完按一下就出二维码 |

### P1 — 后续格式（本期不做，框架留位）

哈希（MD5/SHA1/SHA256）、文本清洗（trim / 去空行 / 行排序 / 行去重 / 行数字数）、命名风格互转、进制转换、颜色（复用 `ColorFormatter`）、Unicode / HTML 实体转义、简繁转换与拼音（`CFStringTransform`）、链接「用浏览器打开」、文件「在 Finder 中显示」。

**明确不做**：与上一条 diff（窄预览区展示不下）、CSV 表格预览（同上）、语法高亮（手写着色器工作量与收益不匹配，v1 有缩进够用）。

## 4. 交互与 UI

### 4.1 预览区布局（自上而下）

```
┌─ 徽章行 ────────────────────────────────────────┐
│ PREVIEW · 文本   [JSON] [Base64]   已转换 · 还原  │   ← 最大化时右侧另显 3 / 57
├─ 正文 ─────────────────────────────────────────┤
│ {                                              │
│   "id": 1234567890123456789,                   │   ← 预览缓冲内容
│   "name": "x"                                  │
│ }                                              │
├─ 表格（时间 / URL query / JWT 分段才有）──────────┤
│ 本地时间   2026-08-01 20:00:00 GMT+8        ⧉  │
│ UTC       2026-08-01 12:00:00Z             ⧉  │
├─ 动作栏 ───────────────────────────────────────┤
│ [格式化 ⌘1] [压缩 ⌘2] [转义 ⌘3] │ [二维码 ⌘4]   │   ← │ 左为格式专属，右为通用
├─ 元信息行（已有）───────────────────────────────┤
│ 来源 Safari · 128 字符 · 8/1 20:00              │
└────────────────────────────────────────────────┘
```

正文与表格共用一个 `ScrollView`，正文高度自适应。动作栏与元信息行固定在底部。

### 4.2 键盘（面板内，`ClipboardPanelController.handleKey`）

| 键 | 行为 | 备注 |
|---|---|---|
| ↑ ↓ | 换条目 | 已有；最大化时列表虽隐藏但仍可用 |
| ⏎ | 粘贴**预览缓冲** | 行为变更：以前粘贴 `item.text` |
| ⌥⏎ | 纯文本粘贴预览缓冲 | 同上 |
| ⌘⇧C | 只复制预览缓冲，不粘贴、不关面板 | 新增。**不能用 ⌘C** —— 主菜单「编辑」里 ⌘C 绑的是 `NSText.copy(_:)`，劫持它会让搜索框与预览区里「选中一段文字再复制」失效 |
| Tab | 切换预览区最大化 | 新增 |
| ⌘1…⌘9 | 触发动作栏第 n 个动作 | 新增 |
| ⌘0 | 还原转换（回到条目原文） | 新增 |
| Esc | 最大化时先收起；否则关面板 | 行为变更 |
| ⌘P / ⌘⌫ | 置顶 / 删除 | 已有，不变 |

### 4.3 状态提示

- 转换后徽章行必须出现「已转换 · 还原」，否则用户不知道 ⏎ 粘的是哪个版本。
- 切换选中条目、切换格式 chip、按 ⌘0，都清空预览缓冲。
- 动作因容量上限被禁用时（二维码 > 2900 字节）按钮置灰 + tooltip 说明原因，**不是点了没反应**。
- 转换可以串（格式化 → 转义 → …），所以每个转换都要重新校验入参；不适用时静默不动，不产出乱码。

## 5. 各格式识别与输出规则

### 5.1 时间

**输入**

| 形态 | 判据 |
|---|---|
| Unix 秒 | 9–10 位纯数字，落在 1970-01-01 ~ 2100-01-01 |
| Unix 毫秒 / 微秒 / 纳秒 | 13 / 16 / 19 位纯数字，同上范围 |
| 小数秒 | `1785499200.123` |
| Apple 绝对时间 | 9–10 位纯数字（2001-01-01 起算）。**与 Unix 秒歧义** |
| ISO 8601 / RFC 3339 | `ISO8601DateFormatter`，含/不含小数秒、含/不含时区偏移 |
| 常见日期时间 | `yyyy-MM-dd HH:mm:ss`、`yyyy/MM/dd HH:mm:ss`、`yyyy-MM-dd` |
| RFC 2822 | HTTP `Date:` 头、邮件头 |

歧义处理：9–10 位纯数字**同时**按 Unix 秒和 Apple 绝对时间列出两行，各自标注清楚，**不猜**。

误报容忍：10 位数字也可能是订单号/QQ 号。因为转换不会自动生效（只是多一张表），**宁可宽松也不漏**。

**输出表**

| 行 | 示例 | 可复制 |
|---|---|---|
| 本地时间 | `2026-08-01 20:00:00 GMT+8` | ✅ |
| UTC | `2026-08-01 12:00:00Z` | ✅ |
| ISO 8601 | `2026-08-01T12:00:00Z` | ✅ |
| 秒 | `1785499200` | ✅ |
| 毫秒 | `1785499200000` | ✅ |
| 相对 | `3 小时前` | ❌ |

时区只给「本地 + UTC」，不做第三时区配置项。

### 5.2 JSON

**检测**：trim 后首字符是 `{` 或 `[`，且 `JSONSerialization` 能解析（不开 `.fragmentsAllowed`，所以 `123`、`"abc"` 不算 JSON）。

**动作**

| 动作 | 说明 |
|---|---|
| 格式化 | 2 空格缩进。**必须保持原始 key 顺序、数字字面量原样透传**（雪花 ID / 高精度小数不得变形） |
| 压缩 | 去掉所有非字符串内的空白 |
| 转义 | 转成可嵌进代码的字符串字面量 |
| 去转义 | 递归剥掉转义层（最多 3 层），常见于日志里的 `"{\"code\":0}"`。剥完若是 JSON 则自动格式化 |

### 5.3 XML

**检测**：trim 后首字符是 `<`，且 `XMLDocument` 能构造成功。

**动作**：格式化（缩进）、压缩。

**安全**：剪贴板内容来源不可信，解析必须**显式禁止加载外部实体**，否则一段构造过的 XML 能让 App 去读本地文件或发起网络请求（XXE）。

### 5.4 URL

**检测**：`URLComponents` 能解析且有 scheme。

**动作**：percent 解码、percent 编码。有 query 时额外给一张参数表（key / value 两列，value 自动 percent 解码，每行可复制）。

### 5.5 Base64

Base64 的字符集太宽松，**误报率是六个格式里最高的**，所以门槛要严，且优先级排最低：

- 长度 ≥ 16；标准 base64 长度是 4 的倍数，base64url 允许无 padding（长度 % 4 ≠ 1）
- 字符集只含 `A-Za-z0-9+/=`（或 base64url 的 `A-Za-z0-9-_`）
- 解出来是**有效 UTF-8**
- 解出来的**可打印字符占比 ≥ 90%**（排除随机二进制）

**动作**：解码、编码。解出来是 JSON 时，徽章行追加 `JSON` 供切换。

### 5.6 JWT

**检测**：三段以 `.` 分隔，每段是合法 base64url，且**第一段解出来是含 `alg` 字段的 JSON**。这个门槛让误报接近于零，所以 JWT 优先级排最高。

**渲染**：header（格式化 JSON）/ payload（格式化 JSON）/ signature（原样，不解）三段。payload 里的 `exp`、`iat`、`nbf`、`auth_time` 若是数字，追加一列人类时间；`exp` 已过期时标红并显示「已过期 X」。

**明确不做签名验证** —— 没有密钥，也不该在剪贴板工具里做。

### 5.7 二维码（通用动作）

- 对任何文本可用，条件是 UTF-8 字节数 ≤ 2900（`QRCodeGenerator.maxBytes`），超了置灰。
- 行为：生成 1024px 二维码 → `PinnedImageWindow.pin` 钉在鼠标所在屏中央（260pt 见方）→ **关闭剪贴板面板**。
- **为什么是钉出来而不是画在预览区**：剪贴板面板装了「点面板外就关闭」的全局监听。二维码画在预览区的话，你一拿手机、一切到微信去扫，面板当场就没了 —— 每次都会发生，不是边缘情况。钉出来的浮窗不受面板生命周期影响，且 `PinnedImageWindow` 自带右键菜单（复制图片 / 另存为 / 关闭），原工具的复制和保存能力也就跟着继承过来了。

## 6. 移除独立 QRCode 模块

### 6.1 删除

- `Sources/Modules/QRCode/QRCodeTool.swift`（含 `QRCodeSettingsView`）
- `Sources/Modules/QRCode/QRCodePanel.swift` 里的 `QRCodePanel` / `QRCodePanelController` / `QRCodePanelView`
- `AppDelegate.swift` 的 `registry.register(QRCodeTool())`
- 菜单栏一级入口、设置 Tab、全局快捷键 `qrcode.generate`（⌃⇧Q）

### 6.2 保留并迁移

**`QRCodeGenerator` 不能删** —— NetCapture 模块有两处在用（`NetCaptureWindow.swift:711` 的显示二维码、`NetCaptureTool.swift:289` 的证书下载二维码）。它现在被三个地方共用，已不属于任何单个模块，**移到 `Sources/Core/QRCodeGenerator.swift`**，与 `Geometry`、`KeyCombo` 等共享基础设施并列。

### 6.3 能力去向

| 原能力 | 去向 |
|---|---|
| 全局快捷键唤起 | → 新的 `clipboard.qrcodeLast`（最近一条直接生成并钉屏，出厂不绑定） |
| 带入剪贴板文字 | → 剪贴板动作天然就是对选中条目做 |
| 钉到屏幕 | → 保留，二维码动作的默认行为 |
| 复制图片 / 另存为 | → 由 `PinnedImageWindow` 的右键菜单承担 |
| 输入框可编辑 | **接受丢失**。主场景是「把刚复制的链接甩给手机」，要改内容改完再复制即可 |
| 设置 Tab | **接受丢失**，原本只有一句用法说明 |

### 6.4 清理

- `qrcode.*` 共 11 条文案：`qrcode.panel.tooLong` / `qrcode.panel.empty` 改名后复用到新动作的置灰提示，其余删除。
- 用户可能自定义过的 `hotkey.qrcode.generate` 会成为 UserDefaults 里的孤儿键 —— 无害（`HotkeyCenter` 只按注册的 definition 查表），顺手清掉即可。
- 设置窗的 tab 选择是纯内存的（`SettingsTabSelection.selectedTab` 默认 `"general"`，不持久化），**不存在「记住了一个已删除的 tab」的问题**。

## 6.5 设置项

设置页 → 剪贴板 → 新增「文本工具」区，位于「隐私」与「忽略的 App」之间：

| 键 | 默认 | 说明 |
|---|---|---|
| `clipboard.textTools.enabled` | `true` | 总开关。关掉后预览区回到纯原文显示，一次识别都不跑 |
| `clipboard.textTools.jwt` / `.json` / `.xml` / `.timestamp` / `.url` / `.base64` / `.qrcode` | `true` | 逐格式开关，总开关开启时才显示 |

识别是主线程同步执行的，所以这组开关的意义是**真正省掉 CPU**：`TextFormatRegistry.detectAll` 里 `filter` 在 `detect` 之前，关掉的格式一次 `detect` 都不会跑。

`clipboard.qrcodeLast` 全局快捷键**不受**二维码开关影响 —— 那是用户自己绑的键位，按下去静默无反应比不一致更糟。开关管的是面板里的识别与按钮。

## 7. 非目标

- 不联网。所有转换纯本地计算。
- 不修改历史条目内容。转换只影响预览缓冲，`clipboard.dat` 里存的永远是原文。
- 不做语法高亮、不做 diff、不做签名验证。
- 不为文本工具新增 ToolModule，也不新增设置 Tab（并进剪贴板已有的设置页；长度上限做成常量，不给配置项）。

## 8. 验收标准（整体）

1. 选中一条 19 位雪花 ID 的 JSON，⌘1 格式化 —— **ID 一字不差、key 顺序与原文一致**，⏎ 粘出去的是格式化后的。
2. 选中 `1785499200`，转换表六行齐全，点任一行的复制图标只复制不关面板，且**历史不多出条目**。
3. 选中一个 JWT，header/payload 都格式化显示，`exp` 那行标出「已过期 X」。
4. Tab 展开预览区、关面板、再开 —— 仍是展开的；展开时 Esc 先收起、再按才关。
5. 复制一个长链接 → 二维码动作 → 屏幕中央出现常驻二维码，切到别的 App 它还在，手机能扫出原链接。
6. 粘一段 20MB 文本进剪贴板再开面板，↑↓ 切换不掉帧、不卡死。
7. 一段带外部实体声明的 XML 不会导致任何文件读取或网络请求。
8. 菜单栏不再有「二维码」一级入口；NetCapture 的证书二维码和代理二维码**照常工作**。
